# V0.1.75 안정화

V0.1.74 기준 변경입니다. 사망 로직 제거, 어비스 10분 제한, /item 및 /itemreset, 한 판 전리품 1개 규칙을 유지합니다.

- 재접속 팝업이 사라진 것만으로 성공 처리하지 않습니다. 전투/결과/입장/필드 화면이 3회 연속 확인돼야 해당 단계로 복귀합니다.
- 같은 판 재접속은 기존 단조 증가 시계 타이머와 전리품 집계 상태를 보존합니다. 로딩 화면은 전투 시작/재입장 성공으로 인정하지 않습니다.
- 퇴장 대상은 2프레임 연속 확인 후 입력하며, 마지막 순간의 클리어가 퇴장보다 우선합니다.
- 어비스 동일 단계 복구, 클리어 터치/나가기 및 네트워크 복구 반복에 상한을 적용합니다. 자동복구 중에도 기존 10분 제한을 확인합니다.
- 입력을 직렬화하고 취소, 창 크기/이동/최소화, 포커스, 화면 나이와 좌표 범위를 입력 직전에 확인합니다. 문제가 있으면 안전 정지합니다.
- 클릭/드래그/키보드 입력의 예외 경로에도 눌림 해제를 실행합니다. 전리품 인식 후 다시하기 좌표를 재확인합니다.
- 업데이트 복사 실패를 무시하지 않고, 현재 작업의 완성된 백업만 롤백에 사용합니다. 실행 중 updater는 임시 사본을 사용합니다. SHA256 없는 패키지는 거부합니다.

게임/Interception 장치에서 장시간 실사용 검증은 별도로 필요합니다. 실제 Windows 앱 빌드, 실행 및 생산 코드 회귀 테스트를 CI에서 수행합니다.
