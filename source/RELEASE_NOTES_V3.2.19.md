# MabiAuto V3.2.19 — AI 사전 점검 및 Codex 한도 오류 재분석

## 업데이트 내용
- **AI 오류 시간별 내역 → AI 사전 점검 (실행 없음)**: Python·Git·Codex 명령·.NET SDK·소스 Git 상태·제작/가공 관련 회귀 테스트의 로컬 준비상태를 확인합니다. 선택적인 GitHub Draft PR 준비상태도 구분하여 표시합니다. 결과를 `%USERPROFILE%\MabiAutoAI\autopilot-results\pipeline-check.json`에 기록합니다.
- **한도 오류 재분석**: 실제 Codex 제공자 사용량 제한으로 `blocked` 처리된 기존 오류에 한해, 한도 복구와 AI 감시 재개 후 사용자의 명시적 동의로 **1회만** 새 격리 작업 폴더에서 다시 분석하도록 합니다. 원본 오류 증거·기존 수정 후보는 유지합니다.
- 잘못된 오류 ID, 다른 종류의 차단, 아직 진행 중인 quota pause, 중복 재분석 요청은 거부합니다.
- 격리된 임시 Git worktree와 가짜 Codex·테스트·PR 응답을 이용하는 오프라인 전체 흐름 및 안전 차단 회귀 테스트를 추가했습니다.

## 유지·제외
- 목재·금속 등 제작/가공 **고정좌표와 기존 작업 처리 경로는 변경하지 않았습니다.**
- 어비스 HUD 및 100회 채집 오류 원인 확인/수정은 이번 릴리스에서 제외했습니다.
- 매크로 종료 시 자식 AI 감시와 Codex 종료 동작은 그대로 유지합니다.
- AI가 제안한 코드를 자동 병합·실게임 적용·운영 자동배포하지 않습니다. 게임 입력이나 사용자의 Codex 계정 자동 접속도 하지 않습니다.

## 배포 확인과 남은 검토
- PR #217의 Windows 생산 빌드/테스트와 어비스·가공 스케줄러 CI 검사 통과 후 main에 통합했습니다.
- V3.2.19는 최신 main Windows CI와 실행 파일 스모크 검사, 필수 AI 모듈 포함 검사, ZIP·SHA256 검사 및 태그 중복 금지 검사를 **모두 통과한 경우에만** 자동 업데이트용 GitHub Release로 공개합니다.
- **중요**: CI는 실제 사용자 PC의 Codex 로그인, 계정 사용량 복구, 실오류 자동 수정 성공 및 실제 Draft PR 생성을 증명하지 않습니다. 배포 후 Work에서 실제 환경의 end-to-end 동작을 검토해야 합니다.
- 이전 V3.2.18 릴리스와 백업/복구 경로는 덮어쓰지 않습니다.
