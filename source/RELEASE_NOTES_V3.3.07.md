# V3.3.07 — 음식 재료 수량 CLI 판정 및 OCR 실패 재시도

- 음식 재료의 보유 수량은 새 CLI 재고를 사용합니다. OCR 현재량 오인식으로 재료를 다시 수급하거나 건너뛰지 않습니다.
- 자동 수급 불가 재료도 CLI 보유량을 최종 확인합니다. 생크림 등 중간재료가 충분하면 하위 재료 검사를 생략하고, 부족분만 계산합니다.
- 현재 퀘스트에서 확인한 재료명과 필요량을 기준으로 CLI 부족 후보가 하나일 때 이름을 복원합니다. 복원 불가능한 이름 OCR 실패는 재인식하며 실제 재료 부족과 구분합니다.
- 재료 확보의 반복 판정에서 행 위치를 제외하고 CLI 재고 증가를 사용합니다. 이동/채집 중에는 건너뛰기를 보류합니다.
- 제작대 도착은 첫 화면의 제작하기 문구와 활성 버튼, 다음 최신 화면의 버튼 상태로 확인합니다. 두 번째 문구 OCR 성공은 요구하지 않습니다.
- 실제 제작 완료창 후 재고 반영을 최대 60초 확인하고 조회 실패를 재시도합니다. 제작 입력을 중복 실행하지 않습니다.
- 진단에는 음식명, OCR 원문과 영역/행 위치, CLI 재고, 필요량, 인식 실패·실제 부족·수급 경로 없음·도구 부족 등의 사유를 남깁니다.
- 필요 수량은 선택한 제작 횟수의 화면 값을 사용합니다. CLI의 1회 제작 가능 여부만으로 여러 회차 재료가 충분하다고 판단하지 않습니다.
- Windows 빌드와 회귀 검사 후 배포합니다. 실제 게임 검증은 배포 후 필요합니다.
- 이전 버전 복구: 포함된 ROLLBACK_PREVIOUS.cmd.
