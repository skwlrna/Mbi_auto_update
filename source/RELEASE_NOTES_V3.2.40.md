# MabiAuto V3.2.40 — 식재료 확보 경로 확인 및 시설별 안전 보류

## 주요 변경
- F9 식재료 가공의 부족 재료를 **현재 게임 CLI 채집 목록, 지원되는 무료 채집 화면 경로, 가공 제법 및 신규 재고 조회**로 보수적으로 분류합니다.
- 채집과 중간가공 어느 쪽으로도 자동 확보가 확인되지 않는 재료, 채집 도구 부족, 퀘스트 전용 재료 및 불명확한 중간가공 경로는 **확보 경로 미확인**으로 분류합니다. 채집 목록에 없다는 이유만으로 아이템이 게임에서 획득 불가능하다고 주장하지 않습니다.
- 첫 F9 전체 선행채집 준비 시 획득 경로 미확인 음식은 해당 선행채집 대상에서 제외하고, 정상 확보 가능 재료의 다른 작업은 기존 안전 규칙대로 진행합니다.
- 해당 음식의 작업 등록 **이전 단계**에서 미확정 공급 경로를 발견하면 그 품목과 시설의 다음 순번을 보류합니다. 금속·옷감처럼 독립적인 다른 시설은 계속 처리할 수 있습니다.
- 보류 중에는 30초 간격으로 **신규 CLI 재고**를 확인합니다. 이전에 부족했던 수량이 확보되었다는 증거가 있어야 보류를 해제하며, 이후에도 기존 F9 등록·수령·위치 및 영속 장부 검증을 전부 다시 적용합니다.
- 보류 상태에서 F10 중지를 지원하며, 자동 구매/거래소 결제/정령의 날개 사용/임의 재등록은 추가하지 않습니다.

## 안전과 기능 한계
- 자동 확보 경로가 불명확하다는 것은 게임에서 영구적으로 구할 수 없다는 의미가 아닙니다. 원문 패킷 구조나 새로운 CLI 명령을 가정하지 않습니다.
- 실제 실행 중 이미 게임 조작이 시작된 후 발생한 오류는 기존 미확정 작업 차단 및 안전 정지를 우선하며, 모든 오류를 독립 보류로 전환하지 않습니다.
- 식재료를 자동 보류한 동안 재료가 보충되지 않으면 F9는 작업을 완료했다고 주장하지 않고, 취소될 때까지 읽기 전용 상태로 대기합니다. 같은 시설의 다음 음식은 앞 음식이 재개·완료되기 전 실행하지 않습니다.
- 음식 제작 퀘스트의 추천 획득처 경로는 기존 정책을 유지합니다. 본 변경의 독립 시설 보류는 **F9 식재료 가공** 대상입니다.

## 회귀 검증
- 획득 경로 미확인/CLI 목록만 있고 화면 경로 미지원/채집 도구 부족/퀘스트 전용/정상 우물 채집을 구별.
- 음식 한 품목이 보류된 상태에서도 독립 시설 등록 진행, 동일 시설 다음 레시피 순서 유지, 신규 재고 확보 뒤 재개, F10 취소 시 무입력 검증.
- Windows PR 및 main CI 후에만 버전 V3.2.40 릴리스가 공개됩니다.
