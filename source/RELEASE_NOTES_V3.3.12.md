# Mabi Auto V3.3.12 — 음식 소량 우선 제작과 중간재 가공 대기열 수정

- 가방·캐릭터 보관함·공용 보관함 합계로 현재 바로 제작 가능한 수량을 먼저 제작합니다. 생크림 30개라면 호박 수프 6회를 먼저 제작하고, 1회도 불가능할 때 부족 재료 확보로 전환합니다.
- 음식 중간재의 독립 가공 경로에서 queue_full 응답 시 실제 대상 시설 대기열을 조회합니다. 7칸 진행 중이면 대기하고, 시설 전체가 완료됐으면 기존 수령·검증 경로를 사용합니다. 받은 중간재는 요청 부족량에서 차감합니다.
- 대기열 응답과 실제 슬롯이 계속 불일치하면 품목·시설·점유·완료·진행 수를 기록하며 같은 음식 퀘스트를 세 번 재생성하지 않습니다.
- 완료된 음식 제작 수량과 정령의 날개 0개 원칙을 유지합니다.

검증: 음식 재고별 배치 선택, 실제 재귀 가공 경로의 대기·수령·중복 생산 방지·불일치 무입력 중단 회귀, Windows 빌드와 기존 제작·가공 회귀 및 배포 실행 검사를 수행합니다.
실제 게임 구동 검증은 미실시이며 기존 수동 롤백 기능을 유지합니다.
