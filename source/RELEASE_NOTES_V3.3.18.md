# Mabi Auto V3.3.18 — 완료 결과 화면 누락 방지 및 강제 퇴장 재검증

- 2026-11-13 18:54:51 V3.3.17 단독 어비스 오류: 허상의 정박지 152판을 이미 완료했고 전리품/전투 시간 보상 화면이 존재했지만, 전투 대기 단계에서는 클리어 제목+터치만 검사해 10분 강제 퇴장을 잘못 시작했습니다. 퇴장 확인창이 남아 HUD 복귀가 실패했습니다.
- 전투 대기에서 매 1.25초 내외로 **결과 화면도 먼저 확인**합니다. 기존 3개 초록 버튼 배치 또는 독립된 '전투 시간' + '발견한 전리품' 위치 고정 OCR을 두 프레임에서 확인하면 클리어 터치 없이 결과 단계로 이동합니다.
- 정상 결과 단계에서는 기존 가운데 '다시 하기' 엄격 버튼 검증을 유지하며, 가공 스케줄러라면 매 판 실제 CLI 가공 상태를 다시 확인해 '다시 하기' 또는 왼쪽 '나가기'를 결정합니다. 보상 텍스트 확인 자체는 버튼 클릭 권한이 아닙니다.
- 10분 경계의 퇴장 아이콘 입력 전/도중에도 새 프레임으로 정상 결과를 재확인합니다. 결과가 확인되면 강제 퇴장을 취소합니다.
- 미완료 던전의 강제 퇴장 확인은 '던전에서 퇴장하시겠습니까' 제목과 **오른쪽 나가기**를 두 프레임 연속 확인해야 합니다. 화면 전체의 '나가기' 문구만 보고 클릭하지 않습니다.
- 확인창이 나타나면 **ESC 1회로 먼저 닫아** 숨겨진 완료 보상 결과를 재확인합니다. 완료 확인 시 정상 결과 처리로 복귀합니다. 확인창이 닫히고 실제 던전 퇴장 아이콘이 동일 위치에서 2프레임 확인된 미완료 전투에만 퇴장을 다시 요청한 뒤 Space 1회로 확정합니다.
- 정상 결과/미완료 전투를 구분하지 못하거나 ESC/Space 확인이 실패하면 추가 입력 없이 안전 정지합니다. 스텔라그램 ESC, 자동가공/제작 및 전리품 집계 정책은 변경하지 않았습니다.

검증: 결과 판정 2프레임, 보상 텍스트 독립 증거, 전투 대기 우선순위, 퇴장 확인 2프레임, ESC 재점검/Space 제한, 이전 어비스·다중가공/WinForms 안전 회귀, Windows CI, 실행 스모크 및 ZIP/checksum 검사. 실제 게임 실측은 미실시, 롤백 유지.
