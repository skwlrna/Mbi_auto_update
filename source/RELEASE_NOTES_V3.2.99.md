# Mabi Auto V3.2.99 — 검색어 최근 기록 UI 변경 대응

## 원인 (실제 확인)
2026-11-07 13:42:52 KST V3.2.98 약품 가공 '산뜻 버섯 진액' 검색 후 상세 선택 실패. 사용자 원격 스크린샷에서 검색 팝업에 **최근 검색어 칩**이 추가되어, 기존 입력 좌표 **(400,862)**가 실제 텍스트 입력칸이 아닌 최근 검색어 칩을 눌렀다는 점이 확인되었습니다. 화면 변화율 10.5%만으로 첫 품목을 클릭하는 조건도 이를 차단하지 못했습니다.

## 수정
- 사용자 현장 확인: 검색 팝업이 열린 상태에서 **Enter** 키를 누르면 실제 텍스트 입력칸에 포커스가 잡힙니다. 약품 가공 및 음식/아이템 제작에서 해당 Enter를 사용하고, 고정 검색 입력칸 클릭을 제거합니다.
- 검색어 붙여넣기 → Enter로 확정 → Space로 적용 흐름 유지.
- 약품 가공은 **적용 팝업이 닫히고 첫 번째 카드만 표시되는 모습이 새 화면 2장 연속 확인된 경우**에만 첫 결과 카드 클릭을 허용합니다. OCR 일치나 영역 변화만으로 잘못된 전체 목록을 선택하지 않습니다.
- 첫 카드 좌표는 **약품 (218,412)** / **음식·아이템 제작 (218,613)** 그대로 유지합니다. 음식·아이템의 기존 결과 선택/상세 검증은 이 버전에서 변경하지 않습니다.
- F07 제법명·현장/무료 버튼·좌표 안전 검증, 기존 F9 작업 수령·중복 등록 방지 로직을 유지합니다.
- 실제 컴파일된 화면을 대상으로 단일 카드/복수 카드/적용 팝업 픽셀 검증 회귀 테스트와 정적 CI 검증을 추가했습니다.

## 주의·검증
기존 앱에 설치된 V3.2.98은 자동으로 코드가 변경되지 않습니다. V3.2.99 공개 릴리스가 확인되어야 업데이트할 수 있습니다. Windows 빌드, 기존 회귀, 실행 파일 기동, ZIP SHA256, 이전 버전 백업 및 롤백 구성, 정확한 메인 SHA CI를 통과해야 공개합니다. **수정 후 실제 게임에서 검색 및 등록 성공 여부는 아직 확인되지 않았으므로** 결과가 불확실하면 추가 입력 없이 멈춥니다.
