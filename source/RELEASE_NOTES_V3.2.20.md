# MabiAuto V3.2.20 — 목재 가공 완료 정체 수정 및 AI 자동수정 소스 검증

## 포함된 수정
- **목재 가공 완료 5건/133초 정체 오탐 대응**: 모든 슬롯이 완료된 경우에만 기존 검증된 관리자 수령 기회를 한 번 허용하며, 관리자가 실제 작업 완료/등록/수령 증거를 남기지 못하면 원래 정체 기준으로 안전 정지합니다. 미완료 슬롯이 있으면 예외를 허용하지 않습니다. 임의 설비 이동·모두 받기·Space 재입력은 계속 금지합니다.
- **Codex 작업용 Git 버전 일치**: 설치 패키지 BUILD_COMMIT.txt와 Git HEAD 및 신뢰할 수 있는 origin을 대조합니다. 오래된 기존 MabiAutoAI/repo를 직접 덮어쓰거나 갱신하지 않고, 새 SHA 기준의 별도 source-snapshots 폴더에 clean clone을 검증 후 등록합니다. 저장소 준비 실패 시 분석을 중지하며 기존 로그·worktree·설정은 보존합니다.
- **Codex NuGet 준비**: 격리 작업 폴더를 만든 후 호스트에서 알려진 .NET 프로젝트의 복원을 먼저 수행합니다. NETSDK1004/피드 오류 등 복원 실패는 환경 차단으로 기록하며 코드 수정 성공으로 오인하지 않습니다.
- **AI 시간별 내역**: 최초 오프라인 후보 테스트와 최종 PR Windows CI, 사용자 실게임 해결 확인을 구분합니다. 로컬 결과에 Codex 분석 기준 SHA를 보존하며 새 후보는 배포 기준 SHA도 기록합니다.
- **GitHub Draft PR 안전장치**: 게시 직전 후보 부모 커밋과 원격 main HEAD를 대조하여 구형 기반 후보 게시를 차단합니다. CI가 아직 돌지 않았다면 PASS라고 표시하지 않습니다.

## 검증 범위
- CI Windows 생산 엔진/안정성 잠금/F9/가공/제작/채집/어비스·가공 스케줄러 회귀가 모두 통과한 뒤에만 V3.2.20 릴리스를 게시합니다.
- EXE 버전·BUILD_COMMIT.txt SHA·필수 Python 배포 모듈 및 ZIP 해시가 일치해야 하며, 태그/Release 중복 시 자동 덮어쓰지 않습니다.
- 기존 좌표·템플릿과 운영 입력 보호를 바꾸지 않았습니다. 매크로 종료 시 자식 Codex 감시 종료 정책을 유지합니다.

## 배포 후 PC 실환경 검증 필수
- 설치 후 파일 버전 3.2.20.0, BUILD_COMMIT.txt의 배포 SHA 및 MabiAutoAI/source-alignment.json 일치 여부를 Work에서 다시 확인하세요.
- 새 오류 한 건에서 최신 소스 clone, 실제 Codex 로그인/실행, 별도 호스트 테스트, 검토용 Draft PR을 확인해야 합니다.
- **Windows CI의 테스트 통과는 실게임에서 오류가 해결됐다는 증거가 아닙니다.** 게임 입력·수정 운영 적용·PR 병합을 AI가 자동으로 수행하지 않습니다.
- 이전 V3.2.19 릴리스, 모든 과거 AI 분석 로그/작업 폴더와 백업·롤백 경로를 보존합니다.
