# V3.2.46 후보 — PC 원클릭 안전 테스트 (오프라인 스모크)

## 버튼
MabiAuto의 **AI 오류 관리 → PC 원클릭 안전 테스트** 버튼을 누르면 PC용 Python 검사기를 별도 프로세스로 실행합니다.

- F9/F10 매크로가 작업 중인 경우에는 테스트를 시작하지 않습니다. 게임 자체는 켜 둬도 됩니다.
- 앱을 닫으면 실행 중인 테스트 프로세스도 중단합니다.
- 사용자 PC에 Git·Python·.NET 8 SDK가 필요합니다. 검사기가 배포된 `BUILD_COMMIT.txt`와 정확히 일치하는 **깨끗한** 소스 체크아웃을 검사합니다.
- 해당 소스가 없으면, 기존 `release_source.prepare_source` 규칙으로 **공식 GitHub main을 한 번 내려받아 정확한 배포 SHA인지 검증한 뒤** 별도의 스냅샷에 저장합니다. 이 작업은 앱 업데이트가 아닙니다. main 버전이 현재 설치된 빌드와 다르면 검사를 중지합니다.
- 확인된 소스는 변경하지 않고, 일회용 Git archive를 임시 폴더로 풀어 테스트합니다. 경로 탈출·링크·과대 파일은 차단합니다.
- 다음 다섯 종류의 테스트를 순서대로 실행합니다: **AI AutoFix 전체 Python**, **F9 자동가공**, **N02 영속 재개**, **F05 등록·수령 장부**, **어비스/가공 통합 스케줄러**. 첫 실패부터 안전하게 멈춥니다.
- PC 내부 진단 결과는 `%LOCALAPPDATA%\MabiAuto\diagnostics\one-click\latest-result.json`에 저장됩니다. 테스트 표준 출력·개인 계정·게임 스크린샷·원시 패킷은 진단 JSON이나 GitHub에 업로드하지 않습니다.

## 제한 사항
**이 버튼은 게임 테스트가 아닙니다.** 게임 API 호출·이동·제작·등록·수령·Codex 자동 수정·GitHub PR 게시·자동업데이트를 절대 실행하지 않습니다. PASS는 현재 설치된 빌드의 오프라인 PC 실행환경/회귀 테스트를 통과했다는 의미만 있습니다. 실게임 F9 동작과 Codex 오류 수정/실제 Draft PR 발행 여부는 안전하게 분리된 추가 검증이 필요합니다. F8 버튼과 기존 AI 감시 시작 버튼은 변경하지 않습니다.

## 릴리스
초안 PR이며 V3.2.45에 종속되어 있습니다. V3.2.41~45의 단계적 검증과 정식 배포 승인 전까지 V3.2.46은 개발용으로 유지합니다. `main`의 버전과 자동업데이트 정보는 변경하지 않습니다.
