# Mabi Auto V3.2.46 — 개인 사용자 요청에 따른 시험 운영 릴리스

> **중요: 실게임 미검증.** 이 릴리스는 한 명의 사용자가 본인의 기존 설치본에 자동업데이트가 적용되도록 **명시적으로 요청한** 상태에서 공개했습니다. GitHub CI 및 PC 원클릭 오프라인 테스트는 실게임 검증을 대체하지 않습니다. F9 재료 부족 보류/이어하기, 중복 수령 방지, 실제 게임에서의 롤백, 실제 Codex 오류 분석→PR 생성까지는 검증되지 않았습니다. 관련 증빙은 `source/V3.2.46_GAME_TEST_ATTESTATION.json`에 **pending**으로 남아 있습니다.

## 포함 기능

- V3.2.41~V3.2.45: 음식 제작 재료 부족 시 보류·재개, 부족 재료 예측, 생활 생산 시설 우선순위, 반복 오류 격리, AI AutoFix 중복 실행 방지 및 검증
- V3.2.46: PC 원클릭 안전 테스트 (AI AutoFix Python, F9 가공, N02 영속 재개, F05 장부, 어비스/가공 통합 스케줄러)
- **AI 감시 Windows 잠금 수정:** `autopilot.lock`의 잠금 영역을 읽기 전에 OS 잠금을 확보하도록 변경. 실제 Windows 단일 실행 경쟁 테스트에서 재현된 `PermissionError` 원인을 수정
- Windows 잠금 파일 공유 충돌, 접근 권한 오류, 다른 감시 실행을 구분하여 UI에 표시. 기존 오류 기록 및 작업공간은 자동 삭제하지 않음
- GitHub 공식 소스를 설치 ZIP의 고정 커밋 SHA로 검증하여 개발용 `main`/RC 차이 때문에 감시가 종료되는 문제 수정

## 배포 및 복구

- GitHub의 **비-프리릴리스** `V3.2.46` 릴리스로 기존 V3.2.40 및 이전 버전의 자동업데이트 검사에 표시됩니다.
- 앱은 `MabiAuto_V3.2.46_Windows_Lite.zip` + `.sha256`가 모두 존재하고 다운로드 SHA256이 일치할 때만 설치를 시도합니다.
- 패키지에는 `ROLLBACK_PREVIOUS.cmd`, `tools/RollbackPrevious.ps1`, `REPAIR_AUTO_UPDATE.cmd`, `START.cmd`를 포함합니다. **롤백 실행은 아직 실사용 검증되지 않았습니다.**
- 실행 중인 매크로에는 임의로 새 코드를 주입하지 않습니다. 문제가 있으면 F10 정지 후 재시작하거나 이전 버전으로 되돌리는 것이 안전합니다.
- **이미 V3.2.46 RC를 설치한 사용자는 같은 버전 번호의 정식 릴리스가 자동 재설치되지 않습니다.** 현재 수정 시험판을 그대로 사용하다가 다음 번호의 업데이트가 출시되면 업데이트됩니다.

## PC 원클릭 안전 테스트

`AI 오류 관리 → PC 원클릭 안전 테스트`에서 오프라인 테스트 5개를 실행합니다. Git, Python 및 .NET 8 SDK가 필요합니다. 게임 입력, 아이템 등록·수령, Codex 실행, GitHub PR 게시, 자동업데이트는 테스트가 수행하지 않습니다.

## AI AutoFix 범위

- 매크로 실행 도중 새 오류가 발생하면 로그/증거를 수집하고, AI 감시가 실행 중이고 로컬 필수 도구 및 Codex 로그인 권한이 확인되면 격리된 작업 폴더에서 수정·회귀 검사 및 GitHub **Draft PR** 제안을 시도합니다.
- AI 코드 수정은 현재 실행 중인 매크로에 **자동 병합하거나 자동 배포하지 않습니다.** 검토와 사용자 승인이 필요합니다.
- 보류·실패한 과거 오류 기록 75건을 일괄 삭제하거나 자동 재분석하지 않습니다. 작업공간 정리는 개별 검증 및 승인 후 ZIP 백업 방식만 허용합니다.

## 미검증 항목 및 이용 조건

단독 사용자 요청: `source/V3.2.46_SOLO_OWNER_RELEASE_ACCEPTANCE.json`. 이 파일은 **실게임 성공 증빙이 아닙니다.** 정식 업데이트 채널에서 배포되더라도 게임 입력·수령·복구가 완벽하다는 보증은 아닙니다.
