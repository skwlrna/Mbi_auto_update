# Mabi Auto V3.3.16 — 어비스 나가기 후 스텔라그램 ESC

- 2026-11-12 20:08 병행 다중가공 오류: 어비스 결과에서 나가기 후 '오늘의 스텔라 픽 / 베스트 스텔라그램' 팝업이 필드 HUD를 가려 60초 복귀와 90초 복구가 실패했습니다.
- 확인된 결과 나가기 이후에만 상단 '오늘의 스텔라 픽'과 중앙 '베스트 스텔라그램'의 서로 다른 두 텍스트 영역을 **2개 새 화면**에서 정확히 인식합니다.
- 스텔라그램으로 확정된 화면에만 Interception ESC(스캔코드 0x01)를 **한 번** 보냅니다. 일반 팝업, 전투 화면, 던전 선택 화면에는 ESC를 보내지 않습니다.
- ESC 이후 같은 팝업이 2프레임 연속 미감지일 때만 기존 협동 미션 확인 및 던전 밖 HUD 3프레임 검증을 재개합니다. ESC 성공만으로 가공 입력권을 반환하지 않습니다.
- ESC 후 팝업 유지 또는 재발 시 다른 버튼 입력·무한 ESC 없이 안전 정지합니다.
- 음식 제작, 다중가공, 어비스 진입 Space와 전투/결과 처리 로직은 변경하지 않았습니다.

검증: 스텔라그램 2개 OCR ROI/2프레임/1회 ESC/퇴장 확인 조건을 잠근 회귀 테스트, 기존 어비스/가공 및 Windows CI, 릴리스 실행 파일·ZIP·체크섬 검증. 실제 게임 수락 시험은 미실시이며 롤백 유지.
