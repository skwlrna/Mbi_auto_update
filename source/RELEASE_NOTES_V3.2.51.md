# Mabi Auto V3.2.51 — 둥지 목록 복귀·선택 오류 보완

> **사용자 요청 배포 · 실제 게임 둥지 클릭 미검증.** Windows 오프라인 테스트는 실제 클릭 성공을 보장하지 않습니다.

## 수정
- 일상 채집의 둥지가 첫 행인데 목록이 이전 스크롤 위치(예: '물'부터 보임)에 머무는 오류를 보완합니다.
- 둥지에만 목록을 맨 위로 되돌리는 제한 드래그를 최대 4회 수행합니다.
- 기존의 서로 다른 최신 두 화면에서 정확한 이름 OCR·아이콘·행 기하 확인을 통과해야만 선택합니다.
- 다른 채집 재료 및 고정 한 페이지 목록에는 해당 드래그를 적용하지 않습니다.
- 오프라인 채집 회귀 테스트 2개를 추가합니다.

## 검증 및 제외
- Windows 회귀 테스트·빌드·패키지 체크섬과 이전 버전 복구 스크립트 제공은 필수입니다.
- **실게임 둥지 선택, 자동업데이트 설치와 롤백은 아직 검증되지 않았습니다.**
- AI 자동수정기 29/30 작업공간·검증 정책 수정은 이번 릴리즈에 포함하지 않습니다. 별도 PR #267로 유지합니다.
- 설치 전에 매크로와 AI 감시를 종료하십시오. 실패 시 `ROLLBACK_PREVIOUS.cmd`로 이전 버전으로 복귀할 수 있습니다(롤백 실기기 미검증).
