## 검증과 배포
- 검토한 PR #314/#315의 Windows 생산 엔진/가공 회귀 CI가 통과했습니다.
- 이번 릴리스의 정확한 main 커밋으로 Windows 빌드·테스트, 실행 파일 기동 스모크, updater ZIP SHA256, 백업/롤백 자산을 검증한 뒤에만 GitHub 공식 릴리스가 발행됩니다.
- **실제 게임에서 미리 테스트하지 않은 CI-only 배포입니다. 게임 기능 수정 성공을 확인했다고 표시하지 않습니다.**
- 설치된 V3.2.62는 시작할 때 새 버전을 확인하므로 첫 업데이트를 위해 프로그램을 종료 후 다시 실행해야 할 수 있습니다. 유휴 중에만 업데이트되며 업데이트 적용에 성공하면 매크로 프로그램을 재시작합니다. 게임 작업 자동 재개는 보장하지 않습니다.
