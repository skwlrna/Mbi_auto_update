# Mabi Auto V3.2.48 — 요리 재료 채집 안정화 및 다중 제작 순차 실행

> **실게임 미검증 업데이트.** 사용자 요청에 따라 제작 오류 수정과 순차 제작 기능을 배포합니다. CI/오프라인 테스트 통과는 실제 게임에서의 채집, 제작, 롤백 성공을 의미하지 않습니다.

## 변경 사항
- 요리 재료 자동이동 뒤 get_activity의 일시적인 idle 5회만으로 재료 확보를 완료 처리하던 문제 수정. 2026-10-20 가든 샐러드 파스닙 32/100 오류를 기준으로 재현 경로를 분석했습니다.
- **재료명과 재고 목표를 확인한 뒤 CLI 재고 조회에서 목표 이상을 2회 검증한 경우에만** 다음 제작 퀘스트 단계로 진행합니다.
- 채집 중 목표 미달이면 퀘스트창을 다시 열지 않고 자동채집을 관찰하며, 재료명이 불명확하면 중복 조작 없이 안전 정지합니다.
- 이미 열려 있는 퀘스트 부족 재료 팝업은 재사용하고, 요리 품목 전환 시 레시피 이름 후보 캐시를 초기화합니다.
- 제작 화면에서 여러 품목을 수량과 함께 추가·삭제·정렬하고, 한 품목의 제작 결과가 확인된 후 다음 품목을 시작하도록 순차 처리합니다.
- 이전 품목에서 오류 또는 취소가 발생하면 나머지 품목을 진행하지 않습니다.
- 관련 검증: 일시적인 idle/재고 부족, 연속 CLI 재고 충족, 다중 제작 순서와 오류·취소 시 정지, 실제 Windows UI 대기열 조작 회귀 테스트.

## 제한 및 주의
- **실제 게임에서 V3.2.48 제작/채집/큐 완료 검증은 아직 없습니다.** 실제 채집 시작·수량 변화·다음 재료 전환을 직접 확인해야 합니다.
- 재료명 미확인 상태에서 재고로 채집 완료를 판단할 수 없다면 자동으로 퀘스트창을 재진입하지 않고 안전 정지합니다.
- 자동복구 중 외부 재고 감소나 재료 부족 판독 실패는 조작을 추정하지 않습니다.
- 현재 대기열은 실행 세션 내 순차 처리입니다. 프로그램 종료 후 미완료 품목의 **완전 자동 재개/영구 큐 복원**은 이 릴리스에서 보장하지 않습니다.
- 실게임 롤백 검증은 수행되지 않았습니다. 프로그램을 정지한 뒤 업데이트하고, 문제가 있으면 제공된 백업/롤백 스크립트를 검토하세요.
- 기존 무료 화면 조작 및 읽기 전용 CLI 원칙을 유지하며 유료 execute_crafting은 실행하지 않습니다.
