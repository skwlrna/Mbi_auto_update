# Mabi Auto V3.2.52 — 가죽+ F9 선행채집 예외 및 제작 시작 진단

> **사용자 요청 배포 · 실제 게임 `가죽+` 첫 제작 미시작 원인 미확정.** Windows CI 통과는 실게임 성공을 보장하지 않습니다.

## 수정
- F9 전체 재료 선행채집 대상에서 `가죽 가공 시설` 품목을 제외합니다. 가죽은 현재 원재료가 소진되면 자동 채집 없이 해당 품목만 종료하는 기존 정책을 유지합니다.
- 가죽 부족 내역이 다른 시설의 `queue_full` 응답에 가려져도 선행채집으로 진입하지 않습니다.
- F9 시작 전 읽기 전용 CLI 진단 로그에 각 품목의 목표 수량, 총 작업 수, 시설 점유 칸 수, 1회 제작 가능 여부와 현재 부족 재료 또는 차단 이유를 기록합니다.
- 가상 테스트: `가죽+` 200개 목표, 가상 가죽 100개 보유 시 1회분이 충분하면 첫 제작 작업을 등록할 수 있는지 검증합니다. 테스트 재료 단가는 실제 게임 수치가 아닙니다.
- 선행채집, 기존 음식 재료 확보, 다른 시설 작업, `queue_full` 마스킹 및 기존 대기열 안전성 회귀 확인.

## 중요한 제한
- **실제 게임의 `가죽+` 미시작 원인은 사용자 F9 로그가 없어 확정되지 않았습니다.** 이번 수정이 해당 증상을 해결했다고 단정하지 않습니다.
- AI 감시 및 자동수정기 PR #269·#271의 별도 개발 사항은 포함하지 않습니다.
- 실제 게임에서의 가죽 첫 제작, 재료 소진 후 수령, 자동업데이트 설치 및 롤백은 아직 검증되지 않았습니다.
- 설치 전 매크로와 AI 감시를 종료하십시오. 업데이트 실패 시 동봉 `ROLLBACK_PREVIOUS.cmd`로 복구할 수 있으나 실제 PC 실행 검증은 미완료입니다.
