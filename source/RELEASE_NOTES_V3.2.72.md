# Mabi Auto V3.2.72 — 음식 제작 분류·누락 재료 수급 안전 수정

- **카레라이스가 제작 → 아이템으로 잘못 이동하던 문제 수정.** CLI 제작 분류가 없거나 범용 아이템으로 표시되더라도 확정된 음식 제법은 음식 카드를 사용합니다.
- 알리오 올리오, 미트 파르미자나, 샤와르마, 넛츠 초코 비스킷, 토마토 크림 생선 커넬 등 이름만으로 구분하기 어려운 음식명을 포함해 56개 제작 이름을 우선 분류합니다.
- 다중 음식 제작 시작 직전에도 각 선택 품목의 제법과 제작 카테고리를 재검증합니다.
- **셀러리·생강·커다란 고기·카레 가루·파프리카·초콜릿·특수 전리품·낚시 재료** 등 직접 자동 확보할 수 없는 재료가 부족하면 해당 음식만 건너뛰고 다음 음식으로 진행합니다. 충분한 보유 재료는 정상 사용합니다.
- 말린 찻잎·발효된 찻잎·오트밀·숙성된 커다란 고기·헤이즐넛 오일 등의 중간 가공품은 하위 재료와 보유량을 확인합니다.
- 직접 확보가 검증되지 않은 재료를 임의 추천 획득처에서 채집하지 않으며, 채집·이동 상태가 불안전하면 전체 작업을 안전 중지합니다.
- 기존 **800×1000 고정좌표**, 텔레그램 제작 상세 상태, 다중 제작 건너뛰기 동작을 유지합니다.
- Windows Lite 자동 업데이트 ZIP, SHA256, 소스 ZIP 및 롤백 도구를 포함하고 실행 중인 매크로는 강제로 교체하지 않습니다.

**검증:** Windows 빌드, 카레라이스 및 기타 음식 분류, 미수급 재료, 다중 제작 회귀 테스트, 전체 메인 CI, 실행 파일 기동 및 업데이트 패키지 검사를 통과한 경우에만 공개 배포합니다. 실제 게임 내 실기 테스트는 별도입니다.
