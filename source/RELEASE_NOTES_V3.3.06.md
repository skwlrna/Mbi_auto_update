# V3.3.06 — 재료 확보 후 제작대 제작 연결

- 마지막 부족 재료 확보를 새 재고로 확인하면 부족 재료 팝업 검사 전에 재료 확보 단계를 종료합니다.
- 퀘스트는 한 번만 눌러 제작대로 자동 이동하며, 이미 제작하기 상세창이 열렸으면 추가 입력 없이 이어갑니다.
- 제작하기 문구와 활성 버튼을 두 화면에서 확인해 제작하러 가기와 구분합니다. 클릭 직전 최신 버튼 상태 확인 후 제작하기를 클릭합니다.
- 기존 제작 수량을 유지하며 품목명과 재료를 중복 OCR 검사하지 않습니다.
- 실제 제작 완료창 확인과 수령 검증을 유지합니다.
- Windows 빌드와 회귀 검사 후 배포합니다. 실제 게임 검증은 배포 후 필요합니다.
- 이전 버전 복구는 포함된 ROLLBACK_PREVIOUS.cmd를 사용하세요.
