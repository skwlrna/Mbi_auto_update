# Mabi Auto V3.2.57 — 다중가공 설비 이동버튼 배경 오인식 수정

> **실게임 검증 전 사용자 요청에 따른 정식 배포입니다.** PR #285의 화면 통합 및 Windows CI 검증은 통과했지만 실제 게임의 자동 이동·현장 가공 완료, 설치 및 롤백은 확인하지 않았습니다.

## 수정 사항
- 현장 가공창의 가죽·금속 배경을 원격 `설비로 이동` 버튼으로 잘못 인식하여 300초 정지하던 경로 수정
- 기존 색상·형태 증거에 버튼 중심의 위·아래 배경 대비(동일 열) 경계를 추가
- 실제 원격 이동 버튼은 유지하고, 파란 수령 버튼·평탄한 배경·단조 그라데이션은 배제
- 도착 판정 시 기존 클릭 이후 변화·현장 X·CLI 유휴·팝업 없음·안정화 요건 유지
- 진단 로그에 상하 경계 비율과 도착 차단 이유 추가

## 검증과 한계
- PR #285: Check V3 Production Engine, Managed K HUD 화면 통합 검사(310개), Abyss + Altering Scheduler Validation 통과
- 2026-10-23 가죽+·강철괴 오류 원본, 2026-10-07 원격 목재 버튼과 합성 부정 사례 회귀 통과
- 기존 V3.2.55 전용 후보 워크플로의 실패는 현재 버전이 V3.2.55가 아니어서 발생한 불일치이며, V3.2.57 배포의 통과 근거로 사용하지 않음
- 테스트에 사용한 오류 이미지는 개발 시점에 알려진 자료이며, 신규 게임 화면에서의 정확도는 별도 확인 필요
- **실제 게임의 장거리 이동·가공 완료·사용자 PC 자동업데이트 및 롤백은 미검증**
