# MabiAuto V3.2.35 — 중간관리자 CLI 자동복구 정밀화

## 개선 사항
- 같은 작업 단계에서 **동일 재료를 동시에 읽는 CLI 조회**를 각각 순서 번호로 구분합니다. 더 최신 재료 조회가 시작된 뒤 뒤늦게 도착한 오래된 응답은 반환값이나 진단 장부에 반영하지 않고 폐기하며, 기존 안전 정지 경로에 전달합니다. 서로 다른 재료를 동시에 조회하는 것은 그대로 허용합니다.
- 가공·채집·제작 중간관리자의 공통 CLI 읽기 전용 조회에 대해 단계별로 요청 수, 실제 CLI 시도 수, 일시 오류 후 복구 성공 수, 최종 실패 수, 같은 재료의 늦은 응답 폐기 수를 집계합니다.
- 단계가 전환되거나 무효화되기 직전에 집계만 진단 로그에 출력하고, 재고 증거와 통계는 함께 초기화합니다. 민감한 원시 패킷/CLI 페이로드는 기록하지 않습니다.
- 일시적 CLI 오류는 기존 **300ms 뒤 최대 1회 읽기 전용 재조회**만 허용합니다. 조회 시도 중 단계 변경이나 F10 취소가 발생하면 같은 단계의 재조회 및 결과 저장을 금지합니다.
- 잘못된 재고 값, 상태 충돌, 영수증 미확인, 화면 입력 실패를 단순 전송 오류로 오판하지 않습니다.

## 그대로 유지하는 안전 장치
- 실제 클릭, 제작 수행, 채집 시작/정지, 가공 등록, 일괄 수령, F05 장부/소비 기록에는 이번 통계나 조회 재시도를 적용하지 않습니다.
- 기존 V3.2.33 중복 실행 차단, V3.2.34 장시간 채집·시설 정체 감시, F10 정지, 0 정령의 날개, AI 자동수정 승인/롤백 정책을 유지합니다.
- 원시 패킷 종류·구조가 확인되지 않은 부분은 추가 구현하지 않습니다.
- 장부의 재고 증거는 화면 입력을 승인하지 않는 진단용입니다.

## 회귀 테스트와 출고 조건
- 동일 재료 겹친 조회, 다른 재료 독립 조회, 늦은 응답 폐기, 일시 오류 1회 복구 집계, 의미 오류 미재시도, 단계별 통계 초기화, 단계 전환 중 오류 재조회 차단 테스트를 추가합니다.
- Windows CI 및 어비스·가공 스케줄러 회귀 테스트를 통과한 뒤 main에 병합하고, 메인 CI가 성공한 커밋에서만 V3.2.35 정식 업데이트 파일을 게시합니다.
- 실제 게임 장시간 동작과 사용자 PC 설치 성공은 별도 현장 검증이 필요합니다.
