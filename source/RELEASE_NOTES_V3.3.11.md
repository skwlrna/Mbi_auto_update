# Mabi Auto V3.3.11 — 음식 재료 확보 단계 오류 수정

- 등록 음식의 CLI 재료 확인 경로에서도 ReadQuest 단계를 기록합니다. 퀘스트 생성 후 양배추 확보 진입 시 CreateQuest → AcquireMaterial 오류로 복구를 반복하던 문제를 수정합니다.
- 채집 후 재확인·중간재 처리 후 재확인·제작대 이동이 기존 단계 규칙을 따릅니다. 재료가 충분한 직접 제작 경로는 기존 Travel 단계를 유지합니다.
- V3.3.10의 가방/보관함 합산과 1회 이상 소량 제작 정책은 유지합니다.

검증: 실제 컴파일된 CraftingScreen 진입 경로에 취소된 재고 조회를 주입해 생성 후·채집 후·중간재 처리 후 단계, 제작대 이동 및 직접 제작 경로를 검사합니다. 제작 회귀, Windows CI 및 배포 실행 검사를 통과한 코드로 공개합니다.
실제 게임 자동화 구동 검증은 미실시이며 기존 수동 롤백 기능을 유지합니다.
