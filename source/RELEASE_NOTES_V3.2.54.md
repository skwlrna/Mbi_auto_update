# Mabi Auto V3.2.54 — 가죽 다중가공 재귀 제작 개선

> **사용자 요청에 따라 실게임 검증 전 배포하는 버전입니다.** Windows CI와 모의 제작 테스트는 통과했지만, 실제 마비노기 모바일에서 가죽→가죽+→상급 가죽 자동 제작과 사용자 PC 롤백을 실행해 검증한 결과는 아직 없습니다.

## 변경 사항
- 가죽+ 제작 중 일반 가죽이 부족하면 하위 가공 제법을 확인한 뒤 일반 가죽부터 제작하고 수령한 다음 가죽+ 제작을 재개합니다.
- 상급 가죽 제작 중 가죽+가 부족하면 기존 재귀 제작 스케줄러를 이용해 가죽+와 필요한 하위 가죽을 순서대로 제작합니다.
- 생가죽 계열(생가죽, 상급 생가죽 등) 및 타닌 가루는 부족해도 자동 채집·구매하지 않습니다. 해당 가죽 품목을 목표 미달로 종료하며, 이미 등록한 작업은 안전 수령 대상으로 유지합니다.
- 한 번의 등록에 필요한 재료부터 확인합니다. 다중가공 목표 전체량을 시작 전에 강제하지 않습니다.
- 다른 독립 가공 시설의 작업과 기존 완료/중단 상태 장부를 보존합니다.

## 검증과 제한
- GitHub Actions Windows CI: 생산 엔진, 자동가공, 스케줄러, Windows 후보 빌드 모두 통과.
- 가죽 → 가죽+ → 상급 가죽은 **테스트용 모의 제법과 재고**를 사용하는 회귀 테스트를 통과했습니다. 실제 게임 CLI 재료수량이나 게임 실동작의 입증이 아닙니다.
- 실게임 테스트와 실제 PC 업데이트/롤백 검증은 **미완료**입니다.
- 게임 매크로와 AI 감시 기능을 중지하고, 프로그램 설치 폴더 및 실행 기록을 별도로 백업한 다음 업데이트하세요. 실패 시 제공되는 `ROLLBACK_PREVIOUS.cmd`를 이용할 수 있지만 사용자 PC에서 검증된 것은 아닙니다.
