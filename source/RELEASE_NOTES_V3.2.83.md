# Mabi Auto V3.2.83 — 일반 필드의 수령 화면 오인 수정

- 장면 분류에서 보상 색상과 초록 확인 버튼을 함께 요구합니다.
- 수령·장부·등록·클릭 동작과 화면 우선순위는 변경하지 않았습니다.
- 확인 버튼 없는 보상 색상 화면을 거부하고 정상 결과창은 유지하는 회귀 검사를 추가했습니다.

실제 오류 이미지의 최종 WorldHud 판정 재생과 실게임 확인은 아직 미완료입니다. 정확한 main CI와 패키징·실행·체크섬 검증 후 게시합니다. 문제가 있으면 ROLLBACK_PREVIOUS.cmd로 복구할 수 있습니다.
