# Mabi Auto V3.2.60 — AI 자동수정 사진 근거·검토 사유 표시 (PR #294)

> 사용자 요청에 따라 배포하는 정식 업데이트입니다. Windows CI는 수행하지만, 실제 사용자 PC에서의 Codex 사진 처리·자동 코드 수정·게임 해결·롤백 성공은 검증되지 않았습니다.

## 변경 사항
- `AI 오류 관리`에서 **검토 필요**의 원인을 자동 집계하여 표시: 코드 미수정, 회귀 테스트 근거 부족, 기존 실패안, 분석 중단 등
- 오류 목록 개별 항목에도 검토 사유를 표시하고, 검증이 완료되지 않은 AI 수정안을 해결 완료로 취급하지 않음
- **별도 명시 동의**를 받은 경우에만 향후 새 오류의 게임 화면 PNG 1장을 로컬에 보관하고, Codex `exec --image` 분석에 전달. 초기값은 OFF
- Codex 실행 전에 동의를 다시 확인하며 외부 MCP·임의 경로·링크·손상된 이미지·과대 파일을 첨부하지 않음
- `agent_no_patch` 상태의 미해결 기록은 개별 선택 및 명시 승인을 받아 1회만 다시 분석 가능. 과거 기록·오류 증거를 덮어쓰지 않음
- 실패했던 실제 소스 탐색 경로 안내를 추가해 코드가 존재하지 않는다는 잘못된 추정을 줄임
- AI 분석 및 수정 결과는 별도 작업 공간에서 검증되며 앱·게임에 자동 적용하거나 PR을 자동 병합하지 않음

## 안전성·검증
- Windows 앱 컴파일, 스케줄러/가공 및 화면 회귀 테스트, Python 자동수정기 회귀 테스트를 CI에서 확인하도록 함
- 실제 PC에서 Codex 인증/사용량, 스크린샷 캡처·전송, 오류 자동 코드수정, PR 생성, 게임 동작, 업데이트/롤백 성공은 **미검증**
- 사진에는 캐릭터명/채팅 등 화면 정보가 포함될 수 있음. `AI 오류 관리 → 고급 → 오류 사진을 Codex에 전달` 설정은 처음엔 OFF이고 언제든 끌 수 있음
- 기존 61건은 저장된 이미지가 없는 상태라면 자동 복구/해결되지 않음

## 업데이트 및 복구
- 진행 중인 매크로를 중지하고 설정 및 작업 장부를 백업한 후 업데이트
- 문제가 생기면 배포 ZIP에 동봉된 `ROLLBACK_PREVIOUS.cmd` 또는 [V3.2.59](https://github.com/skwlrna/Mbi_auto_update/releases/tag/V3.2.59) 패키지로 복귀 가능. 실제 PC 복귀 성공은 검증되지 않음
