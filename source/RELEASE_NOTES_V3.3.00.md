# Mabi Auto V3.3.00 — 약품 F07 / 음식·아이템 제작 버튼 검증 개선

배포일: 2026-11-07 (KST)

## 변경 사항

- **약품 가공**: V3.2.99의 검증된 Enter 검색 → 검색 필터 적용 → 단일 카드 2회 확인 → 첫 카드 (218,412) → 상세창 진입 경로를 유지합니다. 이 선택이 확인된 같은 작업에 한해서 F07 및 최종 N01의 **중복 제법명 OCR**을 생략합니다.
- **가공 안전장치 유지**: 등록 직전 상세창 확인, 원격 가공 차단, 무료 버튼 색상/좌표 안정성, 2개 연속 새 화면 확인, 최종 최신 화면 클릭 전 확인, 관리자의 CLI 상태 확인, 실제 등록 CLI 확인 및 중복 등록 방지는 유지합니다. 검색 기록은 다음 품목을 선택할 때 무효화합니다.
- **음식·아이템 제작**: 제작대의 `제작하기` 텍스트를 OCR로 읽어야만 Space를 누르던 하드 게이트를 제거합니다. 고정 버튼 영역의 청록/녹색 버튼 형태를 **연속 2프레임** 확인하고, CLI 조회 후 **입력 직전 새 화면**에서 재확인합니다. 누락/회색/위치 이탈은 Space 없이 대기합니다.
- **변경하지 않음**: 음식 첫 검색 결과 (218,613), 약품 첫 검색 결과 (218,412), 검색 Enter → 붙여넣기 → Enter → Space, 재료·수량·완료 재고 확인, 다른 고정 가공 제법 선택 및 시설 소유권.
- **테스트**: 실제 프로덕션 어셈블리를 대상으로 화면 버튼 픽셀 양성/음성, OCR 의존 제거, 검색/안전 회귀 및 Windows 패키지 빌드 검사.
- **실게임 확인 상태**: 이 버전의 배포 전 현장 재현 테스트는 아직 진행되지 않았습니다. 실행 후 오토로그에서 F07 제법 이름 재검증 오류가 사라졌는지, 음식·아이템 제작에서 2프레임+최종 픽셀 검증 이후 Space 입력 및 재고 확인까지 완료되는지 확인하십시오.

## 복구 및 롤백

Windows Lite ZIP의 `ROLLBACK_PREVIOUS.cmd`, `tools/RollbackPrevious.ps1`를 통해 이전 버전으로 되돌릴 수 있습니다. 배포는 메인 CI 통과, EXE 스모크 테스트, SHA256 및 ZIP 검증 후 공개합니다.
