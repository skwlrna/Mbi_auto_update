# Mabi Auto V3.2.61 — 가공 시설 전환 안정화 (PR #296)

## 변경 사항
- 시설 진입 직후 전체 UI 구조가 완성될 때까지 최대 2초 대기하고 연속 두 프레임을 확인합니다.
- 실제 오류 화면을 이용한 회귀 검증을 포함합니다.
- 검증 실패 시 시설 UI의 각 판정 결과를 로그에 기록합니다.
- 검증에 실패하면 설비 이동 클릭을 차단하는 안전 장치를 유지합니다.

## 검증 범위 및 주의
- Windows CI와 바이너리 스모크 테스트 통과 후에만 정식 업데이트를 발행하도록 설정했습니다.
- 실제 게임의 전환 중간 프레임 및 사용자 PC에서의 게임 동작은 아직 검증되지 않았습니다.
- 업데이트 파일은 SHA256으로 검증하며, 기존 롤백 스크립트를 포함합니다.
