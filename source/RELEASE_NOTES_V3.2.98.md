# Mabi Auto V3.2.98 — F07 약품 가공 제법/무료 버튼 재검증 안정화

## 오류 근거
2026-11-07 03:45:52 KST, `산뜻 버섯 진액` 약품 가공 상세 화면에서 `F07 관리 제법 제목/무료 버튼 동일성 2회 확인 실패`가 보고되었습니다. 공유된 화면에는 상세 정보, 충분한 재료 및 `가공하기` 버튼이 보이지만 오류 시점의 내부 OCR/좌표 판정 중 어떤 검증이 실패했는지는 원본 진단 로그 없이 확정할 수 없습니다.

## 변경
- F07 관리 가공 등록 전 안전 확인을 **최대 3회 독립적인 2프레임 검증**으로 제한합니다. 각 시도에서 상세 구조, 정확한 제법 정체성, 현장(비원격) 상태, 무료 버튼 시각 검출 및 두 프레임 좌표 안정성이 모두 확인돼야 진행합니다.
- 실패가 발생하면 **입력 없이 새 프레임으로만 재검증**합니다. 실패 프레임을 다른 시도의 성공 증거와 결합하지 않습니다. 두 프레임 검증 성공 후에도 기존 입력 직전 재검증을 유지합니다.
- 매 프레임마다 **상세/제법/원격/무료버튼/좌표/좌표안정** 결과를 기존 로그에 기록합니다.
- 제법명 OCR 실패를 임의의 출력명 별칭으로 완화하지 않습니다. 여러 제법이 동일한 출력물을 가진 경우 기존 식별/정지 정책을 유지합니다.
- F07 단발성 인식 실패 회복, 교대로 한 프레임만 성공하는 상황 차단, 계속 실패할 때 3회 제한 회귀 테스트를 추가합니다.
- F9 다중 가공, 금속 수령, 좌표 최종 확인, 기타 작업 흐름의 기존 안전 장치는 유지합니다.

## 검증·배포·주의
정식 자동업데이트는 메인 SHA 기준 Windows CI 성공, F07 회귀, 실행파일 기동 확인, Windows ZIP SHA256·원본·백업·롤백 확인 후에만 공개합니다. 배포된 앱은 게임 속 실행과 완전히 별개의 단계이며, **실제 게임에서 F07 오류가 해결되었다는 보장은 아직 없습니다.** 재발하면 F07 항목별 로그를 사용해 정확한 실패 조건을 수정해야 합니다. 기존 작업을 강제로 종료하지 않습니다.
