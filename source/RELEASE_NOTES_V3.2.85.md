# Mabi Auto V3.2.85 — 11월 3일 통합 수정

V3.2.84 이후 통합 PR: #354, #358, #359, #360, #361, #363.

- 다중가공 WinRT OCR 동시 실행을 직렬화하고, 알리사 출석부와 NPC 화면이 겹친 경우 확인된 '출석부 건너뛰기'를 한 번 누른 뒤 닫힘을 검사합니다.
- 일반 필드 K/I/Space 보조 인식을 추가하되 던전 밖 CLI, 메뉴/팝업 차단, 두 프레임 및 입력 직전 재검증을 유지합니다.
- 어비스 '다시 하기' 후 경쟁 미션 완료 확인창은 시각 증거와 OCR을 검증해 확인을 한 번 처리하고, 파티 모집/던전 재입장 대기는 시간 제한 없이 유지합니다.
- 가방 무게 90% 이상이면 신규 채집만 시설별로 보류하고 다른 시설의 기존 가능한 가공을 계속합니다. 보류 장부의 정확한 증거 검사도 추가했습니다.
- 빈 병이 필요한 우유/물 채집은 사전 재고를 확인합니다. 정확히 확인된 빈 병 부족 팝업은 ESC 후 일반 필드와 정지 상태를 검증해 해당 품목만 보류하고 다른 작업을 진행합니다. 자동 구매/폐기하지 않습니다.
- 제작 OCR만 실패했고 실제 제작 출력이 0인 경우에는 정상 제작 1종 이후 오류 품목 1종을 재시도하며, 남은 오류 품목은 30초 간격으로 순환합니다. 미확정 제작 작업은 기존처럼 안전 정지합니다.
- 중복 대안 PR #355~#357 및 #362 전체는 포함하지 않았습니다. #359의 보류 기록 검증은 #360 통합 수정에 추가했습니다.
- 요청대로 12번 하단 제작 탭 인식 변경은 제외했습니다.

Windows CI / 배포 빌드 검증과 실게임 검증은 별개입니다. 실제 게임의 클릭·인식 안정성은 아직 확인되지 않았습니다. 문제가 있으면 ROLLBACK_PREVIOUS.cmd로 이전 버전 복구가 가능합니다.
