# V3.3.29

다중가공(F9) 상급 가죽의 제법 CLI 재료 수량과 실제 get_items 수량이 불일치하고, 이미 등록된 3개 작업 중 일부가 진행 중인 경우, 기존에는 그 배치를 기다리는 동안 다른 시설까지 등록 및 수령이 지연되었습니다.

V3.3.29는 재료 불일치 시 가죽 시설의 신규 등록을 금지하고, 확인된 기존 작업을 유지한 채 다른 독립 시설에 F9 제어권을 반환합니다. 약품과 목재는 기존 검증 후 신규 등록하고, 금속 및 식재료는 기존 전체 완료/수령 검증을 그대로 따릅니다. 진행 중 가죽 작업이 모두 끝나면 기존 전체 배치 수령 로직을 거쳐 재고와 제법을 다시 확인합니다.

중간재료 시설 소유권, 부분 완료 수령 금지, 중복 클릭 방지, 원재료 소진 확정 금지, F9 수령 장부 및 자동 업데이트 롤백을 유지합니다. 시험 항목에는 상급 가죽 1완료+2진행 작업 시 즉시 독립 시설로 양보하는 실제 자동가공 코드 회귀가 포함됩니다.

**테스트:** Windows CI 및 오프라인 회귀 테스트 통과 후 공개. 실제 게임 동작 검증은 업데이트 이후 필요합니다.
