# Mabi Auto V3.2.31 — 중간관리자 공통 상태 전환·신선도 검증

가공·채집·제작은 기존 중간관리자 연결을 그대로 유지합니다. 중복 관리자나 CLI 쓰기 명령을 추가하지 않습니다.

- 동일 실행 범위의 `LifeSkillManagerState`가 가공 ↔ 채집, 제작 ↔ 채집, 제작 ↔ 중간가공 전환 시 이전 CLI 재고 관측을 폐기합니다.
- 재료 채집 전/후 및 중간가공 전/후의 재고는 기존 읽기 전용 CLI를 매번 새로 조회합니다. 오래된 관측·잘못된 작업 단계·조회 도중 전환된 응답·음수 수량은 안전한 근거로 사용하지 않습니다.
- 단독 채집 시작·완료에도 공통 조회와 진단 로그를 적용합니다. 제작 퀘스트 채집 완료 후 화면 부족분 검증은 종전대로 수행합니다.
- 상태 전환은 관측 기록일 뿐 입력 권한이 아닙니다. 클릭, 수령, 중간재료 등록은 기존 화면·CLI·시설 소유권 검사에 따릅니다.
- 아직 실제 수신 구조가 검증되지 않은 원시 패킷 파서는 추가하지 않았습니다. 증거 없는 패킷 데이터로 상태를 확정하지 않습니다.
- 신규 회귀: 가공/채집/제작 단계 전환, 이전 상태 무효화, 신선도 만료, 응답 순서 역전, 음수 수량, F10 폐기. 기존 Windows CI 검증 필수.
- 실제 게임에서의 장시간 실측 성능과 오류율은 별도 테스트가 필요합니다.
