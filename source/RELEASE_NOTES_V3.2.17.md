# MabiAuto V3.2.17 — Codex 자동분석 독립 실행 및 시간별 AI 오류 내역

## AI 분석 시작 차단 해소
- 사용하지 않는 구형 Autofix의 OFF 상태·설치 파일 확인을 제거했습니다.
- 내장 Codex Autopilot은 독립적으로 동작합니다. 중복 실행 잠금, 깨끗한 소스·독립 작업 공간, 제한된 회귀 테스트와 사람의 실제 게임 확인은 유지합니다.
- Python, Git, Codex 또는 .NET SDK 등 준비가 안 된 경우 시작 불가 이유를 한국어로 표시합니다.
- **프로그램을 닫으면 해당 프로그램이 실행한 AI 감시도 함께 종료됩니다.**

## 시간별 AI 오류 내역
- 앱 오류가 발생하면 GitHub 업로드 설정과 관계없이 PC에 발생 일시·오류 종류·짧은 설명·최근 진단 로그 일부를 남깁니다. 스크린샷은 이 AI 로컬 경로에 저장하지 않습니다.
- AI 감시가 켜져 있으면 내장 오류 기록과 외부 MCP 오류를 함께 분석 대기열에 넣습니다. 기존 외부 MCP 이전 오류는 첫 감시 시 건너뛰되, 로컬 앱 오류는 보존 후 처리합니다.
- 기존 **AI 현황** 화면을 **오류 시간별 내역**으로 정리했습니다. 발생 날짜·시각, 이해하기 쉬운 오류명, 상세 오류 내용, AI가 처리한 단계, 다음 할 일, 검토용 수정안이 표시됩니다.
- 전체·오늘·최근 7일 필터와 오류 상세 보기, GitHub 수정안 열기를 지원합니다.
- Codex 사용량 한도, 작업 폴더 없음 등 처리되지 않은 이유를 가능한 범위에서 읽기 쉬운 표현으로 안내합니다.

## 검증 및 배포 안전
- AI가 만든 코드 패치는 검증용 Git 작업 공간에 남으며 무검증 자동 병합, 실행 중인 바이너리 교체, 게임 입력을 수행하지 않습니다.
- 테스트 통과는 **코드 테스트 성공**일 뿐, 실게임에서 오류가 해결됐다는 뜻이 아닙니다.
- 사용자가 승인해야 하는 GitHub 수정안 PR 기능과 기존 수동 실게임 피드백은 유지합니다.
- Windows .NET 빌드·Python AI 테스트·스케줄러 회귀 검사를 통과하고 설치 ZIP·파일 체크섬 검증이 완료된 경우에만 V3.2.17 업데이트를 공개합니다.

**주의:** 시간별 내역의 새 로컬 형식은 이 버전 이후 발생하는 앱 오류부터 기록합니다. 과거 GitHub 전용 오류를 자동으로 내려받지는 않습니다. Codex 분석은 앱 내 AI 감시가 켜져 있고 PC의 필수 개발 도구 및 소스 클론이 준비된 경우에만 시작합니다.
