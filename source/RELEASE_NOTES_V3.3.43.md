# Mabi Auto V3.3.43

- MOBI 대시보드, 사이드바 접기·펼치기, 라이트·다크 테마 및 자동가공·채집·제작·스케줄러 화면 디자인 통일.
- 모바일 브라우저에서 상태 조회, 가공 품목 및 총/추가 수량 등록, 대기열 확인·시작·정지·취소, 어비스 던전 선택 및 시작, 전체 정지를 지원합니다.
- 기존 V3.3.42 환경 변수 접속 키와 텔레그램 명령은 유지합니다. 환경 설정 > 브라우저 원격 제어에서 수동 활성화할 수 있습니다.
- 브라우저는 루프백에만 바인딩하며 휴대폰 접속에는 별도 비공개 HTTPS 연결 설정이 필요합니다. [설정 안내](../docs/MOBI_BROWSER_PREVIEW.md).
- 자동 UI 및 HTTP 모의 명령 검증을 수행합니다. 실제 게임·휴대폰·화면 육안 검증은 아직 수행하지 않았습니다.
- 이전 버전으로 되돌리려면 설치 폴더의 ROLLBACK_PREVIOUS.cmd를 실행하세요.
