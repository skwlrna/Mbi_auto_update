# MabiAuto V3.2.21 — AI 자동수정 단계별 현황 · 텔레그램 결과 알림

## 주요 업데이트

- **AI 오류 시간별 내역의 실시간 진행 단계**: 오류 증거·로그 확인 → Codex 원인 분석 및 로직 수정(한 작업) → 수정 파일 안전 검사 → 빌드·회귀 테스트 → 수정안 검토 순서를 표시합니다. 테스트 실패 시 별도 격리 재수정 단계도 표시하고, 현재 단계 경과 시간을 갱신합니다.
- **AI 작업 상태 텔레그램 알림**: 오류 분석 시작, 코드 테스트 통과(운영 미적용), 검토 필요, 테스트 실패 및 안전 차단에 대해 기존 텔레그램 봇으로 메시지를 전송합니다.
- **명시적 수신 동의**: 텔레그램 설정의 `AI 자동수정 시작·성공·실패 알림` 체크박스가 기본 꺼짐이며, 켠 경우에만 발송합니다. 기존 일반 텔레그램 알림 설정은 그대로 유지합니다.
- **개인정보 보호**: 텔레그램에는 안전하게 검증한 오류 식별자, 미리 정의한 상태·실패 분류만 전송합니다. 게임 화면 스크린샷, 원본 로그, Codex 출력, 작업 파일 내용은 AI 결과 알림에 포함하지 않습니다.
- **기존 V3.2.20 보존**: 목재 가공 정체 감지, 소스 SHA 일치, 격리 worktree 및 자동수정 금지 정책에 변경이 없습니다. AI 오류 수정안의 자동 병합, 운영 EXE 자동 교체, 실제 게임 입력은 수행하지 않습니다.

## 검증

- V3.2.20 기반 기능 PR #223에서 Windows 빌드와 기존 생산 엔진 및 어비스·가공 스케줄러 CI가 모두 통과했습니다.
- 본 V3.2.21 버전은 **메인 브랜치 CI가 성공한 현재 커밋**에서만 자동 릴리스되도록 보호합니다. EXE 파일 버전, ZIP 내 BUILD_COMMIT.txt, 필수 배포 파일, SHA256 검증을 만족해야 합니다.
- 오프라인 테스트와 CI 성공은 실제 PC의 Python/Git/Codex 연결 또는 실제 게임 오류 해결을 증명하지 않습니다.

## 설치 후 확인

1. 실행 파일 버전 `3.2.21.0` 및 패키지 최상위 `BUILD_COMMIT.txt`를 확인합니다.
2. 텔레그램 알림을 받으려면 기존 텔레그램 설정에서 별도 AI 알림 체크박스를 선택합니다.
3. AI 오류 관리 → AI 분석 시작 → 오류 시간별 내역에서 단계별 현황을 확인합니다.
4. 새 오류 한 건을 대상으로 단계 표시, Codex 실제 실행, 텔레그램 시작/종료 알림을 실환경에서 검증합니다.
5. 매크로 종료 시 자식 AI 감시도 함께 종료하며, 과거 분석 결과·worktree 및 롤백 파일은 보존합니다.
