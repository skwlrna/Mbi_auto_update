# Mabi Auto V3.2.73 — 가공 화면 오인식 차단·호박 수프 재료명 복원

- **F9 다중가공 방어구 화면 오진입 차단.** 기존 고정좌표로 가공 시설 카드를 선택하기 전 800×1000 6카드 구조에 더해 K 생산 메뉴의 독립적인 하단 3개 글자 영역과 활성화된 청록색 '가공' 탭을 반드시 검증합니다. 다른 제작 탭이거나 모호한 화면은 추가 클릭 없이 안전 정지합니다.
- **호박 수프의 재료명 OCR 누락 보완.** 음식 퀘스트에서 기존에 명시적으로 확인한 부족 재료의 이름·수량과 최신 CLI 가방 재고가 *유일하게* 일치할 때만 회색 재료명 누락을 복원합니다. 실제 사례: 감자 8/60과 양파 6/60 확인 → 감자 66/60 확보 → 재료명 없는 6/60 행을 양파로 재확인합니다.
- 이름이 불명확한 부족 행이 여러 개, 수량 변경, 재고 불일치, 퀘스트 재생성 등 신원 검증이 불가능하면 임의 추천 획득처를 클릭하지 않고 해당 음식만 건너뜁니다.
- 기존 가공 시설 **고정좌표**, K 입력 전 독립 필드 증거, 다중 가공 슬롯/수령·재등록 장부 및 순차 제작의 건너뛰기 동작을 유지합니다.
- Windows Lite 자동업데이트 ZIP과 SHA256, 소스 ZIP 및 롤백 도구를 제공합니다. **실행 중인 매크로를 강제로 종료하거나 교체하지 않습니다.**

**검증:** PR #337의 Windows CI 4/4 통과 및 122개 제작 회귀, 468개 실제 화면 기반 검증. 최종 V3.2.73 메인 커밋에 대해 다시 전체 빌드·회귀 검사, 실행 파일 스모크 테스트, 압축 패키지·체크섬 검사를 통과해야 공개됩니다. 실제 게임에서의 동작 확인은 별도입니다.
