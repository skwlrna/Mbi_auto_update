# Mabi Auto V3.3.13 — 이벤트 메뉴 어비스 인식 수정

- 2026-11-12 16:28:47 오류: 열린 우측 메뉴에서 어비스 아이콘을 60초 내 확인하지 못한 문제의 좌표 검증을 보정했습니다.
- 이전 기본 메뉴(어비스 ~315, 길드 ~575)와 이벤트 배너 메뉴(어비스 ~450, 길드 ~720)를 각각 인식합니다.
- OCR의 길드 보조 검증은 어비스와 동일한 메뉴 배치에서만 허용합니다. 서로 다른 메뉴 배치의 2프레임을 연결하지 않습니다.
- 템플릿의 제한 검색 영역과 허용 배율을 조정하고 검출 원본 진단을 추가했습니다. 좌표 고정 클릭 없이 기존 2프레임·다음 화면 확인을 유지합니다.
- 음식 제작·다중가공·스케줄러 로직은 수정하지 않았습니다.

검증: 양쪽 메뉴 배치와 다른 행/교차 배치 차단 회귀. Windows CI와 릴리스 빌드 검증을 필수로 합니다. 실제 게임 구동 검증은 미실시이며 롤백 기능은 유지합니다.
