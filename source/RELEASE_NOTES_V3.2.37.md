# MabiAuto V3.2.37 — 복구 결과 측정 및 AI 피드백 연계

## 변경사항
- 가공·채집·제작 중간관리자의 읽기 전용 CLI 재조회 결과를 계측합니다.
- 완료된 조회의 복구율은 **재조회 뒤 새 응답 확인 / (새 응답 확인 + 재조회 소진)** 입니다. 미완료 건은 제외하고 확정 사례가 없으면 비율을 표시하지 않습니다.
- 제작 및 채집 등 결과가 미확정인 게임 작업은 CLI 복구율에 포함하지 않습니다.
- 오류 패턴 상세 기록은 24개로 제한하면서, 누적 복구 통계는 기록 교체 뒤에도 유지합니다.
- F9 로컬 진단 스냅샷에 읽기 전용 복구 지표와 실게임 수정률 측정 불가 표시를 추가합니다.
- 기존 AI 오류 이력에는 사용자 직접 해결 확인, 재발 보고, 미확정 사례의 요약을 첨부합니다. 명시적으로 확인된 평가만 별도 비율 계산에 사용합니다.

## 안전 경계
- 재조회 통계나 AI 이력만으로 화면 입력, 가공 등록·수령, 코드 수정 병합 및 배포를 자동 승인하지 않습니다.
- 기존 F9/F05 장부, F10 정지, 중복 실행 금지, 롤백 기능을 유지합니다.
- 이번 수치는 전체 게임 작업 완료율이나 장기 장애 재발률이 아닙니다. 정확한 게임 성과는 검증된 현장 데이터가 추가로 필요합니다.

## 테스트 및 출고
- 회귀 테스트: 종료된 조회의 성공률, 미완료 건 제외, 미확정 작업 분리, 누적 통계 유지, F9 진단, AI 사용자 피드백 구분.
- Windows PR CI 및 병합 후 main CI 통과 시 자동업데이트용 정식 릴리스를 게시합니다.
