# Mabi Auto V3.2.87 — F9 필드 인식 K·I·Space 단일화

이 버전은 V3.2.86 이후 병합된 PR #371의 다중가공(F9) 필드 인식 일관성 수정을 포함합니다.

- **필드 인증**: 지정된 하단 K 글리프와 I 글리프(각 매칭 임계값 0.90), 하단 중앙 Space 글자의 정확 OCR을 유일한 필드 이미지 증거로 사용합니다.
- **사전·최종 확인 통일**: 서로 다른 실제 화면 2프레임에서 K·I·Space를 확인하고, K 입력 직전에 새 화면에서도 같은 기준을 적용합니다.
- **이전 인증 경로 제거**: F9 필드 인증에 한해 Home·End·ESC, 과거 HUD 3/4 및 낡은 K/I 아이콘 템플릿을 필수/대체 조건으로 사용하지 않습니다. 어비스 퇴장 등 다른 기능에서 사용하는 이미지 자산은 유지합니다.
- **입력 안전 유지**: 던전 밖 CLI 및 안전 대기, 가공 메뉴·시설·확인창·결과창 감지, 입력 직전 화면 변경 시 무입력 정지, 기존 배치/수령 장부 및 재시도 정책을 유지합니다. 불확실한 화면에서는 K 입력을 강행하지 않습니다.
- **포함된 이전 기능**: V3.2.86의 다중가공·제작 장기 대기 진단/알림과 기존 어비스/제작 안정화 기능을 유지합니다.

## 검증과 한계

PR #371의 Windows 빌드, 오프라인 회귀 테스트 및 관련 GitHub CI 7개가 통과했습니다. 본 정식 릴리스도 **정확한 main SHA의 종합 Windows CI 성공**, 앱 실행 파일 스모크 테스트, 실행 ZIP 및 소스 ZIP, SHA256, 롤백 파일 확인을 모두 통과해야 공개됩니다.

**실제 게임 조작 및 실게임 장시간 테스트는 하지 않았습니다.** 배포 후 사용자가 동일한 ESC→필드→K 재진입 상황을 관찰해 실제 개선 여부를 확인해야 합니다.

## 설치 및 복구

공식 Windows Lite ZIP을 사용합니다. 실행 중인 프로그램을 강제로 업데이트하지 않으며, 문제가 있으면 설치 ZIP의 `ROLLBACK_PREVIOUS.cmd` 또는 `tools/RollbackPrevious.ps1`로 이전 버전으로 복구할 수 있습니다.
