# MabiAuto V3.2.32 — 중간관리자 안전 CLI 조회 자동 복구

## 기존 중간관리자 통합 개선
- 가공, 채집, 제작이 사용하는 동일한 `LifeSkillManagerState`에 공통 읽기 전용 CLI 조회 복구를 추가합니다.
- 일시적 네트워크 및 CLI 조회 오류(`TimeoutException`, `IOException`, 연결 오류, HTTP 408/429/500/502/503/504)에 한해 **300ms 뒤 최대 한 번** 다시 조회합니다. 실패가 계속되면 기존 예외를 보존하고 안전 정지합니다.
- 재시도 직전과 최종 결과 저장 전에 **작업 단계·epoch**를 재확인합니다. 채집 중 가공 또는 제작 단계로 이동했다면 늦게 도착한 응답은 즉시 폐기하고 다음 작업을 시작하지 않습니다.
- 제작 제법/중간재료 확인, 채집의 일반 상태·목록·무게·재고 조회, 가공 시설별 대기열/제법/선행 재료 조회에 읽기 전용 공통 복구를 연결합니다.
- 로컬 로그에 조회 복구 성공 또는 중단 유형을 구분해 기록합니다. 오류 상세 문자열은 자동 복구 로그에 기록하지 않습니다.
- 의미가 확정되지 않은 원시 패킷은 추가하지 않았습니다.

## 엄격한 안전 범위
- 게임창 클릭, 제작 실행, 채집 시작/정지, 가공 등록, 배치 수령, 장부 저장, 화면 입력과 상태 전환 전체에는 자동 재시도를 적용하지 않습니다.
- `InvalidDataException`, `InvalidOperationException`, 음수 인벤토리 값, 검증되지 않은 불일치/재료 부족, F10 중단은 재시도하지 않습니다.
- 중간관리자에서의 부분 복구는 읽기 전용 조회에 한정하며, 기존 제작 퀘스트 별도 3회 복구나 AI 수정안 승인 장치는 유지합니다.
- 회귀 테스트는 정상 재조회/2회 실패/상태 불일치/음수 재고/epoch 역전/F10 취소를 포함합니다.

## 검증 및 배포
- Windows 실행 파일, N02/F05 회귀, 자동가공·채집·제작, 기존 AI watcher 및 UI/어비스 3종 CI 통과 후에만 메인 병합 및 공개 자동업데이트를 수행합니다.
- 실제 게임 장시간 테스트와 사용자 PC 업데이트 설치 성공은 별도로 확인해야 합니다.
