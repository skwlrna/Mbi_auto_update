## 이번에 구현한 기능
1. 투창병: 플레이어 속성 표식과 소환 몬스터 표식 일치 시 후보 계산.
   해당 플레이어가 투창 표적인지 확인하기 전엔 키 입력 불가.
2. 송곳니: 파도 방향과 대응 포탈을 확인. 포탈 재사용 가능 여부가
   추가로 확인되지 않으면 키 입력 불가.
3. 테로사: 3x3 O/X/빈칸 완전 인식 후, 즉시 이기기 > X 막기 >
   minimax(다음 수 포함)로 O 수 추천. 침수/불안전 발판 제외.
   게임 내 표적 표시 및 안전한 빈칸이 확인되지 않으면 키 입력 불가.
   경기 종료/비정상 보드/강제 패배 상태는 이동하지 않음.
4. 승천: 보호막 및 금색 안전 지대 별도 감지.
   공격/브레이크는 기존 자동전투에 맡기고, 금색 안전 지대 이동은
   정확한 진입 타이밍과 실제 키 경로가 모두 설정되어야 허용.

## 시작하기 전에 필요한 실제 게임 자료
- 게임 클라이언트 화면을 기존과 같은 800x1000 크기로 녹화
- 1번방: 투창 대상 표식과 몬스터 속성 아이콘이 함께 보이는 프레임
- 2번방: 파도 방향, 포탈 위치, 재사용 가능/불가 표기가 보이는 프레임
- 3번방: O/X/빈칸으로 구성된 3x3 보드 및 침수된 타일
- 승천: 보호막 구간, 금색 안전 지대, 이동 가능한 순간
- 캐릭터 키 이동(직업/시점/카메라/이동 시간) 캘리브레이션

## 설정
파일: abyss/config/waterway_mechanics.json
기본값: Enabled=false, ObserveOnly=true, AllowKeyboardActions=false

- 먼저 실제 PNG 템플릿을 준비하고 Roi와 CellRois(상단 좌측부터 총 9칸)를 설정
- Enabled=true, ObserveOnly=true, AllowKeyboardActions=false 로 관찰 로그 검증
- 입력은 세 옵션의 의도적인 변경 및 움직임/표적/안전 구역의
  신뢰 가능한 화면 근거가 있을 때만 실행됨
- KeysByMark, KeysByWave, KeysByCell, KeysToGoldZone은 모두 빈 배열;
  W/A/S/D/SPACE 중 실제 검증된 입력만 사용하도록 설정
- F10 즉시 중단, 2연속 화면 확인, 유효한 게임 창 800x1000 검사 재사용
- 다른 던전 선택 시 기능 무효, 기존 UI·가공·낚시·채집 변경 없음

### 주의
- 파일명은 템플릿을 준비할 위치의 예약 이름일 뿐이며, 파일 자체는
  포함하지 않습니다. **기믹 자동 파훼가 완성된 상태가 아닙니다.**
- 6번째 표식은 공략마다 '정신/저주' 등 표기가 다릅니다.
  unknown_sixth로 남겨 실제 화면에서 이름/모양을 확정합니다.
- 공략상 1차/2차 투창과 승천 HP·시간 수치는 파티/난이도마다
  차이가 있을 수 있어 키 입력 타이밍에 하드코딩하지 않습니다.
- O/X 의사결정은 일반 3목 게임의 근사 모델입니다.
  보스가 두는 방식이나 타겟 순서가 다른 경우 실전 검증 후 수정해야 합니다.
- 공개 제3자 코드를 단순 복사하지 않고 확인된 규칙을 독립 구현했습니다.
