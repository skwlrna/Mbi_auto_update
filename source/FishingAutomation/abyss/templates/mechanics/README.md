# 흩어진 물길 기믹 대응 v1 (실화면 캘리브레이션 필요)

기존 게임 자동전투는 그대로 두고, 어비스 클리어 대기 단계에서만
표식 / 파도 / 3x3 O 발판 기믹을 감지합니다. 기존 낚시·채집·가공·UI는 변경하지 않습니다.

## 현 상태
- 실제 게임 프레임으로 검증되지 않은 프로토타입입니다.
- 기본값 Enabled=false, ObserveOnly=true이므로 입력은 절대 실행되지 않습니다.
- 네트워크 패킷 해독이나 게임 메모리 읽기는 구현하지 않았습니다.
- 자동 플레이는 게임 운영정책상 제한될 수 있습니다.

## 설정 방법
1. 게임 화면을 기존처럼 800x1000으로 고정합니다.
2. abyss/templates/mechanics/ 폴더에 실제 게임 화면에서 캡처한 PNG를 넣습니다.
3. abyss/config/waterway_mechanics.json 의 템플릿 파일명을 맞춥니다.
4. Board.CellRois를 위 왼쪽부터 오른쪽으로 0~8번 순서로 총 9개 입력합니다.
   각 칸의 O, X, 빈칸을 각각 시각적으로 구분해 분류해야 합니다.
5. Enabled=true, ObserveOnly=true 상태로 먼저 인식 로그만 검증합니다.
6. 검증된 이동 시퀀스를 KeysByMark, KeysByWave, KeysByCell에 지정한 뒤
   ObserveOnly=false 를 선택하면 제한된 키 입력을 수행합니다.
   입력 허용 키: W, A, S, D, SPACE. 각 시퀀스 최대 8회.
   좌표/키를 임의로 추정해 기본값에 넣지 않았습니다.

## 기믹 판단
- 1번방: 내 표식 하나 + 동일 유형의 몬스터 표식을 모두 볼 때만 선택
- 2번방: 파도 방향 하나 + 사용자 지정 대응 포탈이 모두 보일 때만 선택
- 3번방: 9칸 상태를 빠짐없이 구분하고 O 2칸 + 빈칸 1칸으로
  한 줄 완성이 확인될 때만 해당 빈칸을 선택
- 모두 2연속 화면에서 동일한 결과가 나와야 합니다.
- 같은 화면/보드 상태에서는 중복 입력을 막습니다.
- F10 중단, 게임 포커스 확인, 800x1000 경계 검사는 기존 엔진과 공유합니다.
- 10분 타임아웃, 정상 종료 및 재시작 흐름은 그대로 유지합니다.

## 테스트
dotnet run --project tests/waterway/Regression.csproj

이 프로토타입은 실게임 기믹 완전 자동 클리어를 주장하지 않습니다.
프레임과 이동 데이터가 확보되어야 단계별 성공 증거·이동 보정을 완성할 수 있습니다.
