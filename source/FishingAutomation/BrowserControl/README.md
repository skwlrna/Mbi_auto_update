# 브라우저 가공 조작

PC에서 매크로를 실행한 상태로 브라우저에서 PC 작업 상태를 보고, 품목과 수량을 가공 대기열에 등록할 수 있습니다. `대기열 시작`은 PC와 텔레그램에서도 사용하는 기존 휴대폰 가공 대기열 전체를 실행합니다. `가공 중지`는 휴대폰 대기열에서 실행한 가공을 멈추고 남은 대기 요청을 보관합니다.

## PC에서 켜기

1. 매크로를 실행하는 프로세스에 `MABIAUTO_BROWSER_TOKEN` 환경 변수를 설정합니다. 서로 다른 PC에서 재사용하기 어려운 무작위 영문·숫자 32자 이상을 사용하세요. 변수가 없으면 웹 화면이 꺼집니다.
2. 매크로를 재시작하고 PC에서 `http://127.0.0.1:18765/`를 엽니다. 접속 키는 브라우저 화면에 입력합니다.
3. PC 로그에 액세스 거부가 표시되면 관리자가 일반 실행 계정에 해당 URL만 예약합니다. 관리자 명령 프롬프트에서 `netsh http add urlacl url=http://127.0.0.1:18765/ user="DOMAIN\USERNAME"`의 사용자 이름을 매크로를 실행하는 계정으로 바꿔 실행한 뒤 매크로를 재시작합니다.
4. 휴대폰 접속에는 PC의 루프백 주소로 전달하는 인증된 HTTPS 프록시가 필요합니다. PC와 휴대폰에서 접근 가능한 사설 주소로만 서비스하고, 프록시 업스트림은 `http://127.0.0.1:18765/`로 설정합니다. Windows HTTP 리스너가 요청을 받을 수 있도록 업스트림 Host 헤더는 `127.0.0.1:18765`로 전달합니다. 방화벽에 앱의 포트를 개방할 필요는 없습니다.

접속 키는 브라우저 탭의 메모리에만 유지됩니다. 탭을 새로고침하면 다시 입력합니다. `보유량 포함 목표 수량`은 가방과 창고 보유량을 포함하며, `새로 만들 수량`은 신규 생산량입니다.

## UI 개편 미리보기

새 UI에서는 환경 설정 > 브라우저 원격 제어에서 실행·중지 및 연결 키 발급을 지원합니다. 기존 환경 변수 설정도 호환됩니다. 상세 내용은 [브라우저 미리보기](../../../docs/MOBI_BROWSER_PREVIEW.md)를 참고하세요.
