# Mabi Auto V3.2.86 — 다중가공·제작 장기 대기 진단 안정화

이 버전은 V3.2.85 이후 메인에 반영된 CI 안전장치 PR #367, #369 및
다중가공·제작 장기 대기 알림 PR #370을 포함합니다.

- **다중가공**: 시설별 재료 보류 또는 입력 전 CLI 읽기 격리 상황이 15분 이상 지속되면 시설·품목·원인과 관측 경과 시간을 화면/로그에 1회 표시합니다. 기존에 구성된 텔레그램 알림도 텍스트로 1회 전송합니다.
- **제작**: 실제 제작 실행 전 OCR 인식 오류로 동일 품목이 15분 이상 보류되면 품목별로 1회 알립니다. 기존 30초 재시도 간격과 순서, F10 중단 및 안전 정지 정책을 유지합니다.
- **안전장치**: 알림은 어떤 클릭·제작·수령·가공 등록도 실행하지 않습니다. 기존 F9 배치 장부와 화면·CLI 검증을 유지하고, 자동 재시작이나 무인 코드 수정은 하지 않습니다.
- **CI/릴리스**: 오래된 버전 릴리스 작업이 매번 자동 재실행되지 않도록 메인 CI 이벤트를 분리했습니다. 이번 버전의 공개 배포는 **정확한 main 커밋 CI 성공**, 버전 일치, Windows 실행파일 및 롤백 포함 ZIP, SHA256, 태그/릴리스 중복 방지에 의해 제한됩니다.

## 검증의 범위
오프라인 모의 테스트, Windows 빌드, 가공·제작 회귀 테스트 및 정식 메인 CI
통과를 배포 조건으로 합니다. **실제 게임 조작/장시간 자동화 테스트는 수행하지
않았습니다.** 게임 측 UI 변경이나 장시간 대기 상황에서 여전히 예상하지 못한
오류가 있을 수 있습니다.

## 복구
설치 ZIP에 포함된 `ROLLBACK_PREVIOUS.cmd`와
`tools/RollbackPrevious.ps1`로 기존 버전을 복구할 수 있습니다.
실행 중인 매크로를 강제로 자동 갱신하지 않습니다.
