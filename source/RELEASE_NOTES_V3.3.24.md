# Mabi Auto V3.3.24 — 던전 클리어 화면 진행 정지 수정

- 클리어 제목과 화면 터치 문구를 이미지 및 제한 영역 OCR로 확인하는 절차를 통일했습니다.
- OCR로 확인된 클리어 화면이 이미지 전용 전투 HUD 재검사에서 차단되는 문제를 수정했습니다.
- 최초 클리어 확인, 터치 재시도, 결과 오진입 복구, 결과 화면 구분에서 동일한 판정을 사용합니다.
- 제목과 터치 문구를 모두 안전 영역에서 확인하고 2프레임 검증 후에만 입력합니다. 결과 버튼 검증, 전투 시간 제한, 병행 가공 판단은 유지합니다.
- Windows 빌드와 회귀 검사 후 배포합니다. 실제 게임에서의 수정 후 확인은 아직 수행되지 않았습니다.
- 이전 버전 복원: ROLLBACK_PREVIOUS.cmd. 업데이트 ZIP은 SHA256 검증 및 BUILD_COMMIT 출처 기록을 유지합니다.
