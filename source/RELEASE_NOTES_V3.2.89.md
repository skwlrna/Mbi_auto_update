# Mabi Auto V3.2.89 — 채집 목표 도달 후 Stop 상태 불일치 복구

V3.2.88 이후 2026-11-05 01:36 KST `Mbi_auto_log` 다중가공 오류를 바탕으로 PR #377의 채집 종료 상태 확인 문제를 수정합니다.

## 변경 내용

- 목표 수량 확보 후 화면 Stop 버튼은 보이지만 CLI의 `MainButtonState`가 잠시 Stop이 아닐 때 즉시 오류를 상위 다중가공으로 전달하지 않습니다. 입력 없이 제한된 채집 종료 확인 루프를 계속 진행합니다.
- 실제 Space 정지 입력 전에는 두 번의 새로운 화면/CLI 관찰에서 Stop 버튼과 CLI Stop 상태가 일치해야 합니다.
- 정지 입력 후 CLI 채집/이동/낚시가 모두 비활성이고 Stop UI가 두 번 연속 사라졌음을 확인한 후, 최종 재고가 목표 이상인지 다시 확인해야 다음 가공 단계로 이동합니다.
- Stop UI가 계속 남으면 기존처럼 확인된 증거에 한하여 Space 재시도를 최대 한 번 허용하며, 확인되지 않은 보류는 재시도 사용으로 계산하지 않습니다. 실제 정지 및 재고가 불확실하면 계속 안전 정지합니다.
- `tests/gathering/Program.cs`에 576/576 Stop-CLI 불일치, CLI Stop 잔상, 진행 중인 채집 안전 차단 등 회귀 검사를 추가했습니다.

## 안정성·배포 조건

- V3.2.88의 제작·어비스·Watchdog 안정화 내용과 기존 F9 K/I/Space 보호를 유지합니다.
- 필수 PR CI, 정확한 main SHA의 CI, Windows 빌드·스모크, Windows Lite ZIP+SHA256, 소스 ZIP 및 `ROLLBACK_PREVIOUS.cmd` 등 롤백 도구 검증 후에만 정식 배포합니다.
- **실제 게임 구동 검증은 수행하지 않았습니다.** 오프라인/모의 테스트 결과는 라이브 게임 동작 성공을 보장하지 않습니다.
- 실행 중 게임에 강제 설치하지 않으며, 필요하면 설치 ZIP의 `ROLLBACK_PREVIOUS.cmd`를 이용해 이전 버전으로 복원할 수 있습니다.
