# Mabi Auto V3.3.23 — 11월 15일 02:28 완료 보상 화면 미인식 수정

- 대상 오류: V3.3.22 / 2026-11-15 02:28:01 / 허상의 정박지. 화면은 이미 보상/다시 하기/나가기 3버튼이 존재했으나 `abyss_result_text_authority` 미검출 후 10분 강제 퇴장 아이콘을 찾다 안전 정지.
- 원인: 실제 결과의 '발견한 전리품' 제목이 y~420에 있었지만 OCR 영역이 y450부터 시작. 정확 '다시 하기' OCR이 누락될 때 결과 화면 인증이 불가능.
- 해결: 실제 화면에 있는 상단 중앙 보물상자 템플릿 + 서로 분리된 하단 녹색 버튼 3개 + 재시도 버튼 중앙 녹색 패치를 조합하여 비 OCR 결과 판정 허용. 보물상자 위치는 제한하며 기존 전투 HUD 거부 조건과 실제 클릭 전 녹색/창 크기/새 프레임 검증은 유지.
- 보완: 전리품 OCR 탐색 영역을 결과 화면 실측에 맞게 올리고, 10분 퇴장 아이콘 검증 최후 순간에도 정상 결과 화면을 2프레임 다시 검사.
- 기존 처리 유지: 정상 어비스는 가운데 '다시 하기', 병행 가공 필요시만 왼쪽 '나가기'. 강제 퇴장 아이콘이 없는 실제 완료 화면에서 잘못 안전 정지하지 않음.
