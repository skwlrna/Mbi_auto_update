# Mabi Auto V3.3.40

- 기존 텔레그램 원격 제어를 켜고 등록한 개인 채팅에서 자동가공 주문을 입력할 수 있습니다.
- `가공 추가 가죽+ 총 200`은 가방·창고 합산 200개까지, `가공 추가 철괴 추가 100`은 100개 이상 추가 생산을 뜻합니다.
- `가공 목록`, `가공 취소 2`, `가공 시작`, `가공 정지`를 지원합니다. 매크로 상세 현황은 기존 `/status`로 확인합니다.
- 실행 중 새로 등록한 주문은 현재 작업 종료 후 이어집니다. 중단되거나 결과가 불분명한 실행 주문은 확인 필요 상태로 남깁니다.
- 실제 텔레그램 계정과 게임에서의 실행은 확인 대기입니다. 이전 버전은 `ROLLBACK_PREVIOUS.cmd`로 복원할 수 있습니다.
