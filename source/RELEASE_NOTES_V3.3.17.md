# Mabi Auto V3.3.17 — 가공 필요할 때만 어비스 나가기

- 스케줄러의 어비스+다중가공에서 결과 화면마다 실제 CLI 가공 대기열을 읽고 '다시 하기'와 '나가기'를 분기합니다. 일반 어비스 단독 모드에는 영향을 주지 않습니다.
- 선택된 모든 가공 시설에 진행 중인 배치가 있고 아직 각 시설의 배치 전체가 완료되지 않았다면, 기존 2~3프레임 결과·중앙 버튼 검증을 거쳐 **나가지 않고 다시 하기**를 실행합니다.
- 선택 시설의 배치 전체 완료, 선택 시설 대기열 비어 있음, 또는 시작하지 않은 작업을 확인하면 기존 엄격한 왼쪽 나가기 확인 후 필드 HUD 3프레임을 검증하고 가공 관리자로 돌아갑니다.
- 일부 슬롯만 완료되고 같은 시설의 나머지 슬롯이 계속 가공 중이면 기존 관리자의 '시설 전체 배치 완료 후 수령' 정책에 따라 **어비스를 계속** 진행합니다. 다른 시설의 완료는 영향을 주지 않습니다.
- 가공을 계속할 때에는 이전 정보를 재사용하지 않고 중간관리자를 통한 CLI 조회를 두 번 수행합니다. 새 조회로 가공 필요가 발견되면 다음 어비스를 시작하지 않습니다.
- CLI 조회 실패·불명확한 상태에서는 무조건 재입장하지 않고 안전 정지합니다. 가공 등록·수령 권한은 전부 기존 중간관리자가 보유하며, 어비스 중에는 다른 게임 입력이 없습니다.
- Smart Recovery의 어비스 결과 화면도 동일한 최신 CLI 결정을 따릅니다. 스텔라그램 ESC/필드 복귀 및 Space 입장 안전장치는 유지합니다.
- 가공/제작 자체 작업 내용·보유재료·단축키·다른 던전 모드는 수정하지 않았습니다.

검증: 선택 시설별 진행/부분완료/전체완료/빈 대기열/알 수 없는 상태, 결과와 복구 양쪽 분기, Windows CI, 배포 ZIP/실행 파일/체크섬 검사. 실제 게임 수락 시험은 미실시, 기존 롤백 유지.
