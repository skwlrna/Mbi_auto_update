# Mabi Auto V3.2.92 — 2026-11-05 게임 업데이트 후 `IsReviving` 필드 호환성 수정

**대상 오류:** V3.2.91 다중가공 19:22·19:23 실행에서 `get_activity 필수 필드 누락: $.IsReviving`으로 시설 K 입력 전에 중단. 최신 CLI 응답은 해당 필드만 없고 다른 주요 상태 필드는 정상 타입으로 확인됐습니다.

## 실제 수정 (PR #383)

- 공통 `GatheringQueries.ParseActivity`에서 **`IsReviving` 하나만 선택적 필드**로 처리합니다. 누락 시 `bool? IsReviving = null`로 유지하며, `false`로 속이지 않습니다.
- 실제 Boolean `true`/`false`가 반환되면 값 그대로 보존합니다. 필드가 있는데 자료형이 잘못되면 기존처럼 차단합니다.
- **`IsDead`, `IsInCombat`, `IsAutoTraveling` 및 모든 기타 필수 필드**의 자료형 검사와 가공/채집 안전 정책을 변경하지 않습니다.
- 기존 F9 K/I/Space 2프레임 화면 인증, 중간관리자 권한, 안전 정지, 중복 수령/등록 차단, 채집 중 전투 대기 로직은 그대로 유지합니다.
- 실측된 누락 응답에 대한 회귀 테스트와 실제 true/false 보존, 사망·전투·이동 중 가공 차단 테스트를 추가했습니다.
- 기존 5초 재시도 요청은 변함없으며, Windows 타이머 정밀도에 민감했던 **테스트 시간 허용 오차만** 조정했습니다.

## 검증 및 롤백

- 배포는 병합된 정확한 `main` SHA의 Windows CI, 게임 화면/채집/가공 회귀 검사, 실행 파일 빌드/스모크, 체크섬과 롤백 패키지를 통과해야만 공개합니다.
- **게임 PC에서 V3.2.92로 실제 가공 수령·등록 성공 여부는 아직 테스트하지 않았습니다.** 오류 해결 여부는 다음 실행의 GitHub 오토로그로 확인합니다.
- 실행 중 강제 설치하지 않으며, 필요시 `ROLLBACK_PREVIOUS.cmd`로 이전 버전 복구가 가능합니다.
