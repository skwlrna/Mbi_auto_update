# Mabi Auto V3.2.93 — 2026-11-05 약초 채집 하단 행 OCR 누락 수정

**확인된 현장 오류:** V3.2.92 실행 20:31:12(한국시간), 다중가공의 선행 원재료 **산뜻 버섯 포자** 채집 중 약초 채집 화면에서 **산뜻 버섯** 행 인증 실패. 오류 스크린샷의 산뜻 버섯은 y≈930에 보이지만 기존 프로그램은 OCR 검색 영역을 y=145~845로 제한하고 있었습니다.

## 수정 내용 (PR #385)

- `LifeSkillListLayout.VerifiedListSearchRoi`를 800×1000 기준 `Rectangle(150,145,630,835)`(세로 145~980)으로 정의해 실제 화면에 보이는 하단 버섯 행을 OCR 탐색 대상으로 포함합니다.
- `InventoryBulkGatheringScreen.FindStableLifeSkillRowAsync`가 수정된 ROI에서 **정확한 OCR 이름 + 같은 행의 아이콘 증거 + 연속 두 화면의 동일 행 위치**를 확인한 경우에만 두 번째 OCR 좌표로 클릭하도록 기존 검증을 유지합니다. y930은 **클릭 좌표가 아니라 관측된 문제 영역**입니다.
- 약초 채집의 최대 9페이지 제한 스크롤과 스크롤 후 재인증 유지. 검색 실패 시 페이지 번호 및 OCR 세로 검색 범위를 기록합니다.
- 과거 잘린 y845 검색과 새 y980 검색을 비교하는 회귀 테스트, 하단 목록 밖 입력 금지, 정확한 행의 2프레임 위치 검사, 기존 안전 정책 유지 검사를 추가했습니다.

## 유지 사항

- V3.2.92의 `IsReviving` 단일 필드 선택 처리와 사망·전투·이동·던전 검사 유지.
- 가방·재료 상세 우회 경로 사용하지 않음. 눈대중의 하단 고정좌표 클릭이나 자동 재시도/중복 채집·가공 입력 추가 없음.
- 업데이트 중인 실행 프로그램에 강제 설치하지 않음.

## 검증과 롤백

- 정식 공개는 **정확한 `main` 커밋의 Windows CI 성공**, 실제 코드 빌드/스모크, 기존 화면·채집 회귀 검사, SHA256 체크섬, 롤백 패키지 확인 후에만 진행합니다.
- **V3.2.93의 실게임 정상 채집 완료 여부는 아직 미확인**입니다. 실제 항목 선택·채집·가공 재진입은 새 오토로그로 확인해야 합니다.
- 문제가 발생하면 ZIP 안의 `ROLLBACK_PREVIOUS.cmd`로 이전 설치를 복원할 수 있습니다.
