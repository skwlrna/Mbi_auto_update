# Mabi Auto V3.2.71 — 텔레그램 제작 상세 상태 확인

- 텔레그램 채팅에서 `상태` 또는 `/status`를 입력하면 현재 제작 중인 품목과 다중 제작 대기 목록의 상태를 상세히 확인할 수 있습니다.
- 품목별 실제 재고 증가 확인 수량/목표, 완료된 제작 횟수/필요 횟수, 제작 순서 및 남은 목표를 표시합니다. 작업 중 재료 확보·채집·중간 가공과 최근 동작을 확인할 수 있습니다.
- 상점 구매 재료 부족 등으로 건너뛴 음식은 구분 표시하고, 재료 부족 사유와 다음 품목 진행 상태를 보여줍니다. 정지나 오류로 종료된 경우에도 완료라고 표시하지 않습니다.
- 조회는 UI 스레드의 진행 스냅샷만 복사해 사용합니다. 텔레그램 `상태` 입력 때문에 게임 입력이나 제작 작업이 시작·정지되지 않습니다.
- 기존 F9 다중가공 상태 출력과 기존 제작/채집/가공 고정좌표를 변경하지 않습니다.
- 긴 다중 제작 목록은 항목이 중간에 잘리지 않도록 길이 제한 내에서 표시하고 생략을 알립니다.
- Windows Lite 자동업데이트 ZIP, SHA256, 소스 ZIP, 백업·롤백 스크립트를 유지합니다. 실행 중인 매크로 강제 교체는 하지 않습니다.

**검증:** 배포는 메인 브랜치의 GitHub Actions Windows 빌드와 제작 회귀 테스트 성공 후에만 허용합니다. 실제 게임에서의 동작 검증은 별도이며, 이번 배포는 사용자 요청에 따른 개인 사용 배포입니다.
