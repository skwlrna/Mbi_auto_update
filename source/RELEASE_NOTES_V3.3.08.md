# Mabi Auto V3.3.08 — 음식 레시피 + CLI 재료 판정

- 음식 54종의 전체 직접 투입 레시피와 별칭 2개를 등록했습니다. 스튜의 밥 4개와 리소토의 치즈 12개는 사용자 제공 1회 게임 화면으로 확인했습니다.
- 등록 음식의 상세 재료 충분 여부, 부족량 및 재료 확보 완료는 레시피 필요량과 최신 CLI 가방 재고로 판단합니다. 재료명 OCR 실패는 이 경로의 중단 조건이 아닙니다.
- 충분한 재료와 상점/마이홈/던전/낚시 재료도 전체 레시피에 포함합니다. 부족한 채집 재료는 퀘스트 행 위치로 수급하고, 중간재는 기존 가공기에 부족량만 전달합니다.
- 수량이 같은 행은 가능한 후보가 모두 채집 대상일 때만 진행하고, 해당 후보들의 CLI 재고로 완료를 확인합니다. 임의의 재료명이나 화면 순서를 추정하지 않습니다.
- 행 위치 판독은 현재 팝업에서 재시도합니다. 같은 위치 오류로 퀘스트를 3회 반복 생성하지 않으며, 이미 완료한 제작 수량을 유지합니다.
- 미등록 음식과 아이템 제작은 기존 화면 판독 경로를 유지합니다. 제작대 도착 및 실제 완료창 검증, CLI 오류와 실제 재료 부족의 구분, F10 취소를 유지합니다.

검증: 제작 회귀 180개, Windows 생산 화면 연결 검사 및 전체 CI 후 배포. 20회 완료 후 세 번째 호박 수프 배치에서 4/100·8/60·34/60 부족이 발생하는 경로를 재현해 50회 완료 및 복구 반복 방지를 확인했습니다.
실제 게임 자동화의 업데이트 후 검증은 미실시입니다. 기존 롤백 기능과 ZIP SHA256 확인을 유지합니다.
