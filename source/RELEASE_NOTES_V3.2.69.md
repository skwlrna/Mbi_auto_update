# Mabi Auto V3.2.69 — 고정 좌표 시설 진입 재시도

- 시설 카드 클릭 좌표는 기존 고정 좌표를 그대로 사용합니다.
- 클릭 후 최대 3초 동안 시설 화면을 연속 2프레임 확인합니다.
- 시설 진입이 확인되지 않으면 새 화면에서 팝업 없는 가공 허브를 2프레임 확인한 경우에만 같은 고정 좌표로 1회 재시도합니다. 재시도의 시설명 OCR 필수 조건과 별도 본문 좌표 전환을 제거합니다.
- 시설 메뉴 진입 실패를 가공 등록 결과 미확정과 분리합니다. 가공 등록/수령 결과가 미확정인 경우 기존 중복 실행 차단을 유지합니다.
- K 입력 전 필드 인증, 팝업 차단, CLI 유휴 확인, 기존 롤백 및 실행 중 매크로 강제 교체 금지를 유지합니다.

검증: 가공 회귀 검사 501개 통과, Windows 대상 프로그램/화면 통합 테스트 빌드 성공. 배포는 PR 및 main CI 성공 후 진행합니다. 실제 게임 동작 검증은 별도입니다.
