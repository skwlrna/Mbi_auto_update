# MabiAuto V3.2.18 — Codex 오류 자동수정 안정화

## 수정 사항
- 과거 어비스 AI 수정 후보의 정적 검사 실패 때문에 새로운 오류의 AI 감시 전체가 시작되지 못하는 문제를 보완했습니다. 과거 후보는 검토 필요로 경고하되, **새 어비스 코드 수정안은 기존 전용 안전 검사를 통과해야만 자동 테스트 성공 후보가 됩니다.**
- 매크로 또는 Codex 감시 종료 중 수정이 끊기면, 다음 AI 시작에서 `이전 AI 분석 중단 · 재분석 가능` 상태로 표시합니다. 수정 도중 생긴 격리 작업 폴더와 오류 증거는 보존하고 **자동 재실행하지 않습니다.**
- 오류 시간별 내역에서 중단된 항목을 선택하고 `중단 작업 재분석`을 클릭하면 명시적인 사용자 동의 후 **새 격리 작업 폴더**에서 한 번만 분석할 수 있습니다. 이전 수정안이나 테스트 상태를 그대로 승격시키지 않습니다.
- Codex가 제작·가공의 핵심 화면 및 좌표 레이아웃 코드를 변경하면 관련 제작·가공 회귀 테스트의 실제 코드 변경과 성공이 필요합니다. 전혀 관계없는 테스트를 고쳤다고 성공으로 인정하지 않습니다.
- 이전 Autofix 실행·OFF 상태를 확인하라는 오래된 설명서를 Codex Autopilot 독립 실행 방식에 맞게 수정했습니다.

## 변경하지 않은 사항
- 기존 목재·금속·가죽·옷감·식재료 및 제작 클릭 고정좌표는 변경하지 않았습니다.
- 매크로 프로그램을 닫으면 그 프로그램이 시작한 AI 감시와 자식 Codex도 종료됩니다.
- 게임 입력, 가공·제작 작업 등록/수령 로직, F9/F10 스케줄러 안전 정책은 그대로 유지합니다.
- Codex가 제안한 코드를 게임에 자동 적용·병합·배포하지 않습니다. GitHub Draft PR 자동 생성은 사용자가 명시적으로 켜고 모든 자동 테스트가 통과한 경우에만 가능합니다.

## 배포 검증
- PR #214의 Windows 생산 엔진 회귀 및 어비스·가공 스케줄러 Windows 검사 통과.
- V3.2.18의 **최신 main** CI가 다시 성공하고, Windows 실행 파일/감시 모듈이 패키지에 포함되며, ZIP과 SHA-256·출처 SHA 검사가 모두 성공한 경우에만 별도 새 릴리스를 공개합니다.
- 실사용 PC의 Codex 로그인, 연결 상태, 게임 화면 오류 수정 성공은 CI에서 검증되지 않습니다. 최초 실제 오류로 전체 과정 검증이 필요합니다.

업데이트는 기존 버전으로부터 새 공개 GitHub 릴리스 `V3.2.18`이 탐지되면 진행됩니다. 기존 V3.2.17 릴리스 및 태그를 덮어쓰지 않습니다.
