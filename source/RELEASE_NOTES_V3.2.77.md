# Mabi Auto V3.2.77 — F9 필드 인식 수정

- 미니맵의 색상·테두리·원형·주야 표시를 사용하는 필드 판정을 완전히 제거했습니다.
- 상단 단축키와 하단 K·I 글자 형태로 필드를 확인합니다.
- Unknown 화면에서 즉시 종료하지 않고 최대 3초 동안 입력 없이 새 화면을 재확인합니다.
- 시설 전환 중 Esc 이후 일반 필드와 가공 허브 양쪽을 처리합니다.
- 연속 두 프레임, 입력 직전 최신 화면, 팝업 차단과 CLI 상태 재확인을 유지합니다.

## 검증

PR #344의 실제 오류 화면(2026-10-31 02:24, 07:01)과 미니맵 전체 가림·단축키 제거 사례를 포함한 Windows 화면 통합 검증 568개 및 한국어 OCR 검증을 통과한 소스입니다. 새 버전은 정확한 main 커밋의 전체 CI, Windows 실행 확인, K/I 파일 포함 확인, ZIP SHA256 및 업데이트·롤백 검증을 통과해야 배포됩니다.

실게임 동작은 아직 검증하지 않았습니다. 설치 후 확인이 필요하며, 문제가 있으면 포함된 ROLLBACK_PREVIOUS.cmd로 이전 버전으로 되돌릴 수 있습니다. 기존 V3.2.76 배포 파일은 변경하지 않습니다.
