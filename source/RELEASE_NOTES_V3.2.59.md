# Mabi Auto V3.2.59 — 가공 시설/필드 화면 오인식 및 이동 좌표 보호 (PR #292)

> **사용자 직접 요청으로 진행한 정식 공개 배포입니다.** Windows CI와 실제 캡처 기반 화면 회귀 검사를 통과했으나, 실제 게임에서 시설 이동·가공품 수령·PC 업데이트/롤백은 아직 검증하지 않았습니다.

## 변경 사항
- 2026-10-24 03:33 금속 가공 시설 6건 완료 뒤 월드 필드를 시설창으로 잘못 인식해 이동 버튼 좌표 (85,235)를 2회 클릭하고 안전 정지한 현상을 대상으로 개선
- 월드 HUD 감지 시 시설 헤더 캐시 및 OCR보다 먼저 필드 화면으로 차단
- 실제 시설 화면에서 제목·설명뿐 아니라 '전체' 탭과 분리된 품목 카드 3개의 구조까지 확인
- 이동 고정좌표 첫 클릭과 최대 한 차례의 재클릭 모두 **입력 직전 캡처에서 시설 구조/팝업 상태를 다시 검사**하며, 불확실하면 입력을 보내지 않고 정지
- 원격 이동 버튼 색상/형태를 놓치는 경우에 대비하여 독립적인 7개 작업 슬롯의 구조 증거도 사용. 그 증거만으로 클릭을 허용하지 않음
- 기존 다중가공 작업 소유권·작업 장부·수령 안전 분기 유지

## 검증
- PR #292의 주요 Windows 빌드, 가공·스케줄러 및 장부 CI 성공
- **캡처 기반 실제 화면 통합 검사 324개 통과:** 광산 월드 필드, HUD 일부 마스킹된 필드, 원격 목재 시설, 가죽·금속 현장 화면, 원격 이동버튼 마스킹 화면 검사
- 첫 이동 및 재클릭 모두 최신 화면 검증을 호출하는 컴파일된 호출 경로 검사 통과
- 배포용 V3.2.59 main CI와 Windows 패키징·실행 스모크·SHA256 검증은 배포 파이프라인에서 별도로 요구됨
- 오래된 V3.2.55 후보 버전 불일치 검사 실패는 현재 V3.2.59의 실행 기능 실패가 아님
- **실게임 성공, AI 자동수정기 작동, 사용자 PC 업데이트/롤백은 확인되지 않았습니다.**
