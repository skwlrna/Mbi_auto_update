# Mabi Auto V3.3.01 — 약품 반복 검색 제거

배포일: 2026-11-07 (KST)

- 같은 시설·같은 약품을 연속 등록할 때 최초 검색 결과를 유지하고, 단일 결과를 새 화면 2회 확인한 뒤 선택합니다. 검색창을 다시 열거나 검색어를 다시 입력하지 않습니다.
- 품목 변경이나 새 시설 진입으로 검색이 필요하면 Ctrl+A → Ctrl+V로 기존 검색어 전체를 교체합니다. 검색어가 이어 붙는 오류를 방지합니다.
- 다른 시설 진입·품목 변경·일일 중단 복구 시 검색 결과 재사용 근거를 폐기합니다. 결과 확인 실패 시 재검색이나 중복 등록 없이 정지합니다.
- 등록 직전 무료 버튼·원격 차단·최신 화면 검증과 CLI 작업 증가 확인은 유지합니다.
- Windows 빌드, 회귀 검사, EXE 실행 검사 및 SHA256 ZIP 검증 후 배포합니다. 배포 전 실게임 재현 검증은 수행하지 않았습니다.

이전 버전 복구: Windows Lite의 `ROLLBACK_PREVIOUS.cmd`를 실행하십시오.
