# Mabi Auto V3.2.70 — 다중 음식 재료 부족 건너뛰기 및 하위 가공 재료 검사

- 다중 음식 제작 중 상점 구매 전용 재료가 부족하거나, 직접 채집할 재료 확보가 실패하면 해당 음식만 건너뛰고 다음 음식으로 계속 진행합니다.
- 완료 품목은 완료 표시, 재료 부족으로 건너뛴 품목은 미완료 목록에 유지하여 재료를 마련한 뒤 다시 실행할 수 있습니다.
- 상점 구매 재료 14종(소금·설탕·식용유·후추·고기·마늘·레몬·토마토·아스파라거스·완두콩·무·고춧가루·딸기·담백한 고기)을 별도 식별합니다. 매크로가 아이템을 구매하지는 않습니다.
- 가공 재료 9종(밀가루·치즈·마요네즈·면·생크림·두부·두유·물에 불린 콩·밥)의 하위 구매 재료를 재고와 대조하고, 물에 불린 쌀·옷감 등 하위 중간재까지 계산합니다. 검증되지 않은 품목은 자동으로 상점 전용이라고 추정하지 않습니다.
- 식재료 이름 OCR 미확인은 무리한 채집을 막습니다. 화면 정리 및 이동·채집 유휴 확인이 실패하면 다음 음식으로 넘어가지 않고 안전 중지합니다.
- 기존 제작/채집/가공 고정좌표는 변경하지 않았습니다.
- 기존 자동 업데이트 ZIP/서명용 SHA256/롤백 도구를 유지하며 실행 중인 매크로를 강제로 바꾸지 않습니다.

**검증:** GitHub Actions Windows 프로그램 빌드, 제작/가공 통합 회귀 테스트 및 배포 전 제작 전용 회귀 테스트. 실제 게임에서의 동작 검증은 별도이며 본 릴리스는 사용자 요청에 따른 개인 사용 배포입니다.
