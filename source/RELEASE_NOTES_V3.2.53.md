# Mabi Auto V3.2.53 — AI 자동수정기 안전 복구

> 사용자 요청에 따라 미검증 상태로 배포합니다. 실PC Codex/29개 작업공간 회수/실게임 실행·롤백은 테스트하지 않았습니다.

## 변경
- V3.2.52 가죽+ F9 원재료 부족 처리 및 첫 제작 진단을 유지합니다.
- AI 수정 결과를 코드 미변경, 회귀 테스트 정책 차단, 테스트 실패, 환경 오류로 구분합니다.
- 기존 C# 및 Python 자동수정 회귀 테스트를 인식합니다.
- 과거 소스 스냅샷 및 Git 등록 소유권을 확인하여 종료된 AI 작업공간을 회수할 수 있게 합니다.
- 작업공간 수정·무시 파일, 로그, 사용 가능한 증거를 SHA-256 검증 ZIP으로 백업한 뒤에만 Git 제거를 요청합니다.
- NTFS junction 차단과 독립 ZIP 무결성 검증, 읽기 전용 회수 진단을 제공합니다.
