# MabiAuto V3.2.42 개발 후보 — 다중가공 재료 부족 사전 예측 (읽기 전용)

## 핵심 변경
- F9 신규 다중가공 시작 시 *CLI가 부족하다고 표시한 재료만* 대상으로 필요한 작업 수와 재료 수량을 합산해 **부분적인 부족분 예측**을 로그에 표시합니다.
- 서로 다른 선택 품목이 동일 원재료를 요구하면 총 수요를 합산하고, 그 재료의 재고는 **새 CLI 요청 1회**로 확인해 한 번만 공제합니다.
- 지원되는 무료 일괄 채집 화면 경로, 채집 도구 부족, 퀘스트 전용, 다중 경로, 경로 미확인 등을 식별합니다. 경로 미확인은 중간 재료 가공 가능성까지 부정하는 것은 아닙니다.
- 부족 재료를 확인하기 쉬운 순서(부족 존재 → 검증된 화면 일괄 채집 경로 → 부족량)로 **진단 로그만 정렬**합니다. 사용자 지정 제법 순서/실제 채집 우선순위/가공 배치 순서는 변경하지 않습니다.
- 상위 20개 재료만 UI 로그로 출력하고 나머지는 생략해 반복·대량 로그를 제한합니다.

## 중요한 안전 제한
- `MissingIngredients`는 전체 제법/소모량 목록이 아닙니다. `queue_full`로 정보가 숨겨진 품목이나 CLI에서 부족 표시가 없는 품목의 실제 필요량을 추정하지 않습니다.
- 화면에서 추출한 `Owned` 수치나 과거 재고는 신뢰하지 않으며, 현재 재고는 읽기 전용 CLI를 새로 조회합니다.
- 예측 성공/실패는 자동 채집 또는 게임 입력 권한을 부여하지 않습니다. 오류가 나면 진단을 생략하고 기존 F9 실행 직전 재료 확인·등록·수령 가드를 유지합니다.
- 자동 구매, 정령의 날개, 게임 쓰기 명령 추가 없음. F10 취소는 진단 중에도 즉시 상위 제어로 전달합니다.
- 3.2.41에서 추가한 보류 영속 저장·명시적 이어하기 정책을 그대로 유지합니다.
- 이 브랜치는 **V3.2.41 미배포 개발 브랜치에 종속**되며 아직 V3.2.42 EXE 버전·릴리스·자동업데이트를 생성하지 않습니다.

## 회귀 검증
- 서로 다른 식재료 제법에 공유되는 물 재료의 총 필요량/신규 재고 1회 공제
- 일괄 채집 가능, 도구 없음, 퀘스트 전용, 경로 미확인 분류
- `queue_full`/빈 부족 목록의 가짜 수요 차단
- 중복 선택 품목·음수 재고·수량 오버플로·F10 취소

실게임 검증 전까지 PR 초안으로 유지합니다.
