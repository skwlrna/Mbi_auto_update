# Mabi Auto V3.2.65 — 재료 전송 주간 체크 자동 처리

- 금속 가공 강철괴 다중가공에서 재료 전송 팝업의 한국어 OCR 실패로 중지한 문제를 보완합니다.
- `재료를 전송하시겠습니까?` 팝업에서 `일주일 동안 보지 않기`가 회색이면 1회만 클릭하고 **초록색 선택 상태**를 검증한 뒤 `확인`을 클릭합니다.
- 이미 초록색인 경우 다시 클릭하지 않습니다. OCR/화면/체크 상태가 불확실하면 중복 가공 클릭 없이 안전 중단합니다.
- 사고 당시 실제 스크린샷에 대한 한국어 Windows OCR 검사, 17개 가짜입력 시나리오, 기존 Windows 빌드 검사를 통과한 main 커밋만 배포되도록 게이트합니다.
- 업데이트 ZIP에 SHA256 검증 및 이전 버전 롤백 기능이 포함됩니다. 실행 중인 매크로(`AnyRunning`)가 있으면 자동 설치를 건너뛰고 작업 종료 후 유휴 상태에서 재검사합니다. 유휴 상태에서 설치 시 앱이 종료되고 업데이트 후 재실행됩니다.

본 배포는 매크로 직접 입력이나 게임 서버에서 주간 숨김 설정의 영속성까지 실측해 검증한 것은 아닙니다.
