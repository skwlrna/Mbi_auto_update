# Mabi Auto V3.2.56 — PR #278 가변 Home/Y 화면 인증 및 음식 제작 메뉴 복귀

> **실게임 미검증 상태의 사용자 요청 릴리즈입니다.** Windows 빌드·회귀 테스트는 통과했지만 실제 게임 입력, 작업 수령, 사용자 PC 설치 및 롤백은 검증되지 않았습니다.

## 변경 사항
- 첫 K 및 재진입 모두 일반 필드의 실제 연속 2프레임과 입력 직전 최종 캡처에서 동일한 화면 인증 경로를 요구합니다.
- Home/Y 배치 변화에 대응하도록 Home·End·ESC 글자 보조 인식을 추가하고, 기존 3/4·K/I·Home/End 인증을 유지합니다.
- 음식 제작 빠른 메뉴를 정확한 제목·하단 가공 탭으로 2프레임 확인한 경우 탭을 한 번 선택합니다. 불확실한 K/Esc 재입력은 금지합니다.
- CLI 유휴·메뉴/팝업 차단·캡처 새로고침을 유지하여 불확실하면 입력 없이 중단합니다.

## 검증 범위 및 제한
- PR #278 최종 커밋에서 Windows 통합 검증 296개, 생산 엔진·스케줄러·후보 빌드 검증 통과.
- 209개 익명화된 과거 화면 조각을 이용한 오프라인 회귀 검증입니다. 필드 오류 5/5 및 음식 메뉴 5/5는 기존 사례의 분류이며 미사용 화면이나 실게임 성공률을 나타내지 않습니다.
- 실제 K 메뉴 전환, 음식 탭 이동, 강철괴 7건 수령, 사용자 PC 업데이트 및 롤백은 **미검증**입니다.

## 업데이트 및 복구
- 실행 중인 F9/매크로를 중지하고 설치 폴더·설정·배치 진행 기록을 별도 백업하십시오.
- 이상 상태에서 임의로 K/Esc를 반복하지 말고 진단 로그를 보존하십시오.
- 패키지의 `ROLLBACK_PREVIOUS.cmd` 또는 [기존 V3.2.55 정식 릴리즈](https://github.com/skwlrna/Mbi_auto_update/releases/tag/V3.2.55)로 복귀할 수 있지만, 이 버전에 대한 PC 실제 롤백은 검증되지 않았습니다.
