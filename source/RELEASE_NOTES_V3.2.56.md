# Mabi Auto V3.2.56 — 가변 Home/Y 배치 K 화면 인증 및 음식 제작 메뉴 복귀

> **실게임 검증 전 사용자 요청에 따라 공개하는 버전입니다.** PR #278의 Windows 회귀 검사는 통과했지만 실게임에서 K 입력·음식 제작 메뉴 전환·강철괴 수령과 사용자 PC 설치/롤백은 확인하지 않았습니다.

## 변경
- Y 버튼으로 Home 위치가 이동하는 두 가지 일반 필드 배치를 Home·End·ESC 글자 보조 경로로 인식합니다.
- 기존 3/4 HUD, K/I, Home/End 인증을 보존합니다. 첫 K부터 실제 연속 2프레임 인증 및 최신 CLI 유휴 확인을 요구합니다.
- K 입력 직전 같은 인증 경로로 재검증하고, 메뉴나 팝업이 나타나면 입력을 막습니다.
- 음식 제작 메뉴에서는 제목·가공 탭을 2프레임 확인하고 가공 탭을 1회만 누르며 미확인 K/Esc 재입력을 방지합니다.

## 검증 및 한계
- PR #278의 Managed K 검증 296개, Check V3 Production Engine, Abyss + Scheduler, V3.2.55 isolated candidate 성공.
- 익명화된 기존 오류 화면 209장 중 정상 필드 5/5와 음식 제작 메뉴 5/5를 회귀 분류, 기타 메뉴·팝업·결과 140장에서 새 필드 인증 오검출 0건.
- **회귀 검증 자료에 해당 오류 사진도 포함됩니다.** 미사용 실제 화면에서의 정확도나 실게임 자동화 성공률을 나타내지 않습니다.
- 실제 K 입력·메뉴 전환·수령·PC 설치·롤백은 **미검증**입니다.

## 업데이트 주의
- 작업 중인 F9 매크로를 중지하고 설치 폴더·설정·가공 진행 기록을 백업하세요.
- 복원은 패키지의 `ROLLBACK_PREVIOUS.cmd` 또는 기존 [V3.2.55](https://github.com/skwlrna/Mbi_auto_update/releases/tag/V3.2.55)로 시도할 수 있습니다. 사용자 PC에서의 실제 복원 성공은 아직 확인되지 않았습니다.
