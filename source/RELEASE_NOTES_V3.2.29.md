# Mabi Auto V3.2.29 — 자동가공 CLI 상태 재검증 및 진단

## 자동가공 안정성
- F9 시작 전 CLI `get_alterable_items`와 `get_altering_works`를 함께 검증합니다.
- 선택 시설의 실제 7칸 포화 증거 없이 `queue_full`만 나타난 경우, 입력이나 배치 저장 전에 300/600ms 간격으로 최대 두 번 읽기 전용 재조회합니다.
- 재조회 결과 해당 제법이 `Alterable=true`이면 기존의 화면·가공 등록 검증 경로로 진입합니다. 구체적인 `MissingIngredients`가 확인되면 기존 재료 해결 경로로 보냅니다.
- 재조회 후에도 불일치하거나 다른 종류의 거절·제법 변경이 발생하면 기존과 동일하게 입력 없이 안전 정지합니다.
- 독립 식재료/의약품 시설이 다른 7/7 시설 때문에 보류되는 경우, 동일 상황의 로그 반복은 줄이면서 거절 이유가 바뀌면 새로운 원인을 기록합니다.

## 불변 안전 규칙
- GUI OCR/화면 검증, 시설 현장확정, 입력 전후 CLI 작업 +1 검증, 정령의 날개 0개 정책, 시설 전체 완료 후 묶음 수령, F10 취소/이력 보존, 불확실 시 `RecoveryRequired` 유지.
- 직접 패킷 해석이나 CLI 실행 명령은 추가하지 않았습니다.
- 실제 PC에서의 오류 감소율은 측정되지 않았으며, 이번 변경은 기존 CLI 조회 상태의 일시적 불일치에 한정됩니다.

## 검증
- 자동가공 회귀에 일시적 `queue_full` 회복, 계속되는 `queue_full` 안전 정지, 재료 부족 단일 조회, 일반 거절, F10 중단 사례를 추가했습니다.
- 기존 Windows CI 및 배포 승인 보호 장치와 롤백 절차를 그대로 유지합니다.
