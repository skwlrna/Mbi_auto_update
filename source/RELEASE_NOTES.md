# MabiAuto V3.1.65 — 설비 이동 고정좌표 버튼 픽셀 비교 및 1회 재클릭

## 실제 실패 재현
- 2026-10-09 15:30 V3.1.64 로그: 목재 시설 진입 성공, 설비 이동 고정좌표 (85,235) 클릭, 클릭 전 버튼검출=False, 클릭 후 현장 X=True·수령버튼=True·CLI 자동이동=False였으나 69초 대기 후 안전 정지.
- 기존 V3.1.56/V3.1.64 즉시 도착 조건은 클릭 전 버튼 OCR/색상 인식이 반드시 True여야 했으므로, 같은 화면에서 버튼 검출이 한 번 누락돼도 도착 검증이 불가능했습니다.

## 변경 사항
- K 메뉴로 시설 진입 후 원래 설비 이동 **고정좌표 (85,235)** 그대로 사용합니다. 어떠한 다른 시설/품목/수령 고정좌표도 변경하지 않았습니다.
- 클릭 직전 고정 버튼 영역 `(15,205,155,65)`을 캡처하고 클릭 후 같은 영역의 픽셀 차이 비율을 실제 배포 `ProductionUiRuntime.MeasureVisualChangeRatio`로 비교합니다.
- 클릭 전 OCR/버튼 색상 검출 여부를 도착 승인 조건에서 완전히 제거했습니다. 클릭 후 버튼 영역에서 충분한 시각 변화가 확인되고 시설 화면, 현장 X, 버튼 미검출, CLI 유휴, 팝업 부재가 함께 확인될 때 도착 후보를 승인합니다.
- **3초 이상 픽셀이 거의 같고**, 3회 이상 확인되었으며 이동 중이 아니고 팝업/시설 전환이 없을 때만 같은 (85,235)를 **단 한 번 재클릭**합니다. 재클릭 직전 새로운 화면/CLI를 다시 확인합니다.
- 재클릭 후에도 3초 이상 동일 화면이면 반복하지 않고 안전 정지합니다. 변화가 불명확하거나 이동 중/전환 중이면 재클릭하지 않습니다.
- 기존 7프레임/3초 안정확인과 1.2초 독립 최종확인, 관리자 지시, 파란 모두 받기 및 전체 슬롯/CLI 수령검증, F10 정지 등은 유지합니다.
- 상태 로그에 버튼 픽셀 변화율, 픽셀 동일 프레임 수, 재클릭 사용 여부를 추가합니다.

## 테스트
- 실제 컴파일된 AlteringScreen이 픽셀 차이·재클릭 정책과 기존 안전확인을 실행하는지 검사
- 실제 프로덕션 픽셀 변화 함수로 고정 ROI 버튼 소멸/동일/작은 깜빡임 검사
- CLI 불확실/이동 중/팝업/이미 재클릭/실제 픽셀 변화에서 추가 클릭을 차단하는 정책 검사
- Windows CI 전체 통과 후 정식 Windows Lite 릴리스 게시; 실제 게임 검증은 업데이트 후 필요
