# MabiAuto V3.1.60 — 약품 검색을 음식 제작과 정확히 동일하게

## 약품 가공 돋보기 검색
- **음식 제작 검색 UI의 좌표·검색창/결과 영역·화면 전환 임계값을 약품 가공에서도 직접 공유**합니다. 약품 전용으로 따로 지정했던 옛 좌표를 사용하지 않습니다.
- 돋보기 클릭 (30,118) → 검색 입력칸 클릭 (400,862) → 품목명 붙여넣기 → Enter → Space 적용 → 결과 화면 변화 확인 → 첫 결과 (218,613) 클릭 → 550ms 대기로 통일합니다.
- 검색창 열림은 음식 제작과 같은 고정 영역의 화면 변화율 8% 이상으로 확인하며, 검색 결과는 OCR 정확히 1개 발견 **또는** 결과 영역 화면 변화율 6% 이상이면 통과합니다.
- 결과 OCR은 음식 제작과 동일한 **보조 확인**입니다. OCR이 없거나 중복 검출되었다는 이유만으로 이미 바뀐 결과 화면의 첫 결과 클릭을 중단하지 않습니다.
- 동일 이름의 다른 제법 순번을 모호하게 누르지 않도록 약품의 첫 제법(RecipeOrdinal=1) 확인은 유지합니다.

## 변경하지 않은 부분
- 음식·아이템 제작 흐름과 좌표 자체, 비약품 시설 가공 고정좌표, F9 새 목표 0부터 시작, 기존 작업 유지, 7칸 관리, F10 정지.
- 약품 시설 도착 여부, 팝업, CLI 안전 상태 및 선택 뒤 실제 가공 상세창 검사와 결제 방지 안전장치는 유지합니다.

Windows CI에서 가공 단위 테스트와 실제 코드 연결 통합 테스트를 검증한 뒤 V3.1.60 Windows 업데이트를 게시합니다. 실제 게임에서는 약품 한 품목을 소량으로 먼저 확인해 주세요.
