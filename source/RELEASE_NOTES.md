# MabiAuto V3.1.62 — 다중가공 시설 전환 화면 인식 보완

## V3.1.61 대비 변경사항
- 금속 가공 ↔ 목재 가공 등 **서로 다른 시설**로 진입할 때 이전 시설의 OCR 생략 캐시 및 설비 도착 확정 타이틀 캐시를 지웁니다. 일반적인 흰색 제목/시설 레벨 구조만 보고 이전 시설로 오인해 추가 Esc를 전송하는 위험을 줄입니다.
- 동일 시설 반복 등록의 기존 **고정좌표 / OCR 생략 고속 경로는 유지**합니다. 품목 선택 위치, 시설 선택 위치, 가공 버튼 좌표는 변경하지 않습니다.
- 시설 전환 중 **K 메뉴의 가공 항목이 이미 보이면 K 재입력을 생략**하고 기존 2프레임 메뉴 항목 확인 후 진입합니다.
- 이전 시설 화면으로 판단해 Esc를 보낼 때는 130ms 간격으로 서로 다른 두 화면에서 시설 제목을 재확인합니다.
- K 입력 전송과 이전 시설 인식 캐시 해제를 로그에 남겨 실제 전환 실패 지점을 구별할 수 있습니다.

## 안전 조건
- CLI 비이동/활동 확인, 이동·완료 팝업 차단, 시설별 수령 완료 7건 검증, 정령의 날개 미사용, Space 재입력 안전 기준은 V3.1.61과 동일합니다.
- 기존 최대 시설 진입 시도 3회와 기존 안전 정지 동작을 유지합니다.

## 회귀 검사
- 실제 컴파일된 AlteringScreen에서 금속→목재, 목재→금속 캐시 무효화, 동일 시설 반복 캐시 보존, 진입 함수에서 실제 무효화 호출을 테스트합니다.
- Windows CI 빌드 및 회귀 검사 성공 후에만 V3.1.62 Windows Lite 및 소스 ZIP을 자동 배포합니다.
- 실제 게임 입력 검증은 CI로 대체할 수 없으므로 배포 후 작은 다중가공 묶음으로 우선 확인해 주세요.
