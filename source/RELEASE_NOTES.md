# V2.0.3

V2.0.2 이후 실제 게임 화면 확인 내용을 반영해 제작·자동채집·자동가공의 무료 화면 경로를 보강한 릴리스입니다.

## 자동 가공
- `설비로 이동` 클릭 뒤 확인 팝업으로 오인해 Space를 누르던 경로를 제거했습니다.
- 설비 이동은 추가 키 입력 없이 게임의 자동이동을 기다리고, 시설 화면에서 `설비로 이동` 버튼이 사라진 상태를 안정적으로 확인한 뒤 현장 가공을 계속합니다.
- 가공 완료 결과 확인에 필요한 Space 동작은 기존대로 유지하며 설비 이동 Space와 분리합니다.

## 자동 채집
- 단독 자동채집과 자동가공 부족 원재료 확보는 가방 100개 퀘스트보다 **생활 스킬 100회 채집**을 우선 사용합니다.
- 100회마다 실제 CLI 재고 증가량을 확인하고 목표에 부족하면 반복합니다. 100회=100개라고 가정하지 않습니다.
- 일상 채집, 나무 베기, 광석 캐기, 약초 채집, 양털 깎기, 추수, 호미질의 확인된 재료-채집 대상 매핑을 추가했습니다.
- `○○ 버섯 포자`는 `○○ 버섯`으로 변환해 찾으며, 개암 버섯 계열은 호미질로 처리합니다.
- 생활 스킬 목록은 개별 품목의 고정 Y좌표 대신 OCR 정확 이름, 같은 행 아이콘 영역 확인, 스크롤 재탐색을 사용합니다.
- 곤충채집은 독립 대량채집 대상으로 직접 탐색하지 않고 제작 퀘스트의 추천 획득처 경로에서만 사용합니다.
- 기존 가방 100개 획득 경로는 보조/fallback으로 유지합니다.

## 제작
- 음식/아이템 제작은 현재의 퀘스트 기반 최대 10회 배치 구조를 유지합니다.
- 제작 퀘스트에 뜨는 직접 재료와 곤충 같은 퀘스트 전용 재료는 `구하는 방법 → 추천 획득처` 경로로 확보합니다.
- 가공 가능한 중간 재료만 자동가공으로 연결하고, 완료 후 제작 퀘스트로 복귀합니다.
- 제작 UI를 자동가공·자동채집과 같은 남색 카드형 스타일, 화살표 없는 목표 수량 입력, 시작/정지 및 진행 상태 구성으로 통일했습니다.

## 검색 및 안전
- 게임 내 아이템/재료/제작품 검색은 모두 `돋보기 → 입력칸 → 이름 입력 → Enter → 적용 → 정확한 이름 선택` 순서를 사용합니다.
- `execute_gathering`, `execute_altering`, `execute_crafting` 등 비용이 발생할 수 있는 CLI 액션은 계속 프로세스 경계에서 차단하며 조회 전용 CLI와 무료 화면 입력만 사용합니다.
- 낚시·던전·어비스·F10 정지·네트워크 복구 등 기존 기능은 유지합니다.
- 자동 빌드와 회귀 검사는 실제 게임 입력 검증과 구분합니다.

# V2.0.2

사용자가 제공한 Mbi_auto_update.zip을 기준으로 UI와 무료 자동가공·자동채집 구현을 복원한 수정 릴리스입니다. V2.0.1은 GitHub main만 기준으로 만들어 이 ZIP의 누적 변경을 포함하지 못했습니다.

## 기준 파일 및 UI
- 기준 ZIP SHA256: 0a509dc61084f9260065a84a01f3be10838d41f4618191c7e516669f8b225b0d (352,714,967 bytes). 파일 내 버전 표기는 V0.1.96입니다.
- ZIP의 여섯 가공 시설 탭과 시설별 제법 목록, 수량 입력의 화살표 제거, 재료 예상량·실제 진행량 표시를 유지합니다.
- MissingIngredients가 있는 제법은 부족 재료 자동 확보를 위해 선택·시작 가능하며, ZIP의 목표 수량 및 진행 표시를 보존합니다.

## 무료 자동가공·자동채집 및 CLI
- ZIP의 RecursiveAlteringSupplyResolver, 가공 작업 자동 저장·이어하기, 캐릭터 문맥 확인, 현장 무료 가공·설비 이동·수령, 일반 화면 이동·채집과 재화 감소 검사를 복원합니다.
- CLI는 조회 전용입니다. execute_gathering은 정령의 날개 5개를 소모하므로 설정값과 무관하게 프로세스 경계에서 차단합니다. execute_altering, complete_altering_work, stop_action 역시 무료 화면 경로에서 실행하지 않습니다.
- 선택 품목 get_gatherable_items 필터 직접검색을 추가하고 실제 DisplayName/ToolOk를 확인한 다음 ZIP의 화면 이동 경로로 시작합니다. ZIP의 무료 채집을 비활성화하는 V2.0.1 조건은 제거했습니다.
- 최신 main의 CLI 검사 버튼과 capabilities/필터 품목 설명 진단을 ZIP UI에 결합합니다. 검사는 두 조회만 수행하며 시작/정지·유료 명령은 실행하지 않습니다. 검사 중 F9·반복 검사·목록 새로고침 충돌을 막습니다.
- 성공한 주기적 CLI 조회는 ZIP의 파일 전용 로그 경로를 유지하여 화면 로그를 반복 출력하지 않습니다.

## 검증 및 배포
- 낚시·던전·어비스와 업데이트 런타임은 사용자 ZIP 및 최신 main과 대조하여 보존합니다. 사용자 ZIP의 .git, 테스트 빌드, 개인 설정·로그, bin/obj는 배포 소스에 포함하지 않습니다.
- 버전 V2.0.2 / 2.0.2.0, CI 및 Windows Lite ZIP·SHA256·Source ZIP 릴리스 워크플로를 갱신합니다. ZIP 기준과 의도한 차이는 changes/release-source/v202-user-zip-baseline.md에 기록합니다.
- 화면·회귀·빌드 검증과 실제 게임 실행 검증은 구분합니다. 자동화된 검사는 실제 게임을 조작하지 않습니다.

# V2.0.1

V0.1.99에서 자동가공·자동채집 통합 기능을 정리한 메이저 업데이트입니다. 실제 최신 main da3e3ce3ecd45e4df1f63e4cae24d607c70b009b의 코드가 기준입니다.

## 자동 가공
- get_alterable_items의 실제 DisplayName, Alterable, ProducedPerWork와 MissingIngredients(필요/보유 수량)을 사용합니다. +가 붙은 품목을 구분하고, 누락 재료를 전체 재료표로 추정하지 않습니다.
- 목표 추가 수량을 생산량으로 올림 계산합니다. 기존 동일 품목 작업을 먼저 수령한 뒤 보유 수량 기준을 잡고, 등록 횟수·대기열 감소·최종 추가 수량을 검증합니다.
- 메인 화면에서 제법·시설·수량 선택, 시작/정지, 진행 수량을 통합했습니다. CLI 실행은 동일 이름의 첫 제법만 지원하며 유료 가공 허용 조건과 작업당 날개 5개 예약 상한을 유지합니다. 불확실한 등록은 재시도하지 않습니다.

## 자동 채집 및 비용 안전 조건
- get_gatherable_items의 선택 품목 필터 직접검색, 실제 DisplayName/ToolOk, 메인 UI 품목·수량 설정과 도구 상태 검사를 유지합니다.
- CLI 검사는 capabilities와 선택 품목 조회만 실행하고 설명·requiresConfirm·전체 품목 값을 기록합니다. 실행·이동·정지 명령은 호출하지 않습니다.
- execute_gathering은 실제로 정령의 날개 5개를 소모합니다. requiresConfirm 또는 시작 버튼을 무료 실행의 근거로 사용하지 않습니다. 기본 ZeroWingMode에서 메인 시작, 실행 어댑터 및 CLI 프로세스 경계에 차단 조건을 추가했습니다.
- 검증된 무료 시작 명령이 없으므로 기본 무료 자동채집 시작은 차단됩니다. 목록 조회와 CLI 검사는 사용 가능합니다. 유료 채집을 켜는 UI는 제공하지 않습니다.
- 독립 채집 루프의 추가 보유 수량 계산, 도구/가방/행동 상태 확인, 무진행·취소·정지 검증을 유지합니다.

## 릴리스 및 회귀 검증
- 프로그램 V2.0.1, 프로젝트 2.0.1, AssemblyVersion/FileVersion 2.0.1.0 및 CI 검증 상수를 일치시킵니다.
- Windows Lite ZIP, SHA256, Source ZIP을 검증 후 GitHub V2.0.1 초안 릴리스로 준비하는 워크플로를 추가합니다.
- 무료 모드의 typed execute_gathering 호출이 프로세스를 전혀 실행하지 않는 검사와 메인 UI 시작 차단 검사를 추가했습니다. 기존 낚시·던전·어비스 코드는 변경하지 않습니다.
- 업로드 기준 /mnt/data/Mbi_auto_update.zip은 현재 작업 환경에 없어 사용자 테스트 빌드와의 대조 및 실제 게임 검증은 확인되지 않았습니다.

# V0.1.99

2차 조회 전용 CLI 진단을 추가했습니다. 자동 채집 화면에서 **달걀 선택 → CLI 검사 → 로그 전달** 순서로 확인하세요.

- capabilities에서 get_gatherable_items와 execute_gathering의 Description, BodyExample, OutputExample, Note, Metadata(requiresConfirm 포함)를 JSON으로 출력합니다. 줄바꿈과 제어 문자는 안전하게 이스케이프됩니다.

회귀 검사에서 조회 명령만 호출되는지, 액션 경계 진입 금지, 원문과 requiresConfirm 보존, 모든 품목 값 출력, 오류 및 취소 후 종료를 검증했습니다.

## V0.1.94 변경 이력

V0.1.93에서 자동 가공/자동 채집을 별도 화면으로 분리하면서 생긴 UI 이질감과 메뉴 전환 문제를 수정했습니다.

## 기존 홈 UI로 통합

- 별도 ProductionDashboard 오버레이를 제거했습니다.
- 홈, 낚시, 던전, 어비스와 동일한 기존 대시보드 디자인을 그대로 사용합니다.
- 자동 가공/자동 채집을 눌러도 창 전체 UI가 다른 스타일로 바뀌지 않습니다.
- 홈 화면에서 자동 가공을 한 번 눌러 바로 선택할 수 있습니다.
- 자동 채집을 먼저 눌러야 자동 가공이 열리는 레이어/전환 문제를 제거했습니다.

## 표시 통일

- 사용자 표시명은 모두 `자동 가공`, `자동 채집`으로 통일했습니다.
- 자동 가공/채집에서는 기존 정보 카드가 작업 대상, 현재 단계, 진행 수량을 표시합니다.
- 하단 영역에는 기존 카드 스타일로 작업 설정과 CLI 실행 정보를 표시합니다.
- 시작 버튼은 선택 모드에 따라 `자동 가공 설정 / 시작`, `자동 채집 설정 / 시작`으로 표시됩니다.
- 진행률과 통계는 목표 수량 기준으로 계산합니다.

자동화 실행 로직과 CLI 검증 로직은 V0.1.93과 동일하게 유지합니다.
