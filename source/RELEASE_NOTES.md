# Mabi Auto V0.1.90

V0.1.89의 자동채집 기능을 그대로 유지한 상태에서 자동가공 완료품 수령 화면 인식을 수정했습니다.

실제 V0.1.88 오류 스크린샷에서는 **금속 가공** 화면과 **모두 받기** 버튼이 정상 표시되어 있었지만, 작은 `Space` 안내 글자를 OCR로 읽지 못해 수령 전에 정지했습니다.

V0.1.90에서는 수령 화면을 다음 두 조건으로 확인합니다.

- 상단의 큰 시설 제목: `금속 가공`, `목재 가공` 등 선택한 시설명
- 왼쪽의 `모두 받기` 버튼

작은 `Space` 글자는 더 이상 화면 판정 조건으로 사용하지 않습니다. 수령 화면을 두 번 확인한 뒤 Space 키 입력 자체는 기존처럼 한 번만 보냅니다.

기존 2단계 수령 흐름도 유지됩니다. 첫 번째 모두 받기가 가공대로 이동만 시킨 경우, 이동 중에는 추가 입력을 보내지 않고 가공대 도착 후 다시 **시설 제목 + 모두 받기**를 두 번 확인한 뒤 두 번째 Space를 한 번 입력합니다. 실제 수령 여부는 Read-only CLI의 `get_altering_works`로 계속 확인합니다.

V0.1.89 자동채집, 정령의 날개 사용 CLI 명령 차단, 던전, 낚시, Interception, 인벤토리 전리품 판정은 변경하지 않았습니다.
