# MABI AUTO V3.1.54 — 캐릭터 식별 오류 수정 테스트 배포

이 버전은 2026-10-08 19:34:35에 관찰된 **다중가공 캐릭터 식별 정보가 부족해 새 작업/이어하기를 구분할 수 없습니다** 오류를 완화하기 위한 자동업데이트입니다. **Windows 빌드와 모의 입력 회귀 테스트는 통과했지만 실제 게임 CLI 응답에서 오류 해결은 아직 검증하지 못했습니다.**

## 주요 변경 (PR #123)
- N02 배치 보호 유지: 기존 완료 품목 재등록 금지, 배치·소비 거래 기록 원본 보존, 다른 계정/캐릭터 구분 불가 시 중단.
- get_my_info의 최상위 및 Character/Account/Server 구조화 필드 인식 강화. 동일 필드 값이 충돌하면 중단.
- 서버명이 없는 CLI 응답에서도 **동일 계정 코드+캐릭터 이름**으로 식별할 수 있으면 허용 (고유 캐릭터 ID 또는 이름+서버 정책은 유지).
- 다중가공 시작 전에 최대 5회 범위에서 재조회해 **완전한 동일 식별 정보 2회**가 확인된 경우에만 이어하기/신규 작업 처리.
- 중간에 불완전한 CLI 응답이 오더라도 앞서 확인한 ID의 충돌을 놓치지 않도록 차단.

## 검증
- PR #123 Windows CI [#37766985583](https://github.com/skwlrna/Mbi_auto_update/actions/runs/37766985583) 통과(29단계).
- N02 47개, F05 14개, N03 58개, 화면 코드 L2 53개, 자동가공 245개 검사 통과. 모두 실제 게임 입력 테스트가 아닌 fake CLI/정적·컴파일 검증.

## 안전하게 실게임 확인하기
1. 실행 중인 작업은 F10으로 안전 정지하고, 설치 폴더의 설정·템플릿과 `%LOCALAPPDATA%\MabiAuto\multi-altering\batch.json`을 **별도로 백업**합니다. 기존 기록은 삭제하지 마세요.
2. 프로그램 재실행 후 **V3.1.54** 표시와 자동업데이트 적용을 확인하세요.
3. 목재 등 소량으로 시작해 캐릭터 식별 경고가 없어졌는지 확인한 다음, F10으로 멈췄다가 이어할 때 이미 완료한 품목이 다시 등록되지 않는지 살펴보세요.
4. 이전 미확정 배치가 있으면 자동 이어하기가 안전상 거부될 수 있습니다. 저장 파일을 임의 삭제하거나 새로 같은 작업을 등록하지 마세요.
5. 식별 경고가 계속 뜨면 더 이상의 반복 등록을 시도하지 말고 로그/텔레그램 알림과 `get_my_info`의 **민감 필드가 제거된 형태**를 전달하세요.
