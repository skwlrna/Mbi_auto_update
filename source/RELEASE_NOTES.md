# Mabi Auto V0.1.89

- V0.1.88 자동가공 이동 복구 및 2단계 수령 수정을 유지했습니다.
- 자동채집 모드를 추가했습니다. 재료와 추가 수량을 선택하고 구하는 방법의 맨 위 장소로 일반 이동합니다.
- 기존 보유량을 제외한 실제 재료 증가량으로 목표를 확인하고 채집을 정지합니다.
- 정령의 날개를 사용하는 CLI 채집 명령은 차단합니다. 낚시 경로는 지원하지 않습니다.
- 기본 진입은 재료 상세창/구하는 방법 목록입니다. 설정에서 시설·가공 품목을 선택하면 해당 품목을 여는 경로도 사용할 수 있습니다.
- 도구, 가방 용량, 활동 상태, 장시간 무진행 및 정지 확인을 검사합니다. F10으로 중단할 수 있습니다.
- GitHub 배포본은 기존 자동 업데이트를 유지합니다.

빌드·모의 회귀 검사·제공된 사진 인식 검사를 통과했습니다. 실제 게임에서 이동부터 종료까지 전체 동작은 아직 검증하지 않았습니다.
