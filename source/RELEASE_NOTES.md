# Mabi Auto V0.1.85

기존 가공 작업이 있어도 자동 가공을 이어갈 수 있도록 변경했습니다.

- 선택한 품목의 기존 작업이 진행·대기 중이면 오류로 종료하지 않고 완료를 기다립니다. 완료된 작업은 수령하며, 기존 동일 품목 작업을 모두 수령한 뒤 새 목표를 시작합니다.
- 입력 수량은 **추가 생산 수량**입니다. 예: 기존 강철괴 7건이 있어도 강철괴 10개를 입력하면 기존 7건을 완료·수령하고, 이후 4회 등록해 최소 12개를 추가 생산합니다. 기존 작업의 대성공 보상은 새 목표에 포함하지 않습니다.
- 기존 작업을 기다리는 동안 새 작업을 등록하거나 비용 버튼을 누르지 않습니다. F10 정지, 취소 확인, 비용 상한과 불확실한 클릭 재시도 금지를 유지합니다.
- 기존 대기열이 진행되지 않는 상태가 계속되거나 수령을 확인하지 못하면 추가 비용 없이 정지합니다.
- K 진입, 전체 CLI 품목 목록, 7칸 대기열, 완료 수령, 재료 조건 확인과 기존 던전·텔레그램·로그를 유지합니다. CLI 비용 명령은 계속 차단하며 `ZeroWingMode=true` 기본값을 유지합니다.

검증: 빌드, 기존 작업 7건이 가득 찬 상황의 이어가기, 완료·진행 작업 혼합, 대성공 보상 제외, 대기 중 정지와 진행 중단 검사 포함 자동 가공 27개 모의 검사. 기존 전리품·던전 관련 회귀 검사는 GitHub 배포 전에 실행합니다.

실게임에서 가공 시작부터 완료 수령까지의 전체 동작과 다른 시설 화면은 아직 검증 전입니다. 이번 변경은 기존 대기열 처리 로직을 검사했으며 실제 게임에서 새 비용 입력은 실행하지 않았습니다. 화면 확인 실패 시 로그와 `debug/altering/altering-last-failure.png`를 남기고 정지합니다.
