# Mabi Auto V0.1.83

어비스 전리품 11종의 집계를 화면 OCR/아이콘 판정에서 get_items 수량 비교로 교체했습니다.

- 입장 전 기준 수량과 결과 화면에서 확인한 수량을 비교해 실제 증가 개수를 기록합니다.
- 가방·계정창고·캐릭터창고의 동일 품목 수량을 합산하므로 창고 이동만으로 획득을 집계하지 않습니다.
- 룬 장식의 색상 태그는 제거하고 별/등급과 + 유무는 정확히 구분합니다.
- 결과 화면 반복 인식이나 동일 판 재접속에서는 중복 집계하지 않습니다. 다시 하기 전 다음 판 기준값을 저장하고 전투 화면 복귀 확인 후 적용합니다.
- 기준값 없음, CLI 연결 실패, 잘못된 응답, 불안정한 수량은 확인 불가로 기록합니다. OCR 추측으로 대체하거나 미획득으로 확정하지 않습니다.
- 조회는 3초 제한이며 결과 수량은 연속 조회로 안정 여부를 확인합니다. 기존 다시 하기 클릭 전 1초 대기와 화면 재확인은 유지합니다.
- 기존 오늘/누적 기록 파일과 텔레그램 전리품 보고 형식을 유지합니다. 이전에 저장된 통계는 수정하지 않습니다.
- ZeroWingMode=true 기본값과 비용 명령 차단을 유지합니다. 자동 가공은 추가하지 않았습니다.

게임이 실행 중이고 MM AI Agent Activation 옵션이 켜져 있어야 전리품 수량을 조회할 수 있습니다. 도중에 매크로를 시작해 입장 전 기준값이 없는 첫 판은 확인 불가이며, 다음 판부터 정상 비교합니다.

검증: 빌드, 전리품 수량 비교/중복 방지/창고 이동/오류 처리 검사, 기존 던전·재시도 회귀 검사, 실제 인벤토리 읽기와 비교. 실제 던전 보상 획득까지 자동 실행하지는 않았습니다.
