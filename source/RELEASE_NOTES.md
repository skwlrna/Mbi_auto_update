## 수정 내용 (F9 K 메뉴 탐색 전용)
1. 현재 F9가 보이는 K 가공 메뉴의 세 개 독립적인 하단 글자 영역(빠른 제작/제작/연금술)을 화면 고정 구조로 검증. 800×1000 레이아웃과 기존 가공 허브/시설창 분리 조건 유지.
2. 160ms 간격으로 실제 화면 **2프레임**에서 같은 구조가 확인되면 기존 한국어 OCR 3회(초기 메뉴 탐색 + ClickLabel 두 번)를 생략하고 검증된 가공 탭 (360,948)에 1회 클릭.
3. 화면에는 실제 모달 패널/확인 버튼이 없어야 하며, 클릭 직전 중간관리자의 기존 `RequireManagedIdleAsync` CLI 비이동/비채집/비전투 검사를 통과해야 함.
4. 메뉴 구조가 불명확하면 고정 좌표로 누르지 않고 기존 bounded OCR 검사를 그대로 사용. F9 일반 필드 HUD가 먼저 확인되면 메뉴 글씨 OCR 없이 기존 안전한 K 진입 경로로 진행.
5. F9 K 진입 직후의 화면 대기 과정은 시설 화면·6카드 가공 허브·하단 메뉴의 **구조만** 확인하며 불필요한 반복 OCR을 하지 않음. 실제 품목/시설의 정확한 이름은 기존 OCR/검증 규칙 유지.
6. 일반 단일가공, 채집의 굵은 나무 OCR 2프레임, 완료품 수령, 설비 이동 Space, 원재료·중간재료 계산 및 저장 복원 로직은 변경하지 않음.

## 검증 및 제한
- 실컴파일된 F9 메뉴 경로에서 CLI 유휴·팝업 차단·화면 2회 구조 인식 후에만 고정 탭 클릭하는 L2 검사.
- 필드 풀밭 / 허브 / 확인 팝업 / 클라이언트 크기 불일치에 대한 합성 화면 회귀 테스트.
- 메뉴 화면 레이아웃은 기존 캡처 기반이라 게임 UI가 달라지면 OCR fallback 또는 안전 정지가 발생할 수 있음. 새 버전 적용 후 적은 작업 수로 실게임 테스트 필요.
