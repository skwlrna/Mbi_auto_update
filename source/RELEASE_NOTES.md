# MabiAuto V3.1.58 — F9는 새 목표 0부터, 이전 게임 작업 유지

- 사용자가 F9를 누르면 예전에 입력했던 가공 수량·품목 진행률을 이어받지 않고 **이번에 입력한 수량을 0부터** 가공합니다.
- 같은 설비에 이전 가공 작업이 진행 중이거나 완료되어 있어도 시작할 때 **취소하지 않고, 강제 수령하지 않고, 전부 완료될 때까지 기다리지 않습니다**.
- 7칸 중 빈 슬롯이 있으면 새 작업을 즉시 등록합니다. 만석이면 기존 중간관리자의 시설별 전체 완료/묶음 수령 규칙을 따릅니다.
- 전체 시설 수령이 가능한 정상 시점에는 기존 작업도 함께 수령될 수 있습니다. 다만 이전 작업의 생산량은 이번 새 목표 완료량에 포함하지 않습니다.
- 지난번 F10 또는 종료한 배치를 다시 열거나 자동 이어하지 않습니다. 새 F9는 매번 독립적인 장부를 새로 만듭니다.
- 기존 N02 등록 확인, F05 재료 소비 기록, F10 중단, 화면 검증, 정령의 날개 미사용, 위치와 수령 안전장치를 유지합니다.

## 검증
Windows CI 회귀 테스트에서 이전 작업 1건 후 새 F9 전체 수량 재등록, 기존 완료 미수령 작업이 있는 경우 새 목표 독립 완료, 기존 작업이 진행 중인 상태에서 나머지 6칸 등록, 정상 시설별 수령, F10 정지를 검사합니다.

실게임 확인은 별도로 필요합니다. 업데이트 후 처음에는 10개 이하 소량으로 시험하는 것을 권장합니다. 업데이트 설정과 자동 롤백은 유지합니다.
