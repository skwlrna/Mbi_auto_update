# MabiAuto V3.1.59 — 시설 고정좌표 우선 · 1차 통과 후 반복 OCR 생략

## 가공 시설 화면 인식 수정
- V3.1.58 10월 9일 03:08:57 오류: 목재 가공 화면이 표시돼 있었는데도 시설 제목 OCR이 틀려 이동 확인 제한시간으로 중단된 상황을 수정했습니다.
- 기존 설비 이동 좌표 (85,235) 및 시설·품목의 고정좌표는 변경하지 않았습니다.
- 시설 제목 OCR의 최초 검색 범위가 실제 고정 제목 왼쪽 일부를 잘라내던 문제를 고쳤습니다.
- 이동 후에는 제목과 시설 레벨 문구의 **두 고정 화면 위치**로 시설 화면을 먼저 확인합니다. 고정된 화면 구조가 확인되면 제목 OCR 때문에 도착 판단을 지연하지 않습니다.
- 도착으로 확정된 시설은 이후 진입 경로에서 제목 OCR을 다시 강제하지 않습니다.

## 반복 가공: 최초 1차 확인 이후 OCR 사용 안 함
- 현재 F9 실행에서 같은 시설에 대한 첫 등록을 성공한 뒤, 중간관리자가 해당 시설 재사용을 지시하는 반복 작업에서는 시설 제목 OCR을 호출하지 않습니다.
- **동일한 고정좌표 품목**을 성공적으로 처음 등록한 뒤에는 반복 등록 때 재료 문구 OCR, 품목명 OCR, 무료/유료 실행 문구 OCR을 호출하지 않습니다. 미확인 품목의 첫 등록에는 기존 제법 동일성 확인을 유지합니다.
- 반복 작업에는 검증된 고정 카드 좌표, 고정 무료 가공 버튼의 실제 색상·크기, 팝업 검출 및 읽기 전용 CLI 상태를 사용합니다. 기존 F10 정지와 위험한 잘못된 가공 입력 방지는 유지합니다.

## 변경하지 않은 동작
- F9에서 입력한 새 목표 0부터 시작, 이전 가공 중인 작업 그대로 유지, 시설별 7칸 혼합 대기열, 전체 완료 후 모두 받기, N02/F05 등록 기록, F10 정지.
- 사용자의 게임 화면과 입출력은 800×1000 기준입니다. 기존 버전으로 롤백할 수 있습니다.

CI의 Windows 실제 가공 화면 통합 회귀 테스트 및 기존 N02/F05 회귀 테스트를 통과한 이후에만 Release를 게시합니다. 실게임에서는 우선 소량으로 확인해 주세요.
