# MabiAuto V3.1.63 — 가공 허브/K 메뉴 화면 오인식 수정

## V3.1.62 대비 변경사항
- **2026-10-09 13:20 실제 실패 화면**에서 금속·목재·가죽·옷감·약품·식재료 카드가 이미 표시된 800×1000 가공 허브를, 하단의 영구적인 '가공' 탭 하나 때문에 K 메뉴로 잘못 인식한 문제를 수정했습니다.
- 상단 '가공' 제목과 위아래 2줄/총 6장 카드의 **고정 화면 구조**를 확인하면, OCR 결과에 앞서 가공 허브로 판정하고 기존 시설 제목 **고정좌표를 클릭**합니다.
- K 메뉴의 '가공' 항목 인식/클릭은 허브 구조 판정 뒤에만 실행하며, K 후 다시 캡처한 화면에도 허브 고정 구조를 우선 적용합니다.
- 실제 가공 허브에서 하단 '가공' 탭이 상존하더라도 중복으로 클릭하지 않습니다. 6장 허브가 단일 시설 화면으로 잘못 승인되는 것도 차단합니다.
- 동일 시설 OCR 생략 캐시, 시설/품목/버튼 고정좌표, 활동/이동 확인, 팝업 차단, 수령/Space/정령의 날개 안전 기준은 유지합니다.

## 회귀 테스트
- 컴파일된 실코드 800×1000 시각 판정: 하단 탭만/카드만/상단 카드만 표시된 부분화면은 허브로 판정하지 않고, 상단 제목+두 줄의 6장 카드 구조가 보일 때만 허브로 판정하는 테스트 추가
- OCR 엔진 없이도 실제 허브가 즉시 감지되는 경로 확인
- PR과 병합된 main의 Windows 전체 CI 통과 후에만 V3.1.63 배포
- 실제 게임에서의 모든 입력 시나리오를 자동 검증한 것은 아니므로 배포 후 목재/금속 다중가공 소량 테스트 권장
