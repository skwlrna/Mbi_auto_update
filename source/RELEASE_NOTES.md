# Mabi Auto V0.1.84

자동 가공 모드를 추가했습니다. 가공 → 시작(F9)에서 시설, CLI 전체 품목, 목표 생산 수량을 선택합니다. 일반 화면에서는 K로 메뉴를 열고 가공 탭과 선택 시설로 이동합니다.

- 무료 CLI 조회로 전체 제법·생산 수량·재료 부족·진행 시간·완료 상태를 읽습니다. `+` 품목과 재료별 제법을 구분합니다.
- 목표 수량을 1회 생산 수량으로 올림 계산합니다. 예: 강철괴 100개, 1회 3개이면 34회·최소 102개입니다. 대성공은 추가 보상입니다.
- 화면의 **가공하러 가기 / 정령의 날개 5개** 버튼만 사용합니다. 설정창에 비용 상한을 표시하며 사용 체크를 끄면 비용 버튼 입력을 차단합니다. 앞 예의 상한은 170개입니다.
- 7칸 대기열, 완료 수령(Space), 최종 보유 수량 증가를 확인합니다. 기존 동일 품목의 진행 작업이 있으면 새 실행을 차단합니다. 이미 완료된 선택 시설의 작업은 시작 전에 수령합니다.
- 화면·품목·비용·등록 상태를 확인하지 못하면 추가 입력 없이 정지합니다. 불확실한 비용 클릭은 재시도하지 않습니다. 같은 이름의 제법은 전체가 한 화면에서 확인되는 경우에만 선택합니다.
- CLI `execute_gathering`, `execute_altering`, `execute_crafting`, `complete_altering_work`는 계속 차단합니다. `ZeroWingMode=true` 기본값을 유지하며 화면 비용 허용은 설정창의 별도 선택입니다.
- 기존 던전 흐름과 전리품 비교, 텔레그램 오류 알림, 로그 구조를 유지합니다. F10으로 정지해도 이미 등록된 게임 작업은 계속될 수 있습니다.

검증: 빌드, 무료 CLI 6개 실제 조회, 자동 가공 수량·대기열·비용 제한·중복 방지 모의 검사, 기존 회귀 검사, 제공된 금속 사진의 제목·품목 후보·실행 버튼·비용 5·수령 단축키 인식.

**실게임에서 가공 시작부터 완료 수령까지의 전체 동작은 아직 검증하지 못했습니다.** 원격 게임 캡처가 실패하여 제공 사진으로 화면 인식을 검사했습니다. 목재·가죽·옷감·약품·식재료와 전체 품목의 실제 화면도 검증 전입니다. 화면 확인이 안 되는 품목은 정지하며 로그와 `debug/altering/altering-last-failure.png`를 남깁니다. 최초 사용은 소량으로 확인하세요.
