# Mabi Auto V0.1.93

자동채집과 자동가공 화면을 mobi-Support 계열의 다크 대시보드 스타일로 전면 개편했습니다.

## 자동채집 / 자동가공 전용 화면

- 좌측 사이드바: 홈, 낚시, 던전, 어비스, 자동가공, 자동채집, 설정
- 상단 상태칩: 게임 연결, CLI 연결, 캐릭터 확인
- 설정 카드: 최근 선택 품목/제법과 목표 수량
- 실행 상태 카드: 현재 상태, 진행 수량, 진행률, 경과 시간, 실행 방식/가공 위치
- 제어 카드: 큰 시작/정지 버튼
- 상태 정보 카드: CLI, 캐릭터, 재화 조회 상태
- 하단 상세 로그: 자동채집/자동가공/CLI 로그만 별도 표시

기존 자동채집/자동가공 실행 로직과 검증 절차는 유지합니다. 시작 버튼을 누르면 기존의 검증된 설정창에서 품목과 수량을 확정하고, 실행이 시작되면 전용 대시보드에 선택값과 진행 상황이 실시간으로 표시됩니다.

정령의 날개 항목은 새 대시보드 전면 화면에 표시하지 않습니다. 비용 관련 실행 정책 자체는 기존 자동화 검증 로직을 그대로 유지합니다.
