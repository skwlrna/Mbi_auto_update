# Mabi Auto V0.1.88

자동 가공의 **모두 받기 2단계 동작**을 반영했습니다.

실게임에서 확인한 흐름은 다음과 같습니다.

1. 완료 작업이 있을 때 첫 번째 **모두 받기(Space)** 를 누르면 즉시 수령되는 것이 아니라 가공대로 자동 이동합니다.
2. 가공대 도착 후 같은 가공 화면과 **모두 받기**가 다시 표시됩니다.
3. 두 번째 **모두 받기(Space)** 를 눌러야 실제 완료 작업이 수령됩니다.

V0.1.88은 첫 입력 후 바로 성공으로 가정하지 않습니다. Read-only CLI의 `get_altering_works`로 작업 수가 실제 감소했는지 먼저 확인하고, 감소하지 않았을 때만 가공대 도착 화면을 수동 입력 없이 기다립니다. 동일한 시설 제목과 Space 표시를 두 번 확인한 뒤 두 번째 Space를 정확히 한 번 입력합니다.

첫 번째 입력만으로 작업 수가 감소한 경우에는 두 번째 입력을 하지 않습니다. 가공대로 이동하는 동안 K키나 메뉴 입력을 보내지 않으며, 2차 수령 화면을 제한 시간 안에 확인하지 못하면 추가 입력 없이 정지합니다.

V0.1.87의 시설 화면 복구, CLI 비용 명령 차단, Interception, 던전, 낚시, 인벤토리 전리품 판정은 그대로 유지합니다. 자동채집 기능은 이번 버전에 포함하지 않았습니다.

검증: 자동 가공 회귀 검사에 '1차 모두 받기=이동, 2차 모두 받기=실제 수령' 시나리오를 추가했습니다. GitHub Windows CI에서 전체 빌드/회귀 검사를 통과한 뒤 릴리스합니다.
