# MabiAuto V3.1.61 — 중간관리자 수령 완료창 인식 개선

## V3.1.60 대비 변경사항
- **다중가공 중간관리자가 지시한 수령 완료 확인창**에서 '가공 완료' 제목 OCR이 놓쳐도, 800×1000 화면의 고정 보상 구조(파란 보물상자 광원, 갈색 상자 본체, 흰 제목 영역, 청록 보상 카드)가 함께 확인되면 제목 OCR을 필수로 요구하지 않습니다.
- **수령 성공은 반드시 별도 CLI로 검증**합니다. 수령 전 해당 시설 작업 수 > 0, 수령 후 신선한 조회 결과가 정확히 0인 경우에만 결과창 닫기를 허용합니다.
- Space 입력 전후 중간관리자 CLI 활동 idle(false), 시설 화면·이동 팝업 배제, 자동이동 false, 실제 초록 확인 버튼, 입력 전 최종 재검증을 유지합니다.
- 다른 초록색 확인창이나 구조가 불일치한 화면에서는 Space 입력을 차단합니다. 완료창 Space는 최대 2회로 제한하며, 닫힌 뒤 시설 화면 2프레임 복귀를 확인합니다.
- 제목 OCR은 고정 보상 구조가 불분명할 때 보조 판별로 사용하고, 보상 구조나 OCR만으로 CLI 수령 확인을 대신하지 않습니다.

## 유지 사항
- V3.1.60의 **음식 제작 기준 약품 돋보기 검색 흐름**, 고정 검색 좌표와 결과 선택 흐름 그대로 유지
- 시설 최초 확인 뒤 동일 시설 반복 시 OCR 생략, 고정좌표 인식, 다른 제법 오선택 방지, F9 신규 목표 수량 0부터 시작, F10 안전 정지 유지
- **다중가공 지연시간은 변경하지 않음**(안정성 우선)
- 단일가공과 다른 유형의 팝업 동작은 변경하지 않음

## 검증
Windows GitHub Actions의 전체 생산 코드 빌드와 자동 회귀 검사, 실제 코드 경로 검사(L2), 합성 800×1000 확인창 화면 테스트가 통과한 소스만 Release로 배포합니다. 실제 게임 화면에서의 입력/인식 검증(L4/L5)은 수행되지 않았으므로 소량 수령부터 확인해 주세요.
