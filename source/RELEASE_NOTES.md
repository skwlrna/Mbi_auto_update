# V3.1.32

같은 다중가공 목록에서 한 품목의 결과물이 다른 품목의 재료로 소비될 때, 정상적인 내부 재료 소비를 완성품 감소 오류로 오판하던 문제를 수정합니다.

- 작업 등록 직전/직후의 짧은 구간에서 다른 선택 품목 결과물의 실제 보유량만 비교합니다.
- 등록이 실제 대기열에 1건 추가된 것이 확인된 뒤 그 구간에서 감소한 수량만 내부 재료 소비로 인정합니다.
- 예: 강철괴 등록으로 철괴가 239 → 236으로 감소하면 철괴 3개를 내부 소비 보정값으로 기록합니다.
- 철괴 생산 진행/완료 판정은 실제 보유량 + 내부 소비 보정량으로 계산하므로 강철괴가 철괴를 사용해도 철괴 생산 실적이 사라지지 않습니다.
- 내부 소비 보정값은 품목별 이어하기 세션에 저장되어 앱 재시작 후에도 유지됩니다.
- 작업 등록 시간 밖에서 발생한 결과물 감소는 기존과 동일하게 외부 소비 가능성으로 보고 안전 정지합니다.
- 기존 같은 시설 7칸 라운드로빈, 배치 전체 완료 전 이동 금지, 중간재료 통합 스케줄러, 정령의 날개 0개 규칙은 그대로 유지합니다.

# V3.1.29

다중가공 중 부족한 중간 가공재료를 별도 단일가공으로 실행하지 않고, 메인 다중가공과 같은 시설별 7칸 배치 스케줄러로 처리합니다.

- 중간재료가 필요한 경우 해당 시설의 현재 작업이 한 칸이라도 진행 중이면 추가 이동/등록하지 않고 배치 전체 완료까지 기다립니다.
- 현재 시설 배치가 모두 완료되면 기존 검증된 수령 로직으로 한 번에 수령한 뒤 실제 인벤토리 부족량을 다시 계산합니다.
- 기존 완료 배치 수령만으로 중간재료 부족량이 해소되면 중간재료 작업을 추가 등록하지 않습니다.
- 아직 부족한 경우에만 빈 시설을 중간재료 배치가 소유하고, 메인 다중가공과 동일한 MultiAlteringCoordinator를 이용해 최대 7칸씩 처리합니다.
- 중간재료 처리 중 더 하위 중간재료가 필요해도 같은 스케줄러/재귀 재료 해결기를 사용합니다.
- 중간재료 전용 이어하기 세션을 품목 고유키로 저장해 중단 시 중복 등록을 방지합니다.
- 완료 후 요청 시점 대비 실제 중간재료 증가량을 다시 검증한 뒤 상위 가공을 재개합니다.
- 기존 단일가공은 검증된 재귀 단일 실행 경로를 그대로 유지하며, 이번 통합 스케줄러는 다중가공에만 주입됩니다.
- 기존 0 정령의 날개, 완료품 수령 Space 검증, 같은 시설 혼합 7칸, 배치 전체 완료 전 이동 금지 규칙은 그대로 유지합니다.

# V3.1.11

V3.1.10 실게임 로그에서 자동 가공/다중가공 이어하기가 `작업 등록 확인` 체크포인트에서 멈춘 뒤, 기존 동일 품목 작업이 먼저 완료·수령되어 대기열이 `저장 전 1건 → 현재 0건`으로 줄면 중복 등록 안전장치가 상태를 확정하지 못하고 중단하던 문제를 수정한 패치입니다.

## 이어하기 복구
- 중단 직전 등록 대기 상태에서 동일 품목 대기열이 줄어든 경우, 마지막 확인 이후 완성품 보유량 증가를 함께 비교합니다.
- 사라진 기존 작업의 최소 생산량만으로 현재 완성품 증가를 설명할 수 있고, 중단 직전 새 작업까지 등록되었다고 보기에는 생산량이 부족한 경우에만 **새 작업은 등록되지 않았음**으로 안전하게 확정합니다.
- 이 경우 체크포인트를 정리한 뒤 남은 작업만 정상적으로 이어서 등록합니다.
- 완성품 증가량만으로 두 경우를 구분할 수 없으면 기존 원칙대로 입력 전에 정지해 중복 등록을 막습니다.

## 회귀 방지
- 실게임 오류와 같은 `저장 전 1건 / 현재 0건` + 기존 작업 수령 시나리오를 자동 가공 회귀 테스트에 추가했습니다.
- 완성품 증가량이 커서 중단 직전 등록 여부가 모호한 시나리오는 새 입력 없이 정지하는 테스트를 추가했습니다.
- 단일가공 엔진을 순차 재사용하는 다중가공에도 동일 수정이 적용됩니다.
- 식재료 고정좌표, 약품 검색, 가죽 보유재료 전용 정책, 설비 이동/현장 판정 로직은 변경하지 않습니다.

제작 퀘스트를 만든 뒤 재료명을 처음 추측하는 대신, 퀘스트 생성 전에 현재 제작 배치의 레시피 재료명을 먼저 읽어 기준 후보로 사용하는 패치입니다.

## 제작 레시피 선판독
- 제작 시작 시 기존처럼 `get_craftable_items(품목명)` 조회를 먼저 수행합니다.
- 제작 상세 화면에서 실제 제작 횟수(예: 10회)를 설정한 뒤 재료 수량과 함께 재료명도 먼저 읽습니다.
- CLI의 1회 기준 부족 재료 후보와 상세 화면의 현재 배치 재료명을 합쳐 이번 배치의 재료 후보를 확정합니다.
- 상세 화면 OCR 이름은 실제 품목 카탈로그와 정확히 일치하는 이름만 후보에 추가해 잘못 읽은 이름이 기준값으로 굳어지지 않게 합니다.

## 퀘스트 OCR 보정 우선순위
- 퀘스트 재료명은 전체 품목 목록보다 이번 배치에서 미리 확정한 레시피 재료 후보를 먼저 비교합니다.
- 예: 현재 레시피 후보가 `감자 / 양파 / 양배추 / 허브`일 때 퀘스트 OCR이 `양합`이면 `양파`로 보정합니다.
- 전체 카탈로그의 `양털` 같은 비슷한 이름 때문에 동률로 중단되는 문제를 피합니다.
- 레시피 후보에서 확정되지 않는 경우에만 기존 전체 카탈로그 안전 보정 경로를 사용합니다.

## 유지되는 보호
- 2~10회 제작의 실제 재료 충분 여부는 상세 화면의 배치 수량 비율을 2프레임 확인하는 기존 방식을 유지합니다.
- 제작 완료는 실제 완료창 기준이며 재고 증가는 완료 판정에 사용하지 않습니다.
- 정령의 날개를 쓰는 CLI 제작/채집/가공 액션은 계속 차단합니다.

# V3.0.29

제작 퀘스트 재료명 OCR 보정이 짧은 문자열에서 너무 넓은 후보를 잡던 문제를 수정한 패치입니다.

## 재료명 보정 방식
- 부분문자열 유사도(`ContainsApprox`)를 재료명 자동 보정에 사용하지 않습니다.
- 먼저 현재 제작 레시피의 실제 부족 재료 후보를 우선 비교합니다.
- 그다음 전체 실제 품목 목록을 대상으로 이름 전체의 편집거리, OCR 문자열 전체 접두 일치 여부, 공통 접두 길이, 길이 차이를 순서대로 비교합니다.
- 가장 좋은 후보가 하나일 때만 자동 보정합니다.
- 실제 로그 사례인 `양배 → 양배추`, `감사 → 감자`를 회귀테스트에 추가했습니다.
- 진짜 동률 후보가 남으면 임의로 고르지 않고 안전하게 중단합니다.

## 유지되는 보호
- 회색 재료명 전용 3배 확대/저임계값 OCR 보강은 그대로 유지합니다.
- 추천 획득처는 대상 재료명 2프레임 확인 후 고정좌표 `(400,650)`를 사용합니다.
- 제작 완료는 실제 완료창 기준이며 재고 증가는 완료 판정에 사용하지 않습니다.

제작 퀘스트 팝업에서 밝은 재료 수량은 인식되지만 왼쪽 회색 재료명이 OCR에서 누락되어 중단되던 문제를 수정한 패치입니다.

## 제작 퀘스트 재료명 판독
- 기존 전체 재료 영역 OCR은 수량 비율 판독에 그대로 사용합니다.
- 같은 행의 재료명이 누락되면 그 행의 왼쪽 이름 칸만 좁게 다시 잘라 3배 확대/저임계값 고대비 OCR을 수행합니다.
- `감자 1/80`, `양파 2/30`, `양배추 0/60`, `허브 4/20`처럼 수량만 먼저 잡혀도 회색 재료명을 행 단위로 복구할 수 있습니다.
- 보강 OCR 후보가 하나로 확정되지 않으면 임의의 재료명을 선택하지 않고 기존처럼 안전하게 중단합니다.
- 이후 실제 재료 행 클릭 전에는 해당 재료명을 다시 두 프레임 확인하므로 잘못된 이름으로 입력을 진행하지 않습니다.

## 유지되는 보호
- 추천 획득처는 대상 재료명 2프레임 확인 후 고정좌표 `(400,650)`를 사용합니다.
- 제작 배치 재료 판정, 완료창 기준 제작 종료, 이동 중 CLI 일시 거부 재시도 정책은 그대로 유지합니다.

# V3.0.25

생활 스킬 대량채집의 실제 화면 흐름과 제작 배치 재료 판정을 최신 런타임 로그에 맞게 수정한 패치입니다.

## 생활 스킬 자동채집
- 생활 스킬 상세 팝업에서 화면에 존재하지 않는 `100회 채집` 문구를 찾던 단계를 삭제했습니다.
- `굵은 나무` 등 대상 상세 팝업 확인 후 `가까운 위치 찾기`를 800×1000 고정좌표 `(300, 534)`로 클릭합니다.
- 이후 게임의 자동 이동/자동채집을 그대로 기다리고, 자동채집의 자연 종료와 실제 재고 증가로 100회 1사이클 종료를 확인합니다.
- `100회`는 행동 횟수이며 `100개` 획득과 동일하게 취급하지 않습니다.
- 목표 실제 수량이 부족하면 다음 100회 사이클을 다시 시작하고, 목표 수량에 도달하면 원래 자동가공 흐름으로 복귀합니다.

## 제작 2~10회 재료 판정
- CLI `Craftable`만으로 직접 제작 여부를 결정하지 않습니다.
- 제작 횟수를 설정한 뒤 상세 화면에 표시된 실제 배치 재료 비율을 2프레임 확인합니다.
- 예: 10회 설정에서 `65/80`, `24/30`, `52/60`, `16/20`처럼 하나라도 부족하면 반드시 `퀘스트 만들기` 경로를 사용합니다.
- 화면 재료 비율을 안정적으로 읽지 못한 경우에도 안전하게 퀘스트 경로를 사용합니다.
- 실제 배치 재료가 모두 충분하고 CLI 제작 가능 상태도 확인된 경우에만 `제작하러 가기`를 사용합니다.

## 유지되는 보호
- 제작/가공/채집의 지역 이동 중 CLI 일시 거부 재시도 및 이동 중 재고 조회 생략 정책은 그대로 유지합니다.
- 제작 완료는 재고 증가가 아니라 실제 제작 완료/확인 결과창으로만 판정합니다.

# V3.0.24

연속 제작 중 재고 증가를 제작 완료로 오판하던 문제를 수정한 패치입니다.

## 제작 완료 판정
- 제작 중 재고 증가는 진행 상황/진단 정보로만 사용합니다.
- 대성공으로 요청 수량 이상의 결과물이 먼저 쌓여도 제작 완료로 판단하지 않습니다.
- 제작대 사용중 상태가 풀리는 것만으로도 완료 처리하지 않습니다.
- 실제 제작 완료 또는 확인 결과창이 2프레임 연속 확인되고 fresh 프레임에서도 다시 확인된 경우에만 완료로 인정합니다.
- 실제 결과창이 확인되기 전에는 완료 확인용 Space 입력을 보내지 않습니다.

## 완료 후 재고 검증
- 실제 완료창을 닫은 뒤에만 배치 결과 재고를 검증합니다.
- 10회 제작이면 완료창 확인 후 최소 10회분 결과가 반영됐는지 확인합니다.
- 이 재고 검증은 완료를 결정하는 신호가 아니라 완료창 이후 결과 일관성 검사입니다.

## 검증
- 제작 중 재고량 또는 busy/idle 전환이 완료 신호로 다시 사용되지 않도록 CI 보호 조건을 추가했습니다.
- 기존 crafting/V3 회귀 검사 69개와 전체 production CI를 통과했습니다.

- 생활 스킬 진입 실패 원인을 추적할 수 있도록 C 입력, 생활 스킬 메뉴 확인, 생활 스킬 진입 클릭 완료 로그를 추가했습니다.
- 설비 이동 및 채집 이동 중 불필요한 Space 입력 금지 규칙은 그대로 유지합니다.

## 제작

- 이후 별도의 제작대 복귀 단계 OCR/클릭을 수행하지 않고 게임의 자동 제작대 복귀를 기다립니다.

- Windows 빌드, 자동 가공·자동 채집·제작 및 V3 production engine 회귀 검사를 통과하도록 CI 보호 조건을 추가했습니다.

# V2.0.3

V2.0.2 이후 실제 게임 화면 확인 내용을 반영해 제작·자동채집·자동가공의 무료 화면 경로를 보강한 릴리스입니다.

## 자동 가공
- `설비로 이동` 클릭 뒤 확인 팝업으로 오인해 Space를 누르던 경로를 제거했습니다.
- 설비 이동은 추가 키 입력 없이 게임의 자동이동을 기다리고, 시설 화면에서 `설비로 이동` 버튼이 사라진 상태를 안정적으로 확인한 뒤 현장 가공을 계속합니다.
- 가공 완료 결과 확인에 필요한 Space 동작은 기존대로 유지하며 설비 이동 Space와 분리합니다.

## 자동 채집
- 단독 자동채집과 자동가공 부족 원재료 확보는 가방 100개 퀘스트보다 **생활 스킬 100회 채집**을 우선 사용합니다.
- 100회마다 실제 CLI 재고 증가량을 확인하고 목표에 부족하면 반복합니다. 100회=100개라고 가정하지 않습니다.
- 일상 채집, 나무 베기, 광석 캐기, 약초 채집, 양털 깎기, 추수, 호미질의 확인된 재료-채집 대상 매핑을 추가했습니다.
- `○○ 버섯 포자`는 `○○ 버섯`으로 변환해 찾으며, 개암 버섯 계열은 호미질로 처리합니다.
- 생활 스킬 목록은 개별 품목의 고정 Y좌표 대신 OCR 정확 이름, 같은 행 아이콘 영역 확인, 스크롤 재탐색을 사용합니다.
- 곤충채집은 독립 대량채집 대상으로 직접 탐색하지 않고 제작 퀘스트의 추천 획득처 경로에서만 사용합니다.
- 기존 가방 100개 획득 경로는 보조/fallback으로 유지합니다.

## 제작
- 음식/아이템 제작은 현재의 퀘스트 기반 최대 10회 배치 구조를 유지합니다.
- 제작 퀘스트에 뜨는 직접 재료와 곤충 같은 퀘스트 전용 재료는 `구하는 방법 → 추천 획득처` 경로로 확보합니다.
- 가공 가능한 중간 재료만 자동가공으로 연결하고, 완료 후 제작 퀘스트로 복귀합니다.
- 제작 UI를 자동가공·자동채집과 같은 남색 카드형 스타일, 화살표 없는 목표 수량 입력, 시작/정지 및 진행 상태 구성으로 통일했습니다.

## 검색 및 안전
- 게임 내 아이템/재료/제작품 검색은 모두 `돋보기 → 입력칸 → 이름 입력 → Enter → 적용 → 정확한 이름 선택` 순서를 사용합니다.
- `execute_gathering`, `execute_altering`, `execute_crafting` 등 비용이 발생할 수 있는 CLI 액션은 계속 프로세스 경계에서 차단하며 조회 전용 CLI와 무료 화면 입력만 사용합니다.
