# MabiAuto V3.1.67 — 중간관리자 수령 완료창 회색 보상 대응

## 실제 오류 근거
- 2026-10-09 18:13 V3.1.66: 금속 가공 강철괴 7건을 수령해 CLI 시설 작업 수가 7→0으로 줄었습니다.
- 게임 화면은 실제 "가공 완료" 결과와 초록 확인 버튼, 회색 아이템 보상이었지만, 기존 청록색 카드 기반 고정 보상 구조와 제목 OCR이 모두 실패하여 중단됐습니다.
- V3.1.50에서는 초록 완료 확인 버튼, 시설창 부재, 이동 팝업 부재를 확인하는 완료창 닫기 경로가 정상 동작했습니다.

## 변경 범위: 중간관리자 수령 승인 정책만
- `AlteringReceiptPolicy.CanCloseManagedCompletionResult`의 7인자 **중간관리자 전용 경로**에 안전 조건부 대체 판정을 추가합니다.
- 수령 전 해당 시설의 작업 수 > 0, 수령 후 **시설 전체 작업 수가 정확히 0**, 실제 초록 완료 확인 버튼, 시설창 부재, 이동 팝업 부재, CLI 비이동(false)이 모두 검증되면 제목 OCR과 청록색 보상 카드 검출이 모두 실패해도 완료창을 닫을 수 있습니다.
- 하위 `dungeon/AlteringScreen.cs` 및 화면 픽셀 검출·OCR·UI 클릭 좌표·단일가공 정책은 **전혀 변경하지 않습니다**. 기존 중간관리자 CLI 유휴 검사, Space 전 새 화면 재확인, 수령 Space 최대 횟수, 시설 복귀 검증은 유지합니다.
- 시설 전체 수령이 미확인(7→7 / 7→6 / 조회불가), 이동 중/미확인, 여행 팝업, 시설창 또는 초록 버튼 부재에서는 여전히 Space 입력 없이 중단합니다.
- 다만 보상 구조를 별도로 확인하지 못한 경우 기존보다 팝업 판별 근거가 하나 줄어드므로, 최초 실게임 사용은 소량 수령으로 검증해야 합니다.

## 회귀 확인
- 중간관리자 7→0 + OCR 실패 + 청록색 검출 실패 + 초록 완료 확인 버튼 + CLI 비이동 => 승인.
- 작업 수 전체 수령 증거 없음, 초록 버튼 없음, 시설/이동 팝업, CLI 이동 중 또는 불명 => 거부.
- 단일가공의 기존 제목/결과 판정, 하위 화면 탐지, 기존 청록색 카드 이미지 검사는 변경하지 않습니다.
- GitHub Windows CI 통과 후에만 공식 Windows Lite 업데이트를 게시합니다.
