# MabiAuto V3.1.64 — V3.1.56 근거리 즉시 도착 판정의 수령 경로 복원

## 오류 근거
- 2026-10-09 13:41 V3.1.63 오류: 목재 가공 허브/시설 진입 정상, 원격 설비 이동 버튼 사전 검출, 이동 고정좌표 (85,235) 1회 클릭.
- 클릭 이후 69초 동안 CLI 자동이동 상태가 관측되지 않았고, 시설 화면이 표시되어도 관리자 Fresh 이동 완료로 승인되지 않아 안전 정지.
- V3.1.56에서 이미 짧은 이동 대응용 **이중 앵커 근거리 즉시 도착**을 구현했지만, 최근 버전의 `!receiptMode` 제약 때문에 **수령용 Fresh 이동에는 적용되지 않았음**.

## 변경 내용
- 앱 전체를 구형 V3.1.56으로 다운그레이드하지 않고, V3.1.56의 현장 X / 사전 원격 버튼 / 사후 이동 버튼 부재 / CLI 정지 / 팝업 없음 **동시 검증 조건**을 V3.1.63 수령 이동에도 적용합니다.
- 일반 등록용 Fresh 경로 및 수령용 Fresh 경로 모두, 동일한 7프레임/3초 안정화와 1.2초 지연 최종 재검증을 통과해야 이동 완료로 확정합니다.
- 이동 버튼은 기존 고정좌표 **1회**만 클릭하며 재클릭하지 않습니다. 품목, 시설, 파란 모두 받기 버튼 등의 기존 고정좌표를 변경하지 않습니다.
- 실패 분석 로그에 현장 닫기 X와 파란 수령 버튼의 시각 검출 결과를 추가합니다.
- 수령 Space는 기존처럼 전체 작업 완료 여부, 파란 버튼, 확인 팝업 부재, 정상 CLI, 수령 이후 전체 슬롯 소멸을 독립적으로 검증하고 실행합니다.
