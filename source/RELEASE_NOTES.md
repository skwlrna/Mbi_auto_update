# Mabi Auto V0.1.80

전리품 오인식을 막기 위해 집계 판정을 전면 보수적으로 바꿉니다. 다시 하기/던전 진행 로직은 변경하지 않습니다.

- 전리품은 같은 아이콘이 3프레임 연속으로 강하게 잡히고, 위치도 안정적이어야 후보가 됩니다.
- 아이콘 점수는 최소 0.84를 요구하고, 다른 전리품 템플릿보다 각 프레임에서 최소 0.04 이상 앞서야 합니다. 유사 아이콘끼리 점수가 붙으면 집계하지 않습니다.
- 후보 아이콘 옆의 정확한 아이템 이름이 3프레임 중 최소 2프레임에서 확인돼야 최종 집계합니다.
- OCR만으로 아이템을 추측하던 fallback을 완전히 제거했습니다. 이름만 보이거나 애매하면 +0 처리합니다.
- 전리품 템플릿 검색 배율을 0.90~1.12로 좁히고 기본 임계값을 0.82로 올려, 고정 800×1000 결과 화면에서 엉뚱한 크기의 유사 이미지가 매칭되는 것을 줄였습니다.
- 룬 장식 일반/+처럼 비슷한 아이콘은 점수 차이가 충분하지 않으면 어느 쪽도 집계하지 않습니다.
- 기존 누적 통계 파일 형식과 /item, /itemreset은 유지합니다.

# Mabi Auto V0.1.79

V0.1.78의 게임 진행/다시하기 판정은 그대로 유지하고 유지보수 안전성만 보강합니다.

- 업데이트 직전 버전을 `.previous_version`에 1개만 보관하고 `ROLLBACK_PREVIOUS.cmd`로 수동 복구할 수 있게 했습니다.
- V0.1.78 → V0.1.79 첫 업데이트에서도 기존 updater가 백업을 지우기 전에 새 앱이 `.previous_version` 복사본을 보존합니다.
- 업데이트 성공 판정은 단순 창 실행이 아니라 템플릿, Windows OCR, Interception 입력 준비가 모두 확인된 뒤에만 기록합니다. 게임 창/텔레그램/업데이트 서버 연결은 성공 필수 조건이 아닙니다.
- 템플릿 준비 확인은 실제 실행 위치인 `release/`를 우선 검사하고 구버전 호환 폴더를 fallback으로 사용합니다.
- 낚시 디버그 PNG는 최신 150개 또는 총 100MB까지만 유지하여 장기 실행 시 디스크가 계속 늘어나지 않게 했습니다.
- 어비스/던전 인식 임계값, 전리품 판정, 다시하기 클릭/전환 로직은 V0.1.78 그대로 유지합니다.

# Mabi Auto V0.1.78

정상 작동 중인 V0.1.77 기준으로 전리품 집계와 다시하기 입력만 보완합니다.

- 허상의 마력석은 동일 위치 아이콘이 두 프레임 모두 0.85 이상이고, 그 옆의 정확한 이름도 두 프레임에서 확인돼야 집계 후보로 인정합니다.
- 아이콘만 보이거나 OCR 이름만 잡힌 경우 집계하지 않습니다. 이름이 표시되지 않거나 읽히지 않는 화면은 집계를 보류합니다.
- 허상의 마력석 후보 판정 시 결과 화면 2장, 아이콘 점수/좌표, OCR 결과와 승인/보류 사유를 `release/abyss/debug/loot_hallucination`에 자동 저장합니다. 최대 150파일/100MB로 제한합니다.
- 어비스와 일반 던전 결과의 다시하기는 인식 후 1초 기다리고, 최신 화면에서 같은 버튼과 입장 화면 여부를 다시 확인한 뒤 클릭합니다. 대기 중 정지하면 클릭하지 않습니다.
- 기존 누적 집계는 초기화하거나 차감하지 않습니다. /item 및 /itemreset 유지.
- V0.1.77 창 포커스 재시도, 설정·템플릿·OCR/Interception 환경 및 자동업데이트 채널 유지.

아이템 미획득/획득 실화면은 아직 확보하지 못했습니다. 보수적인 판정 기준을 적용했으며, 저장된 진단으로 실제 오인식 원인과 인식 누락을 추가 조정할 수 있습니다.
