# Mabi Auto V0.1.87

자동 가공에서 기존 작업을 완료·수령한 뒤 시설 화면을 잘못 판단해 정지하던 문제를 수정했습니다.

- 실제 V0.1.86 오류 화면은 이미 **금속 가공 시설 내부**였지만 상단 시설 제목 OCR 확인이 실패해 "선택한 가공 시설 화면으로 전환되지 않았습니다"로 정지하고 있었습니다.
- 시설 화면 상단 제목 전용 고정 영역을 추가하고, 그 좁은 영역에서만 한 글자 OCR 오차를 허용해 이미 시설 안에 있는 상태를 안정적으로 확인합니다.
- 기존 작업 수령 후 화면을 다시 판정하여 목표 시설이면 그대로 진행하고, 가공 허브·다른 시설·품목 상세·일반/전환 화면이면 각 상태에 맞는 입력만 수행합니다.
- 시설 진입은 최대 3회까지만 재시도하며 각 시도 전에 새 화면을 확인합니다. 무작정 키/클릭을 반복하지 않습니다.
- 로그에 기존 작업 수령 시작, 현재 화면, 시설 진입 시도 n/3, 성공/실패를 남깁니다.
- CLI 비용 명령 차단, Interception, 던전, 낚시, 전리품 판정은 그대로 유지합니다. 자동채집 기능은 이번 버전에 포함하지 않았습니다.

검증: Windows CI에서 빌드, 안정성 회귀, 던전/재시도, Read-only CLI, 인벤토리 전리품, 자동 가공 회귀 검사를 모두 통과했습니다.

실제 게임의 모든 가공 시설/품목 조합은 아직 전수 실게임 검증 전입니다. 화면을 확정하지 못하면 기존과 같이 추가 비용 입력 없이 정지합니다.
