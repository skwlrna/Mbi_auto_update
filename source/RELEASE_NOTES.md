# V0.1.98

자동 채집 화면의 `CLI 검사` 버튼은 선택 품목으로 capabilities와 get_gatherable_items(filter)만 조회한 뒤 종료합니다. 실제 채집, 이동, 입력, OCR, 화면 캡처 및 날개 사용은 실행하지 않습니다. 기존 자동채집 시작 동작은 유지합니다.

릴리스 후 확인: **달걀 선택 → CLI 검사 → 로그 전달**. 자동채집 시작 버튼은 누를 필요가 없습니다. 도구가 없어도 CLI 검사는 가능합니다.

로그: capabilities 전체 명령, items 수, itemFields, DisplayName의 대소문자 구분 exact match 수, 응답 상태와 개인정보 값을 제외한 JSON 구조 요약. 배열 구조는 앞 10개 행, 중첩은 8단계까지 표시하며 전체 배열 개수는 보존합니다. 응답 오류도 기록하고 종료합니다.
