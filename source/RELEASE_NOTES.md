# MABI AUTO V3.1.53 — 다중가공 안정화 실게임 테스트 배포

이 버전은 GitHub 공개 자동업데이트를 통해 사용자가 실제 게임 환경에서 검증하는 **테스트용 안정화 후보**입니다. Windows CI는 통과했지만 **실제 게임·Interception 드라이버·물리 F10 검증은 아직 완료되지 않았습니다.**

## 주요 수정

- **N03:** F10 취소 이후의 저수준 키·마우스 입력 시작 차단, 클립보드 STA 취소 보호
- **N02:** 다중가공 배치의 품목별 완료 기록 영구 저장, 재시작 시 완료 품목 중복 등록 차단
- **F05:** 중간재료 소비 전·후 스냅샷과 거래 ID 영속화, 소비 보정 원자 적용 및 중복 적용 차단
- **F02:** 시설 내 진행 작업이 남아 있으면 `모두 받기` 차단; Space 직전 CLI·화면 재검증
- **F03/F04:** 이동·완료 팝업의 의미 확인, 관리 모드 활동 상태 및 Space 직전 허가 강화
- **N01/F07:** 클릭 직전 최신 화면에서 무료 버튼 중심 재탐지, 동일 출력명의 다른 제법 혼동 방지
- **F01:** 이동 클릭 후 연관된 출발 증거와 현장 도착 안정화가 확인되지 않으면 등록 금지

## 실게임 테스트 안내

1. 프로그램을 종료하고 다시 실행해 `V3.1.53` 자동업데이트와 재시작을 확인합니다. 실행 중인 가공 작업은 중지한 후 업데이트하세요.
2. 목재·강철괴·불린쌀 등 2~3종을 소량으로 시작해 각 품목 등록 횟수와 완료 수량을 기록합니다.
3. 설비 이동 확인창이 **있는 경우와 없는 경우**, 완료창/모두 받기 수령, 7칸 혼합, 재료 부족·중간재료 해결을 확인합니다.
4. 의도적으로 F10으로 중단하고 재실행합니다. 이전 완료 품목이 다시 등록되지 않는지 확인합니다.
5. 안전 정지·오인식이 있으면 프로그램 로그와 해당 디버그 캡처, 사용한 가공 조합 및 남은 작업 상태를 보존합니다.

**주의:** 이전 버전에서 진행 중이던 배치 또는 미확정 거래가 있으면 안전을 위해 자동 이어하기가 거부될 수 있습니다. 저장 세션을 임의로 지우거나 같은 가공을 다시 등록하지 마세요. 기존 설정·템플릿·텔레그램 값은 업데이트 과정에서 보존하도록 구성되어 있으며, 실행 실패 시 이전 버전 복구 경로를 제공합니다.

Windows 테스트 ZIP, SHA256 체크섬, 소스 ZIP을 함께 게시합니다. 본 릴리스는 실게임 사용 검증 완료 선언이 아닙니다.
