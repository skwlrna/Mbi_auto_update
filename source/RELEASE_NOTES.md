# Mabi Auto V0.1.86

가공 메뉴의 시설 선택이 중복 인식으로 멈추는 문제를 수정했습니다.

금속·목재·가죽·옷감·약품·식재료 모두 같은 수정이 적용됩니다. 전체 카드 영역을 읽어 한국어 인식에 필요한 주변 문맥을 유지하면서, 선택한 카드의 큰 제목 영역 안에 있는 정확한 이름만 클릭 후보로 인정합니다. 아래의 시설 이름·레벨 배지는 제외합니다.

가공 메뉴 제목과 시설 제목을 두 번 확인한 뒤 클릭하며, 전환 후 선택한 시설 화면의 제목도 확인합니다. 제목을 확정하지 못하면 추가 입력 없이 정지합니다. 품목 상세 확인과 비용 5개 확인, CLI 비용 명령 차단, 기존 작업 완료·수령 후 추가 생산 방식은 유지합니다. 기존 던전·전리품·텔레그램·로그 흐름도 유지합니다.

검증: 실제 오류 순간의 가공 메뉴 사진과 최초 제공된 가공 메뉴 사진에서 여섯 시설 제목이 각각 한 개만 인식됨을 확인했습니다(총 12개 확인). 빌드와 자동 가공 27개 모의 검사를 통과했습니다. 기존 회귀 검사와 실행 파일 시작 검사는 GitHub 배포에서 실행합니다.

실제 게임에서 시설 클릭 이후 가공 시작부터 완료 수령까지의 전체 동작은 아직 검증 전입니다. 이번 사진 검사는 게임에 입력을 보내거나 재화를 사용하지 않았습니다.
