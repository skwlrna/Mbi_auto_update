# Mabi Auto V0.1.94

V0.1.93에서 자동 가공/자동 채집을 별도 화면으로 분리하면서 생긴 UI 이질감과 메뉴 전환 문제를 수정했습니다.

## 기존 홈 UI로 통합

- 별도 ProductionDashboard 오버레이를 제거했습니다.
- 홈, 낚시, 던전, 어비스와 동일한 기존 대시보드 디자인을 그대로 사용합니다.
- 자동 가공/자동 채집을 눌러도 창 전체 UI가 다른 스타일로 바뀌지 않습니다.
- 홈 화면에서 자동 가공을 한 번 눌러 바로 선택할 수 있습니다.
- 자동 채집을 먼저 눌러야 자동 가공이 열리는 레이어/전환 문제를 제거했습니다.

## 표시 통일

- 사용자 표시명은 모두 `자동 가공`, `자동 채집`으로 통일했습니다.
- 자동 가공/채집에서는 기존 정보 카드가 작업 대상, 현재 단계, 진행 수량을 표시합니다.
- 하단 영역에는 기존 카드 스타일로 작업 설정과 CLI 실행 정보를 표시합니다.
- 시작 버튼은 선택 모드에 따라 `자동 가공 설정 / 시작`, `자동 채집 설정 / 시작`으로 표시됩니다.
- 진행률과 통계는 목표 수량 기준으로 계산합니다.

자동화 실행 로직과 CLI 검증 로직은 V0.1.93과 동일하게 유지합니다.
