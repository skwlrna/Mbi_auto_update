# Mabi Auto V3.2.84 — Home·End 필드 인증 보완

- Home·End가 알려진 위치·간격에서 확인되면 ESC 글자 미인식 시에도 필드 인증 경로를 제공합니다.
- 하단 K/I, 연속 두 프레임, 메뉴·팝업 차단 및 K 입력 직전 재검증을 유지합니다.
- 인식 점수 임계값·3초 제한·수령·등록 동작은 변경하지 않았습니다.

구현 커밋의 Windows 빌드와 전체 자동 검사를 통과했습니다. 실제 오류 이미지 두 장의 최종 필드/K 입력 직전 재생 및 실게임 확인은 미완료입니다. 문제가 있으면 ROLLBACK_PREVIOUS.cmd로 복구할 수 있습니다.
