# MabiAuto V3.2.16 — Codex 사용량 한도 인계 및 어비스 전투 중 클리어 오인 방지

## AI 감시 / ChatGPT 인계
- 기존 마비오토의 하루 8회 Codex 실행 제한을 제거했습니다.
- Codex 제공자가 실제 계정 사용량 한도/크레딧 소진을 명확하게 반환하면 추가 호출을 멈추고 미처리 오류를 안전하게 보관합니다. 잔여 할당량을 추측하거나 무제한이라고 표시하지 않습니다.
- AI 현황의 **ChatGPT로 이어가기**에서 사용자가 확인하면 민감 정보 없는 오류 분류·식별자·대기 건수만 클립보드에 복사하고 ChatGPT 웹사이트를 엽니다. 대화 전송은 사용자에게 맡기며 원본 로그·스크린샷·비밀값은 자동 전송하지 않습니다.
- Codex의 한도 중단과 기존 안전 정지, 자동 병합·배포 금지 원칙은 유지합니다.

## 2026-10-15 20:15 병행 어비스 오류 대응
V3.2.15 실제 오류 로그에서 전투가 끝나기 전에 클리어 제목과 유사한 화면을 두 번 탐지했지만 실제 터치 문구의 인식은 부족했습니다. 기존 제목만으로 고정 좌표를 누르던 fallback 이후 실제 결과 화면을 확인하지 못했고, 나가기 검증 실패로 가공도 안전 정지됐습니다.

- 클리어 판정을 **제목 + 실제 터치 문구가 한 화면에 함께 잡히는 연속 두 프레임**으로 강화했습니다.
- 제목만 탐지했을 때 고정 좌표를 누르던 fallback과 결과 전환 후 같은 방식의 재시도 경로를 제거했습니다.
- 10분 타임아웃 복구 중 터치 문구 단독 클릭 우회 경로도 제거했습니다.
- 첫 확인 프레임에서 전역 스킵 모니터가 별도 입력을 실행하지 않게 보류합니다.
- 정상 클리어, 전투 중 유사 제목, 터치 문구가 없는 경우, 연속 프레임이 끊긴 경우에 대한 Windows 스케줄러 회귀 테스트 및 Python 안전 계약 테스트를 추가했습니다.

## 설치 후 확인
V3.2.16 적용 후 AI 현황의 인계 기능과 병행 어비스를 각각 점검합니다. 실제 게임에서 전투 종료·클리어 터치·퇴장까지 성공했는지는 자동 테스트만으로 입증되지 않습니다. 증거가 불완전할 때 임의 클릭 대신 대기 또는 안전 중지됩니다.

V3.2.15 릴리스는 보존하며 최종 main Windows CI, 기동 검사, ZIP 필수 파일 및 체크섬 검사에 통과한 경우에만 V3.2.16 자동업데이트를 공개합니다.
