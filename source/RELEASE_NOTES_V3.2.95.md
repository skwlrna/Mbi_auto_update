# Mabi Auto V3.2.95 — 약품 가공 검색 첫 카드 좌표 수정

**오류 근거:** 2026-11-06 00:42:56 KST, V3.2.94에서 `산뜻 버섯 진액` 검색 결과를 인식했지만 상세 화면이 열리지 않아 다중가공이 안전 정지했습니다. 보관된 실제 오류 화면에서 대상 첫 카드는 X=162~275, Y=330~493인데 프로그램은 음식 제작 검색 좌표 (218,613)를 눌렀습니다.

## 이번 수정 (PR #389)

- 약품 가공 검색 결과 첫 카드 클릭을 `(218,613)`에서 실화면 중심 `(218,412)`로 변경했습니다.
- 약품 검색창, 검색어 입력, 검색 결과 화면 변화 검증은 유지했습니다.
- 음식 제작의 `(218,613)`과 식재료/금속/목재/가죽/옷감의 기존 카드 좌표는 변경하지 않았습니다.
- 금속 가공 수령, 다중가공 재시도 금지, 작업 장부, 화면·CLI 미확정 시 안전 정지는 수정하지 않았습니다.
- 실제 앱 어셈블리 기준 좌표 분리·안전 영역 회귀 테스트와 기존 다중가공·채집·중간관리자 검사를 수행합니다.

## 배포 및 검증

- 정식 배포 전 **해당 릴리스 main 소스 SHA**의 Windows CI와 모의 회귀 검증, 실행 파일 스모크, ZIP SHA256, 롤백 스크립트를 검증합니다.
- **실제 게임에서 산뜻 버섯 진액 가공 성공은 아직 확인되지 않았습니다.** 배포 후 새 오토로그로 확인해야 합니다.
- 설치된 프로그램을 강제로 종료하지 않으며 `ROLLBACK_PREVIOUS.cmd`로 이전 버전으로 돌아갈 수 있습니다.
