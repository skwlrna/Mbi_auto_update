# Mabi Auto V3.2.90 — 11월 5일 게임 업데이트 이후 가공 상태 조회 진단 개선

2026-11-05 16:57 KST, V3.2.89에서 다중가공 첫 시설 진입 도중 `The given key was not present in the dictionary.` 예외가 발생했습니다. F9의 K/I/Space 화면 인증 직후 `get_activity` 조회가 있었지만, 당시 오류 메시지만 기록되어 실제 누락된 키는 확인되지 않았습니다.

## 수정 내역 (PR #379)

- `GatheringQueries.ParseActivity`가 기존 필수 상태 필드의 누락 경로(예: `$.Mode.MainButtonState`), Boolean/String 타입 불일치, 공백/잘못된 텍스트를 구분해 진단합니다.
- 누락되거나 변경된 필드 값을 정상·대기 상태로 추측하지 않습니다. 안전성 확인이 불가능하면 게임 입력 전에 중단합니다.
- 다중가공 예외에 예외 유형과 메서드 기반 호출 경로를 오토로그에 기록하되, 원본 CLI 응답·계정·캐릭터 값·로컬 파일 경로는 남기지 않습니다.
- `tests/gathering`에 Mode/Interaction/Dungeon 하위 필드 누락, 잘못된 Boolean, 정상 응답 검증을 추가했습니다.

## 주의사항

- **실제 게임 업데이트 후 CLI 응답의 변경 여부, 기존 작업 수령 성공 여부는 아직 검증되지 않았습니다.** 이 버전은 원인 진단과 안전한 실패 처리를 개선한 것이며, 변경된 게임/CLI 프로토콜을 임의로 추측해 맞춘 버전이 아닙니다.
- 현재 화면/CLI 상태가 불명확하면 K·Space·모두 받기·재등록을 자동 반복하지 않습니다. V3.2.89의 채집 Stop/CLI 확인 및 기존 안전 정지 정책을 유지합니다.
- 정확한 main 커밋 CI, Windows 실행 파일 스모크 검사, Lite ZIP·SHA256·소스 ZIP 및 롤백 스크립트 검사 후에만 정식 배포합니다.
- 실행 중인 프로그램에 강제 설치하지 않습니다. 필요 시 패키지의 `ROLLBACK_PREVIOUS.cmd`를 사용해 이전 설치 상태로 복구하세요.
