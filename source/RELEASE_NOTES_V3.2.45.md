# MabiAuto V3.2.45 개발 후보 — AutoFix 중복 방지·테스트 강제·Draft PR 안전 게이트

## 기존 기능 재사용
기존 `ai-autopilot/autopilot.py`가 사용자 PC에서 MCP/런타임 오류 이벤트를 감시하고, 배포된 빌드 커밋으로 고정한 격리 Git 작업트리에서 Codex로 수정한 뒤, 관련 회귀 테스트와 Windows 빌드를 수행합니다. 테스트 실패 시 최대 2회 수정 라운드를 사용하고, 원본 설치 파일은 변경하지 않습니다. `AutoCreatePr`가 **사용자 PC에서 명시적으로 활성화**되어 있고 GitHub CLI 로그인이 확인되면 결과를 **Draft PR**로 게시할 수 있습니다. 자동 병합·정식 배포는 허용하지 않습니다.

## V3.2.45 새 보강
1. **이미 대기 중인 Draft PR의 중복 생성 방지:** 오류의 `summary.txt` 또는 `error.txt` 바이트가 완전히 같은 경우에만, 과거 24시간 내 동일 증거의 자동 테스트 통과 및 실제 Draft PR 생성 기록을 교차 확인해 Codex를 다시 실행하지 않습니다. 결과가 차단·테스트 실패·PR 미게시인 이전 이력은 건너뛰는 근거가 아닙니다. 다른 증거/새 오류는 정상 처리합니다. 과거 결과 파일은 변경하지 않고 새로운 오류 건에는 `existing_draft_review_skipped` 영수증을 남깁니다.
2. **중요 코드 수정의 테스트 강제:** 가공 스케줄러, 영속 F9 장부, 이전 작업 이어하기, 공급 재료, 수령 회계, 시설 권한 등의 파일을 수정하면 관련 등록된 회귀 스위트(`altering`, `n02-resume`, `f05-consumption`, `combined-scheduler`)를 같이 실제 변경하고 실행해야 합니다. 무관한 테스트 하나만 통과해서는 자동 PR로 게시할 수 없습니다.
3. **AI 자기수정·업데이트 차단:** Codex가 임의로 `ai-autopilot` 실행 코드·GitHub 게시 로직·업데이트 매니저·배포 스크립트를 수정해 권한을 확대하지 못하도록 diff 검사와 PR 게시 직전의 독립 검사로 차단합니다. 리포지토리 경로 탈출, 심볼릭 링크, 바이너리·비밀키 및 허용되지 않은 확장자도 검증합니다.
4. **기존 사용자 동의 유지:** 배포된 사용자가 `AutoCreatePr`을 켜지 않았으면 원격 PR을 생성하지 않습니다. 게시 가능한 Draft PR 역시 실게임 검증·사람 승인 전까지 미배포 후보입니다.

## 자동 테스트
- 동일 오류 + 실제 Draft PR 교차검사, 증거 변경·오래된 기록·실패한 후보는 차단하지 않음
- 악의적인 결과 파일/외부 링크/심볼릭 링크/중복 결과 기록 무시
- 위험 코드와 대응 회귀 테스트의 필수 짝 확인
- PR 게시 전에 자체 파이프라인/업데이트 파일·비정상 경로 수정 차단
- 기존 MCP 감시기 전체 Python 회귀, F9/N02/F05 및 Windows 빌드 회귀

## 적용·배포 상태
이 작업은 PR #252(V3.2.44)에 종속된 개발 브랜치 초안입니다. #249~#252의 실제 게임 검증과 단계적 배포가 끝나기 전에는 **V3.2.45 정식 자동업데이트를 실행하지 않습니다.** 현재 자동화 구현·테스트 통과는 사용자 PC의 Codex 계정 로그인/실제 오류 수정 성공/실게임 안전성을 증명하지 않습니다.
