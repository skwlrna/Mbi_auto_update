# MabiAuto V3.2.33 — 가공·채집·제작 작업 결과 검증 및 중복 실행 차단

## 적용 내용
- 생활기술 중간관리자에 **실행 구간별 작업 검증 장부(LifeSkillWorkFence)** 를 추가합니다. 동일 품목의 작업이 진행 중이거나 이전 실행 결과가 미확정이면 같은 실행 중 재시작을 차단합니다.
- 제작은 기존 **실제 제작 완료창 확인**과 새 CLI 재고 증가(제작 횟수 × 생산량) 검증이 모두 성공했을 때에만 다음 제작 배치로 진행합니다. 한쪽이라도 미확정이면 자동 재클릭 없이 원래 예외를 유지합니다.
- 채집은 시작 입력 직전에 작업 구간을 등록하고 종료·정지 확인 후 신규 CLI 재고 증가가 목표 수량 이상인 경우에만 정상 완료로 기록합니다.
- F9 다중가공은 계획/시설/제법별 병렬 중복 배치 실행을 차단합니다. 기존 등록 확정량이 역행하면 중단하며, 실행 중 예외 발생 시 자동 중복 등록을 막습니다. 수령과 실제 생산량은 **기존 F05 영수증 및 배치 장부**가 판정합니다.
- 오류의 원문 민감 정보를 저장하지 않고 `craft_result_unconfirmed`, `gather_stop_or_inventory_unconfirmed`, `alter_batch_unconfirmed` 등의 범주와 중복 차단 사유를 로컬 진단 로그에 남깁니다.
- 단계 전환 CLI 재고 무효화와 읽기 전용 300ms 1회 재조회는 V3.2.32 그대로 적용합니다. 새로운 원시 패킷 파서는 추가하지 않습니다.

## 안전 제한
- 작업 검증 장부는 한 실행에만 유지되는 메모리 장부이며 다음 실행/F9 이어하기를 허가하지 않습니다. 가공 이어하기는 기존 영속 장부의 재검증을 거칩니다.
- 조회만으로 게임 클릭, 가공 등록, 제작 재실행, 채집 시작/정지, 배치 수령을 자동 재시도하지 않습니다.
- F10 취소·정령의 날개 0개·게임화면 현장 검증·AI 수정 승인과 롤백 정책은 유지합니다.
- 기존 제작 퀘스트 준비 단계의 제한적 자동복구 방식은 변경하지 않습니다. 검증 장부는 실제 제작 완료 구간에 적용합니다.

## 검증 및 배포
- 회귀 테스트: 동일 작업 중복 차단, 완료 근거 미달, 결과 미확정 격리, 이전 응답 폐기, 정상 후속 실행, 가공 등록 역행 차단.
- Windows CI 통과 및 main 병합 후에만 정식 자동업데이트 릴리스를 게시합니다.
- 실제 게임 장시간 운용과 개별 사용자 PC의 업데이트 설치 성공은 별도 확인이 필요합니다.
