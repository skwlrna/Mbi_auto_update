# MabiAuto V3.2.13 — 2026년 10월 15일 가공 제법 순서 변경 대응

오늘 게임 업데이트로 가공 레시피 표시 순서가 바뀐 뒤, 선택한 제법이 의도한 제법과 다르거나 `+ 추가`에서 조건 오류가 뜰 수 있는 문제를 개선했습니다.

- **동일 이름 제법 표시:** 과거에는 같은 시설·같은 이름의 가공 제법 중 첫 번째 제법만 표시하던 UI를 고쳐, 다른 1회 생산 수량/제법 순번도 구분해 모두 표시합니다.
- **새로고침 시 선택 보존:** 제법 표시 순서가 바뀌어도 이름·시설·1회 생산 수량으로 선택한 제법을 다시 확인하고 올바른 목록 순번을 갱신합니다.
- **불명확한 제법은 안전 정지:** 같은 이름과 동일한 1회 생산 수량의 복수 제법 등으로 제법을 확실히 식별할 수 없으면 임의 제법 등록·게임 입력을 금지합니다. 기존 재료 부족 자동 해결 및 F9 안전 검증 조건도 유지합니다.
- **CLI 구조 진단:** `get_alterable_items` 읽기 전용 응답의 필드 이름, 품목 수, 가공 불가 품목 수, 중복/구별 불가능한 제법 건수만 로그에 남깁니다. 파싱 실패 시에도 응답 필드만 제한적으로 기록하며 CLI 원본 데이터/캐릭터 정보는 기록하지 않습니다.
- **테스트:** 목록 역전 시 제법 동일성 유지, 중복 제법 선택, 모호한 제법 차단, 클릭/추가/삭제/비우기 동작과 Windows 전체 가공·스케줄러 회귀 테스트를 포함합니다.

## 실사용 확인

실제 10월 15일 업데이트 이후 CLI 응답 원본은 아직 확보되지 않았으므로 게임 측 필드 형식 변경 여부를 확정한 것은 아닙니다. 업데이트 적용 후 매크로의 **자동 가공 > 제법 새로고침 > 품목 선택 > 다중가공 + 추가**를 순서대로 확인해 주세요. 계속 오류가 발생하면 로그의 `[CLI][가공 제법]` 및 `[자동 가공] 선택 제법 상태` 부분으로 원인을 진단할 수 있습니다. 게임을 실행하거나 입력을 발생시키지 않는 조회만으로 파악할 수 있는 문제와 실게임 테스트가 필요한 문제를 구분합니다.

V3.2.12의 다중가공 버튼 응답 개선, 스케줄러, Codex 사용량 보호와 오류 수집 기능은 그대로 포함합니다. 기존 V3.2.12 릴리스는 덮어쓰지 않고, CI 인증된 커밋을 기준으로 별도의 V3.2.13 Windows Lite ZIP, SHA256, Source ZIP을 검증 후 자동 업데이트용 공개 릴리스로 게시합니다.
