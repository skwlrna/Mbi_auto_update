# MabiAuto V3.2.13 — 10월 15일 가공 제법 목록 호환성 및 진단 개선

게임 업데이트로 가공 제법 표시 순서가 변경된 뒤 가공 작업을 선택했는데도 ‘선택한 제법의 가공 조건을 확인하세요’라는 메시지가 나타나는 사례를 조사해 가공 목록 선택 및 진단을 보완했습니다.

- **중복 가공 제법 유지:** 동일 시설·동일 이름의 레시피를 하나로 합치지 않고 CLI에서 조회한 각 제법을 구분하여 표시합니다. 같은 이름이면 원본 제법 순번과 1회 생산량이 표시됩니다.
- **선택 보존:** 새로고침 시 기존 이름·1회 생산량·시설을 비교하고, 유일하게 식별되는 경우에만 선택을 복원하며 새 CLI 제법 순번을 반영합니다.
- **안전 차단:** 같은 이름에 생산량도 동일해 변경된 목록에서 구분할 근거가 없거나 이전 선택을 찾지 못하면 다른 제법으로 자동 전환하지 않습니다. F9와 정령의 날개 0개 사용 제한은 유지합니다.
- **CLI 스키마 진단:** 가공 제법 개수, 사용 불가 건수, 중복 이름/생산량 건수와 필드 이름만 읽기 전용 로그로 기록합니다. 파싱 실패 시에도 키 목록을 남기며 원본 CLI JSON이나 캐릭터 정보는 기록하지 않습니다.
- **회귀 테스트:** 게임 레시피 순서 역전, 같은 이름의 서로 다른 생산량, 식별 불가능한 제법 등록 차단 및 입력 방지, 기존 가공·채집·스케줄러 테스트를 Windows CI에서 검증합니다.

**실게임 확인 필요:** 2026년 10월 15일 게임 점검 이후의 실제 `get_alterable_items` 반환 데이터는 아직 확보되지 않았습니다. CLI API 계약 자체 변경은 확정하지 않았으며, V3.2.13 실행 후 가공 화면의 '새로고침'을 눌러 기록되는 `[CLI][가공 제법]` 로그로 필드 구조를 확인할 수 있습니다.

이 버전은 V3.2.12의 버튼 응답 개선, Codex 사용량 보호, 스케줄러 안정성 및 오류 진단 개선 기능을 포함합니다. 공개 배포는 최신 main 커밋에 대한 Windows CI 성공과 ZIP/SHA256/필수 파일 검증 이후에만 진행합니다.
