# Mabi Auto V3.2.55 — 가죽 7칸 묶음가공 및 원재료 재고 판정 수정

> **실게임 검증 전 사용자 요청으로 공개하는 버전입니다.** Windows 모의·회귀 테스트는 통과했지만, 실제 마비노기 모바일에서 새 7칸 배치 동작 및 실제 PC 복원/롤백을 완료한 증거는 없습니다.

## 주요 수정
- 일반 가죽·가죽+ 등 자동 제작 가능한 중간재료는 가죽 가공 시설에서 **최대 7칸 묶음 등록** 후, 시설 전체 완료가 확인되면 묶음 수령하도록 개선했습니다.
- 가죽+ 200개 목표라도 67회분의 재료를 시작 전에 요구하지 않고, **다음 1회분의 재료 확인을 시작점으로** 실제 가능한 작업 수만큼 등록합니다.
- 재료가 일부만 남아 있으면 가능한 작업만 등록하고 확정 수령을 대조합니다. 예: 테스트 가상 레시피에서 생가죽 35개 보유 시 중간재료 가죽 3회분을 등록·수령한 후 상위 가죽+ 3회분을 제작합니다.
- 생가죽 계열·타닌 가루가 부족하면 자동 채집/자동 구매하지 않고 해당 가죽 품목만 중단합니다. 이미 등록한 작업, 별도 가공 시설 및 정령의 날개 0개 규칙을 보존합니다.
- 가죽 레시피 Owned 재고와 새 인벤토리 `get_items` 수량이 다르면 **소진으로 확정하지 않고** 해당 입력을 안전 보류합니다.
- 이전의 생가죽이 조금 있어도 모두 없어진 것처럼 표시되던 `원재료 소진` 안내를 수량을 포함한 `원재료 부족`으로 개선했습니다.

## 안전·검증 안내
- **실제 게임에서 7칸 등록 및 완료 후 수령을 끝까지 테스트하지 않았습니다.** 모의 테스트의 재료 소모 수량은 실제 게임 제작법을 입증하지 않습니다.
- **이전 '이어하기'의 RawMaterialExhausted 영구 종료 기록을 자동 재개시키는 수정은 포함되지 않습니다.** 신규 F9 배치와 기존 저장 배치를 혼동하지 마세요.
- 게임 내 매크로/F9 작업을 중지하고 설치 폴더·배치 진행 기록·설정을 별도 백업한 뒤 업데이트하세요.
- 업데이트 문제가 생기면 패키지의 `ROLLBACK_PREVIOUS.cmd`를 사용하거나 이전 **V3.2.54** 릴리즈로 복귀할 수 있습니다. 실제 사용자 PC의 롤백 절차는 미검증입니다.
