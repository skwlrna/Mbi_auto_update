# MabiAuto V3.2.38 — 가공·채집·제작 작업 검증 통합 계측

## 구현
- 기존 화면·CLI 검증과 중복 차단 펜스에서 **작업 시작, 검증된 출력, 배치 콜백 반환, 결과 미확정, 미완료 시도**를 작업 종류별로 별도 집계합니다.
- 채집·제작의 출력 검증은 화면 완료 확인과 새 CLI 재고 증가 검증이 모두 통과한 경우에만 계산합니다. 검증률은 완료 여부가 판정된 시도 중 출력 검증 수의 비율입니다. 아직 진행 중인 시도는 제외합니다.
- 가공 F9의 배치 콜백 정상 반환은 출력 완료/실제 수령과 **다른 증거**로 남기며, 출력 검증률을 임의 계산하지 않습니다. 실제 생산량·수령량은 기존 F9/F05 영속 장부와 대시보드 기준입니다.
- 오류·중단 때 수량 검증이 미확정이면 누락이 **의심되는 미확정 시도**로 표시합니다. 누락이 확정된 것으로 가정하지 않으며 자동 재실행하지 않습니다.
- F9 종료 진단 로그에 세 작업 종류별 결과 통계를 표시하고, 로컬 가공 오류 진단 스냅샷에는 민감한 재료/패킷 원문 없이 요약 횟수를 남깁니다.
- 이전 V3.2.37 CLI 읽기 전용 복구 통계 및 AI 확인 이력은 그대로 별도 유지합니다.

## 보호되는 동작
- F9/F05 장부, 작업 중복 차단, F10 정지, 0 정령의 날개, 기존 재료 확보 경로, 화면 검증 정책, AI 변경 승인·롤백을 변경하지 않습니다.
- 새로운 클릭/중지/수령/등록 재시도나 확인되지 않은 패킷 구조를 추가하지 않습니다.
- 이번 계측은 **작업 시도별 증거 확인 비율**이며 전체 목표 생산량 완료율이나 실게임 확정 누락률은 아닙니다. 원재료 소진 및 검증되지 않은 수령은 기존 장부에서 판정합니다.

## 테스트 및 배포
- 채집/제작 확정 증거, 미확정·중복 호출, 진행 중 작업 분리, F9 콜백과 수령 증거 분리, 작업 종류 간 검증 혼동 방지 회귀 테스트를 추가합니다.
- Windows PR CI와 병합 후 main CI가 성공한 경우에만 정식 자동업데이트 릴리스를 게시합니다.
