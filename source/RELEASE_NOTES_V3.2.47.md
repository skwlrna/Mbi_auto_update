# Mabi Auto V3.2.47 — 가방 무게 기반 자동 채집 안전 정지

> **실게임 미검증 — 개인 사용자 명시 요청에 따른 자동업데이트 배포.** GitHub Windows CI 및 오프라인 회귀 테스트는 게임 실전 동작을 보증하지 않습니다. 사용자가 자신의 설치본에 새 버전을 배포해 달라고 요청했으며, 자동업데이트에는 알려진 실전 검증 부족과 롤백 미시험 위험이 있습니다. CLI의 실제 가방 무게 수신 및 게임 내 채집·정지 동작은 검증되지 않았습니다.

## 변경 내용
- 가공 전 재료 부족 시 실행되는 단일·다중 자동 채집에 기존 `get_inventory` 조회의 `CurrentInventoryWeightAsDecimal`, `MaxInventoryWeightAsDecimal`을 이용한 무게 안전 규칙을 추가했습니다.
- 가방 무게 **80% 이상 경고**(채집 실행당 1회), **90% 이상에서는 추가 채집 중단**. 실행 시작 전과 진행 중 이미 존재하는 무게 조회 경로에 적용합니다.
- 안전 정지 시 실제 CLI 무게, 채집으로 증가한 수량, 남은 부족 수량을 로그로 알리고 기존 화면 정지/활동 재확인 절차를 사용합니다.
- 오프라인 테스트는 경계값 79.9%, 80%, 89.99%, 90%, 최대 초과와 시작 전·채집 도중 정지, 경고 중복 방지를 다룹니다.
- 무료 화면 조작 원칙과 유료 CLI 실행 차단을 유지합니다.

## 중요한 제한
- 100회 단위 채집 또는 네트워크/화면 상태 지연 중에는 다음 CLI 조회보다 먼저 무게가 늘 수 있으므로 90% **완충 기준은 절대적 상한을 보장하지 않습니다.**
- 품목별 무게는 확인되지 않아 목표 수량을 무게로 나누어 예측하지 않습니다.
- 자동 창고 이동, 아이템 폐기, 무게 확보 후 무인 재개는 구현하지 않았습니다. 멈춘 뒤 사용자가 무게를 정리하고 다시 실행할 때 기존 수량 조회 로직이 부족 수량을 재계산합니다.
- 실게임 무게 필드 조회와 실제 중단, 무게 초과, 롤백 동작은 **미검증**입니다. 성공했다고 기재하지 않습니다.

## 설치·복구
- 기존 V3.2.46 정식 버전에서 `V3.2.47` 비-프리릴리스 공개 버전이 조회되면 자동업데이트 검출 대상입니다.
- `MabiAuto_V3.2.47_Windows_Lite.zip`과 대응하는 `.sha256` 파일이 모두 게시되고 무결성 검증에 통과해야 합니다.
- 설치 전 기존 구성/파일 백업 및 `ROLLBACK_PREVIOUS.cmd`, `tools/RollbackPrevious.ps1`을 유지합니다. 복구 스크립트는 실게임 복구 검증되지 않았습니다.
- 새 코드를 실행 중인 매크로에 동적으로 주입하지 않습니다. 안전하게 정지 후 새 버전을 실행하세요.
