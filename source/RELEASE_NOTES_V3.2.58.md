# Mabi Auto V3.2.58 — 가죽 중간재료 부족·재고 불일치 안전 복귀 (PR #289)

> **실게임 검증 전 사용자 직접 요청으로 공개한 정식 배포입니다.** Windows CI 및 시뮬레이션 회귀 검사는 통과했지만 실제 게임에서 전체 중간재료 수령·보류 및 PC 업데이트/롤백 성공은 확인하지 않았습니다.

## 변경 사항
- 가죽+용 가죽 4작업 등록 후 `제법 Owned=0/10`, `get_items=9`처럼 재료 정보가 다를 때 전체 다중가공이 정지하는 문제 수정
- 중간재료 시설 소유권을 유지한 채 기존 작업 전체 완료·수령을 검증하고, 대기열 0건 및 소유권 반환 후에만 메인 작업을 이어갑니다
- `external_leather_raw_missing`으로 확인된 원재료 부족만 해당 품목 종료로 처리하며 재고·제법 불일치는 종료로 확정하지 않습니다
- 재고 불일치의 시설별 보류를 F9 장부에 남기고 다시 확인하는 동안 다른 독립 시설의 작업은 계속합니다
- 취소, 수령 실패, 산출량 미확정, 미수령 작업 및 활성 중간재료 소유권은 보류로 덮지 않고 안전 정지합니다
- 최대 7칸 가공, 생가죽·타닌 가루의 자동 확보 금지, 기존 작업/장부 규칙 유지

## 검증 및 한계
- PR #289 Windows 주요 CI 4종 통과: 가공 회귀 463개, N02 이어하기·장부 77개, 화면 통합 310개, UI Contract Windows Build 포함
- 2026-10-23 17:58 오류를 본뜬 주입 시나리오에서 4작업 등록·부분 완료 대기·수령·독립 시설 지속·취소 및 실패 분기 검증
- 주입한 49개 재고, 타이머 및 재검증 값은 실제 패킷에서 읽은 값이 아닙니다
- 오래된 V3.2.55 전용 후보 CI의 버전 불일치는 이 버전의 기능 실패 증거가 아니며 배포 승인 근거에도 사용하지 않았습니다
- **실게임의 재현 성공, 자동 업데이트와 사용자 PC 롤백은 미검증**입니다

## 업데이트 및 복구
