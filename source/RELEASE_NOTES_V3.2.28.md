# Mabi Auto V3.2.28 — 던전 메뉴·AI 진단 가독성·창 반응성 개선

## 변경 사항
- `던전 / 어비스` 왼쪽 메뉴에서 `페카 심층` 선택 항목을 제외했습니다. 기존 페카 심층 내부 구현은 제거하지 않았으며, 나머지 던전·어비스 모드 및 실행 핸들러는 유지했습니다.
- `로그 / 진단`의 AI 오류 관리 영역과 별도 `AI 오류 시간별 내역` 창을 앱의 차콜 다크 테마에 맞췄습니다.
- AI 오류 목록의 일반/교차 행, 헤더, 선택 상태, 오류 경고 글씨에 명확한 배경 및 글자색을 설정했습니다. 버튼과 필터도 같은 테마를 사용합니다.
- 커스텀 대시보드에서 반복 생성되던 GDI 글꼴을 픽셀 크기별로 재사용하고 폼 종료 시 해제합니다. 리사이즈 때 변경되지 않은 컨트롤의 재배치·불필요한 재그리기를 줄였습니다.

## 자동업데이트
- 설치된 V3.2.27은 공개 V3.2.28 릴리스가 검증 후 게시되면 앱의 기존 업데이트 확인 절차로 새 버전을 감지할 수 있습니다.
- 자동 업데이트는 `MabiAuto_V3.2.28_Windows_Lite.zip` + 대응 `.sha256` 체크섬을 사용합니다. 소스 ZIP도 함께 배포됩니다.
- 기존 `ApplyUpdate.ps1`, 복구 스크립트 및 롤백 절차를 유지합니다. 덮어쓴 기존 공개 릴리스는 없습니다.

## 확인 및 제한
- CI의 Windows 빌드, 가짜 CLI를 이용한 WinForms 회귀 검사, 생산 엔진 및 어비스·가공 검증을 통과한 `main` 커밋만 배포합니다.
- 릴리스 워크플로는 현재 `main` SHA, 앱·실행 파일 버전, 필수 패키지 파일, ZIP 내부 구조, 해시 및 실행 가능성을 검증한 뒤 공개 릴리스를 생성합니다.
- 실제 사용자 PC의 창 드래그 성능, DPI별 화면 대비, 게임 실행 중 반응성과 복구 절차는 별도의 실기기 검증이 필요합니다. 이동 성능 개선을 보장하는 것이 아니라 불필요한 화면 작업을 줄인 변경입니다.
- 게임 조작, 자동 분석 승인, AI 수정안 자동 병합·배포 정책, 패킷 수신 동작은 변경하지 않았습니다.

코드 변경: [GitHub PR #236](https://github.com/skwlrna/Mbi_auto_update/pull/236).
