# V3.3.28

하단 '화면을 터치해 주세요' OCR 우선 판정은 유지합니다. OCR이 누락될 때 강한 클리어 제목 이미지가 같은 위치에서 2프레임 확인되면, 결과창이 먼저 나타나지 않았는지 재검증하고 안전 영역을 한 번 클릭합니다. 1프레임 전투 이펙트, 약한 제목 점수, 이동하는 제목은 통과하지 않습니다.

터치 문구 기존 1~4배 OCR이 모두 실패한 경우에만 Lanczos-3 방식의 2.8배 확대 OCR을 추가했습니다. 다른 OCR 경로는 변경하지 않았습니다.

클릭 후 보물상자 + 분리된 초록 버튼 3개의 결과 확인, 다시 하기/가공 시 나가기, 타임아웃 및 롤백을 유지합니다.

실제 게임에서 오검출과 지연 여부 검증이 추가로 필요합니다.
