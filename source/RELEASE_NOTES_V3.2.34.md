# MabiAuto V3.2.34 — 장시간 가공·채집·제작 운영 안정화

## 장시간 운영 안정화
- 채집 중 **재고 변동이 없는 반복 관측 로그**를 60초 주기로 제한합니다. 새 재고 증가, 전투 전환, 이동 전환은 즉시 기록합니다. 기존 정체 감시, 도구·무게·CLI 재확인 빈도는 변경하지 않습니다.
- 전투 대기 중에는 반복 로그를 최대 1분에 한 번만 기록하며, **2초 주기의 전투 상태가 450회 연속 확인**되면 무한 대기 대신 안전 중단합니다(정상 폴링 기준 약 15분). 다시 시작/클릭/Space를 누르지 않습니다.
- 가공 F9의 독립 시설에서 `queue_full` 등으로 **선택 시설이 0/7칸인 채 타 시설 포화로 막힌 상태**는 기존 2분 최초 경고 뒤 **10분 간격으로 재알림**합니다. 같은 현상의 반복 알림만 제한하며 원재료 부족/등록/수령을 추측하지 않습니다.
- 시스템 시간이 역행하면 오래된 경과 시간을 신뢰하지 않고 보류 감시 시각을 새로 설정합니다.
- 제작은 이미 V3.2.33에서 실제 완료창 및 재고 증가와 작업 중복 입력을 검증합니다. 이 버전은 해당 경로를 유지하고 관련 회귀 테스트를 다시 검증합니다.

## 안전 제한
- 장시간 로그/알림은 **진단 전용**이며 화면 입력 허가, 패킷 추측 또는 오류 시 자동 재시작 근거로 사용하지 않습니다.
- 기존 가공시설 별 타이머 정체 감시, 배치 수령·소비 영속 장부, F10 취소, 정령의 날개 0개, AI 자동수정 승인·롤백 정책은 변경하지 않습니다.
- 전투 미해소 시에는 기존 작업 실패/정지 진단으로 넘기며, 전투 중 임의 정지 클릭을 만들지 않습니다.
- 원시 패킷 ID와 미관측 프로토콜 구조는 추가하지 않습니다.

## 테스트 및 배포
- 회귀 테스트: 처음·반복·진행 증가·상태 전환 시 로그 출력, 로그 제한 시각, 시간 역행, 450회 전투 경계, 채집 진입 전 장시간 전투, 다중가공 10분 재알림, 시설 해소 시 리셋.
- Windows CI 3종 성공, main 병합, 병합 커밋 메인 CI 성공 이후에만 Windows Lite/Source/SHA256 공개 릴리스를 게시합니다.
- 실제 PC 자동업데이트 설치와 무인 장시간 게임 운용 성공은 별도 현장 검증이 필요합니다.
