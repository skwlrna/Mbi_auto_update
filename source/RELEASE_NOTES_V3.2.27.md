# Mabi Auto V3.2.27 — 모비레이 참고형 콤팩트 대시보드 및 자동업데이트

## 변경 내용
- 사용자가 2026-10-18 첨부한 모비레이 화면을 참고하여 MabiAuto의 외형을 짙은 차콜 + 보라색 강조 스타일로 개편했습니다.
- 기본 화면을 1120×720 크기의 촘촘한 구성으로 조정하고 왼쪽 메뉴, 상단 테스트·설정 버튼, 3열×2행 상태 카드를 배치했습니다.
- 6개 카드에는 기존 런타임의 실행 상태, 모드·진행 단계, 생활 생산 이동, 작업 통계, 시스템 상태, 최근 활동을 표시합니다.
- 카드 간격·버튼 높이를 줄이고 하단 실행 기록과 수동 업데이트 확인 버튼의 겹침을 정리했습니다.
- 기존 채집·가공·제작·낚시·던전·어비스·스케줄러 및 F8/F9/F10 실행 핸들러는 변경하지 않았습니다.
- 실제 게임 기록이 없는 DPS, 재화, 캐릭터 정보나 가상의 ON/OFF 값을 만들어 표시하지 않습니다.
- 상대 프로그램의 실행 파일·이미지·글꼴·네트워크 기능을 포함하지 않고, 사용자가 제공한 화면의 시각적 구조만 참고했습니다.

## 업데이트
- 기존 V3.2.26 설치본은 실행 후 업데이트 확인으로 V3.2.27 공개 릴리스를 감지할 수 있습니다.
- Windows Lite ZIP, 해당 ZIP의 SHA-256 체크섬 및 소스 ZIP을 같은 CI-승인 커밋에서 빌드해 제공하며, 업데이트 시 체크섬 검증 및 기존 복구 스크립트를 유지합니다.
- 설치 중 오류가 발생하면 이전 버전 보관본과 `ROLLBACK_PREVIOUS.cmd`를 통해 복구할 수 있도록 기존 업데이트 구성을 보존합니다.

## 검증 및 주의
- GitHub Windows UI 빌드·격리 CLI 화면 테스트·생산 엔진·어비스·가공·스케줄러 회귀 테스트가 성공한 커밋만 운영 릴리스 후보로 사용합니다.
- 릴리스 워크플로에서 현재 `main` SHA 일치, EXE 버전, 파일 구성, ZIP 내용, 체크섬, Windows 프로세스 시작을 다시 검증한 후 공개합니다.
- 사용자의 실제 PC DPI, 게임 연동 및 자동업데이트 복구를 수동으로 직접 확인한 것은 아닙니다. 처음 실행 전 기존 프로그램과 설정/장부를 별도로 백업하고, 게임 매크로가 정지한 상태에서 업데이트하세요.
- 이전 V3.2.26의 가죽 완료 작업 수령 관련 안전 조건을 완화하지 않았습니다. 게임 및 캐릭터/CLI 조건이 확인되지 않으면 기존 안전 정지 정책이 우선입니다.
