# V3.3.05 — 가공·제작 화면 오인 정지 수정

- 정상 가공 시설의 초록색 배경을 확인창으로 오인하여 정지하던 문제를 수정했습니다. 가공 전체에 적용됩니다.
- 실제 가로형 확인 버튼의 형태와 범위를 확인하며, 기존 중앙 이동 확인창 및 수령 검증을 유지합니다.
- 공통 OCR은 한 번의 인식 누락으로 즉시 정지하지 않고 입력 없이 최대 6회 관찰합니다. 연속 두 프레임의 위치 일치 기준은 유지합니다.
- 제작 분류 카드에도 같은 관찰 방식을 적용했습니다. 가공·제작 입력을 임의로 재실행하지 않습니다.
- PR #406 포함. Windows 빌드와 가공·제작 회귀 검사를 통과했으며 실제 게임 검증은 배포 후 필요합니다.
- 20:20 로그의 완료된 중간재료 이어받기 장부 충돌은 별도 문제이며 이 버전의 해결 범위에 포함되지 않습니다.

이전 버전으로 복구할 때는 포함된 롤백 스크립트를 사용하세요.
