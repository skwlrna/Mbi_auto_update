# Mabi Auto V3.2.66 — 목재 가공 허브 복귀 안전 재시도

- 2026-10-26 16:13:26 KST 오류: 목재+ 완료 7건 수령을 위해 금속 가공에서 목재 가공으로 전환하다가 세 번째 시도에서 K 입력으로 가공 허브가 열렸지만, 재선택 없이 안전 정지했습니다.
- 이 버전은 카드 클릭 1회, 그 이후 이번 탐색의 K 재입력, 팝업 없는 6카드 허브를 모두 확인했을 때만 마지막 한 번의 카드 선택 기회를 부여합니다.
- 두 번째 클릭은 기존 제목 좌표를 반복하지 않고, 새 화면에서 대상 카드 시설명 OCR을 고유하게 확인한 뒤 같은 카드의 별도 본문 영역을 클릭합니다.
- 불확실한 화면·팝업·OCR 오류·관리자 CLI 유휴 미확정 상태에서는 추가 K/Esc/카드 클릭 없이 안전 정지합니다. 확인하지 않은 수령이나 재등록을 반복하지 않습니다.
- 실제 16:13 원본 화면의 Git blob 검증, 한국어 Windows OCR·컴파일된 화면 통합 검사, 메인 Windows CI, 실행 파일 스모크 테스트, ZIP/SHA256 및 롤백을 필수 검증합니다.
- V3.2.65의 재료 전송 주간 체크 수정과 실행 중인 매크로 업데이트 보류 로직을 유지합니다.
