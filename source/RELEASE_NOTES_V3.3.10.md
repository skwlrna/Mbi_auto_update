# Mabi Auto V3.3.10 — 음식 보관함 합산 및 가능한 수량 제작

- 음식 재료는 가방·캐릭터 보관함·공용 보관함을 한 CLI 응답에서 합산합니다. 위치별 수량과 합계를 로그에 표시합니다. 가공 중간재는 기존의 합산 조회와 연결합니다.
- 등록 음식 54종은 자동 수급 불가 재료와 하위 가공 재료를 함께 계산해 최대 10회부터 1회까지 가능한 배치를 선택합니다. 채집 가능한 원재료 부족은 가능한 제작 횟수를 줄이는 조건으로 사용하지 않습니다.
- 예: 고기 합계 106개면 고기 기준 10회, 78개면 7회, 10개면 1회 가능합니다. 다른 구매 재료도 함께 확인하며 실제 1회조차 불가능할 때만 남은 목표를 건너뜁니다. 이미 완료한 수량은 보존합니다.
- 제작 횟수 확정 후 퀘스트를 생성하면 즉시 클릭하고 재료 수급 단계로 연결합니다. 완료 후 다음 배치에서 최신 합산 재고로 다시 계산합니다.
- 스케줄러 음식별 시작·완료·배치 축소·건너뛰기 이유를 별도 food-summary.log에 보존하고 기존 오류 전송에 첨부합니다. 이후 가공 로그가 길어지거나 일반 로그가 교체돼도 해당 실행의 음식 요약은 유지됩니다.

검증: 제작 회귀 194개(가방/보관함 합산, 10/7/1/0회 실제 엔진 흐름, 공유 하위 재료 예약, 로그 회전 뒤 요약 보존 포함). Windows CI, 실행 파일 시작 및 ZIP/SHA256/소스 검증 후 공개합니다.
실제 게임 자동화 구동 검증은 미실시이며 기존 수동 롤백 기능을 유지합니다.
