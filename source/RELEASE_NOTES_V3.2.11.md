# MabiAuto V3.2.11 — Codex 한도 보호 및 ChatGPT 수동 인계

초기 스케줄러 운영 중 반복되는 오류로 AI 사용량을 과도하게 쓰지 않도록 보호합니다.

- **Codex 사용량 소진 감지:** 명확한 사용량/크레딧 소진 응답을 확인하면 AI 감시의 추가 Codex 실행을 일시정지합니다. 이 상태는 프로그램을 다시 실행해도 유지합니다. 일반 HTTP 429(일시적 속도 제한)은 사용량 소진으로 단정하지 않습니다.
- **오류 대기열 보존:** 진행 중 소진된 오류의 결과와 격리 작업 폴더를 보존하며 새로운 MCP 오류 보고서를 삭제하지 않습니다. 기존 결과를 자동으로 재실행하지 않고 다음 오류는 대기시킵니다.
- **중복 AI 비용 감소:** 10분 내 정확히 동일한 오류 증거의 중복 분석 방지 기록을 감시 프로그램 재실행 후에도 유지합니다.
- **ChatGPT 인계:** `AI 현황 → ChatGPT 인계 복사`를 누르면 오류 ID와 추정 오류 범위만 포함한 안전한 요약을 PC 클립보드에 복사합니다. 채팅으로 자동 전송하지 않습니다. 필요할 때만 사용자가 민감정보를 지운 로그를 추가합니다.
- **한도 복구 후 재개:** 사용량 초기화를 사용자가 직접 확인한 경우 `AI 현황 → Codex 한도 재개`를 눌러 저장된 미처리 새 오류 분석을 다시 허용합니다. 사용량이 재발생할 수 있고, 기존 실패한 패치는 자동 재생하지 않습니다.
- **기존 하루 최대 8회 유지:** 계정 사용량 소진과 별개의 로컬 한도입니다. 하루 한도에 걸린 오류도 ChatGPT 인계용 로컬 요약을 만듭니다.
- **안전 유지:** 매크로 F10, 매크로 종료 시 AI 감시 종료, Codex 격리 수정, 사용자 확인 없는 자동 병합·배포 금지, 기본적인 개인정보 보호 원칙을 유지합니다.

이번 기능은 ChatGPT 대화에 직접 연결하거나 OpenAI API 요금을 부과하지 않습니다. ChatGPT에서 분석을 계속하려면 **복사한 인계 요약을 직접 채팅에 붙여넣어야 합니다.**

Windows 오프라인 테스트와 EXE 시작 검사는 실제 게임 환경에서의 기능 정상 동작을 보장하지 않습니다.
