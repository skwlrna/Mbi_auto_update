# Mabi Auto V3.2.91 — 게임 업데이트 이후 CLI 활동 상태 구조 확인 보강

2026-11-05 게임 점검 이후 V3.2.90 다중가공 F9 시작 시 `get_activity 필수 필드 누락: $.IsReviving` 오류가 확인됐습니다. V3.2.88~V3.2.90은 모두 `IsReviving`을 필수로 요구했지만, 오류 당시 실제 응답의 전체 키 구조는 남아 있지 않았습니다.

## 변경 내용 (PR #381)

- `get_activity` 필수 필드 누락 또는 자료형 불일치 시 **값이 아닌 제한된 필드 구조와 자료형**을 로그에 기록합니다. 고정 상태 그룹과 필수 키, 최대 12개의 허용된 추가 상태 키 후보 및 제한된 중첩 후보만 기록합니다.
- `IsReviving`이 다른 이름이나 위치로 바뀌었을 가능성은 후보로만 표시합니다. 임의의 대체 필드를 `IsReviving`으로 인정하거나 `false`를 넣지 않습니다.
- 관리 가공의 K 입력 전 상태가 불완전하면 읽기 전용 `get_activity`를 1회 더 실행해 구조의 일관성을 구분하되, 두 번째 응답이 정상이어도 이번 입력을 차단합니다.
- 무료/날개 사용 검증 래퍼의 기존 예외 재전달에서 원래 발생 위치를 보존하도록 `ExceptionDispatchInfo`를 사용합니다.
- 실제 2026-11-05 `$.IsReviving` 누락을 재현하고 개인 정보·원본 응답값이 진단 로그에 포함되지 않는지 검사하는 테스트를 추가했습니다.

## 안전 및 배포 조건

- **게임 CLI의 변경된 실제 필드 구조는 아직 확인되지 않았고, 다중가공이 성공적으로 진행된다는 검증도 하지 않았습니다.** 이번 버전은 호환성 원인 확인을 위한 진단과 안전 정지 개선입니다.
- 누락 상태를 정상·대기 상태로 추측하지 않으며, 불확실한 상태에서 K/Space/완료품 수령/가공 등록을 자동 반복하지 않습니다.
- 정식 Windows Lite 패키지는 정확한 `main` 커밋의 CI 통과, Windows 빌드/스모크, ZIP SHA256 및 이전 버전 복구 도구 검증 후에만 공개됩니다.
- 실행 중 프로그램에 강제 설치하지 않습니다. 필요하면 `ROLLBACK_PREVIOUS.cmd`로 이전 설치 버전으로 되돌릴 수 있습니다.
