# V3.3.30

단독 자동채집 화면에 **최대 5종 순차채집 목록**을 추가했습니다. 채집 품목을 선택하고 수량을 입력해 **+ 추가**를 누르면, 등록된 수량을 **최종 목표 보유량**으로 저장합니다. F9는 목록의 품목을 등록 순서로 채집하며, 시작 직전 `get_items`로 실제 재고를 재확인해 부족한 수량만 채집합니다. 목표를 이미 충족한 품목은 입력 없이 건너뜁니다.

**주의:** `get_items` 기준 총보유 수량은 가방, 계정 보관함, 캐릭터 보관함을 합친 수량입니다. 가방만 목표로 지정하는 방식은 아닙니다.

- 목록에는 최대 5종의 서로 다른 품목을 등록할 수 있습니다. 같은 품목을 추가하면 기존 목표가 갱신됩니다.
- **목록이 비어 있는 상태의 F9는 기존처럼 단일 품목을 추가 수량만큼 채집**합니다. 이전 사용법을 바꾸지 않습니다.
- 기존 다중채집 코어와 안전 정지·재고 확인·F10 취소·미확정 동작 차단을 그대로 사용합니다. 품목 하나라도 실패하면 다음 품목을 시작하지 않습니다.
- 기존 F9 시설별 다중가공, 스케줄러, 어비스 클리어/보상 화면 인식, 자동 업데이트·SHA256·롤백 경로는 변경하지 않습니다.

**테스트:** 5종 순차, 목표 충족 건너뛰기, 재고 차액만 채집, 누적 진행 상황, 중간 품목 실패 시 이후 입력 금지 및 기존 단독 채집 회귀를 CI에서 검증합니다. 실제 게임에서의 최종 수락 테스트는 별도로 필요합니다.
