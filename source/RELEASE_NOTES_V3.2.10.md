# MabiAuto V3.2.10 — 스케줄러 안정화·자동 오류 진단·성능 기록

이번 버전은 V3.2.9 이후 `main`에 병합된 스케줄러 중심 개선 사항을 담습니다.

- **진단 도구(1차):** DebugViewCLI·ProcDump·ImageMagick의 로컬 수동 진단 명령을 추가했습니다. 별도 도구 설치는 자동으로 진행하지 않으며, ProcDump는 명시적 동의가 필요합니다. 스케줄러 디버그 출력은 기본 OFF입니다.
- **실행 안정화(2차):** 스케줄러 중복 시작 방지, 단계별 상태 기록, 15분 무활동 로그 경고를 추가했습니다. 경고는 자동 중단·재시작을 유발하지 않습니다. 기존 F10 정지를 유지합니다.
- **안전한 복구(3차):** 일시적 조회 실패만 최대 1회 재시도합니다. 저장된 작업을 자동 재실행하거나 게임 동작·수령·가공 등록을 반복하지 않습니다. 이어하기는 기존 사용자 확인과 CLI/장부 검증이 필요합니다.
- **Codex 자동 테스트·오류 학습(4차):** 스케줄러 수정안에는 스케줄러 전용 회귀 테스트를 필수로 요구합니다. 오류 학습은 원본 로그를 복제하지 않는 추정 분류이고, AI 테스트 통과만으로 실게임 해결을 확정하지 않습니다.
- **성능 계측(5차):** 제작·가공·전환 단계별 소요 시간과 최근 30회 완료/취소/실패 기록을 로컬에 보관합니다. 진단 상태 파일 갱신 간격을 15초에서 30초로 조정했습니다. 게임 입력 및 가공 대기·작업 순서는 기존대로입니다.

## 안전 및 업데이트 안내

- 자동 병합·Codex 수정안의 무단 운영 적용·프로그램 종료 후 자동 분석 재시작은 여전히 금지합니다.
- 설정·알림·이미지 템플릿은 기존 SHA256 검증·백업·롤백 업데이터 경로를 사용합니다.
- 이 릴리스의 ZIP은 Windows CI 성공 뒤 **새 태그 V3.2.10**으로만 게시하며, 기존 V3.2.9 릴리스를 덮어쓰지 않습니다.
- Windows 빌드·모의 회귀 검사 성공은 실제 게임 환경에서의 정상 동작을 보장하지 않습니다. 실제 스케줄러는 작은 작업으로 확인하세요.
