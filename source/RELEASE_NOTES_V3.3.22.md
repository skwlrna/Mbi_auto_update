# Mabi Auto V3.3.22 — 어비스 전투 중 결과 화면 오인식 차단 및 상태 복구

- 대상 오류: 2026-11-14 22:58:10 (V3.3.21) 허상의 정박지. 22:56:08 실제 전투 중 결과 화면으로 승격했지만 22:58:10 다시 하기 버튼 OCR=0, 중앙 녹색 0.000으로 120초 대기 후 정지.
- 함께 검증: 22:53:32 (V3.3.20) 클리어 S/화면 터치 오버레이에서 결과 화면으로 잘못 넘어간 상황.
- 결과 판정은 독립적인 실제 전투 HUD를 우선 거부합니다. 초록색 버튼 영역만으로 확정하지 않으며, 정확 다시 하기 OCR 또는 위치 제한된 '전투 시간'+'발견한 전리품' 2개 항목을 버튼 구조와 함께 확인해야 합니다. 재검증 프레임 간 최소 700ms 간격을 둡니다.
- 판정 오류로 ResultConfirmed에 들어갔더라도 다시 하기 버튼이 없고 전투 HUD가 새로운 3프레임에서 연속 확인되면 CombatClearWait로 복구하고 동일 판의 전투 시작 타이머를 그대로 보존합니다. 같은 판 복귀는 최대 3회 후 안전 정지합니다.
- 게임 내부 HUD 판별 함수와 전투 전용 HUD 증거를 분리했습니다. 기존 입장/타임아웃/스케줄러의 흐름과 인벤토리 집계 상태를 변경하지 않습니다.
- 클리어 제목/화면 터치 문구는 각자 제한 영역의 정확 OCR로 보완하면서 기존 2프레임 검증을 유지합니다. 결과 버튼 고정 좌표 (400,930)와 최종 녹색 검증 0.250은 변경하지 않습니다.
- 새 tests/release/test_v3322_combat_result_rescue.py와 V3.3.21 이전 모든 필수 회귀 검사를 메인 CI 및 릴리스 게이트에 연결했습니다.
- 실게임 수용 검증은 필요합니다. CI 통과는 실제 전투 재현 성공을 뜻하지 않습니다. 이전 버전 롤백과 SHA256 검증을 제공합니다.
