# MabiAuto V3.2.14 — 다중가공 추가 버튼 가공 조건 오판 개선

V3.2.13 적용 후에도 `+ 추가`가 `선택한 제법의 가공 조건을 확인하세요`로 거부된 실사용 제보를 반영했습니다. 종전에는 CLI가 `Alterable=false`이면서 `MissingIngredients=[]`라고 보고하면, **작업 목록에 추가**하는 읽기 전용 설정 과정에서도 오류로 차단했습니다. V3.2.13의 제법 순서/중복 개선과 별개로 남아 있던 조건입니다.

- **가공 목록 추가 개선:** 제법 이름·시설·생산 수량·순번이 확실히 확인된 경우, 현재 CLI 가공 가능 플래그가 불확실하더라도 목록에 등록할 수 있습니다.
- **명시적 안전 안내:** 즉시 가공 불가 상태라면 `목록 등록 완료 · F9 시작 전 재검증`을 표시합니다. 실행 가능하다고 잘못 표시하지 않습니다.
- **F9 안전장치 강화:** 시작 직전에 `get_alterable_items`를 다시 확인합니다. 계속 `Alterable=false`이고 부족 재료 증거가 없다면 배치 생성이나 게임 화면 클릭 전에 안전 중지하고 CLI `Reason`을 안내합니다.
- **기존 재료 확보 유지:** 부족 재료가 구체적으로 확인되면 기존 자동 재료 해결 경로를 유지합니다. 모호한 중복 제법, 제법 순번/생산 수량 변경은 계속 차단합니다.
- **회귀 테스트:** 설정만으로는 게임 입력이 발생하지 않는지, 준비되지 않은 제법을 추가·비우기 가능한지, F9의 불가/준비 회복/재료 부족/제법 변경 검증을 Windows에서 확인합니다.

## 점검 후 실사용 테스트

V3.2.14 자동업데이트 후 **자동 가공 → 제법 새로고침 → 가공 품목 선택 → 다중가공 + 추가**를 테스트합니다. `목록 등록 완료`까지 표시되면 설정 오류는 해소된 것입니다. 그다음 F9에서 다시 중단되는 경우 `[CLI][가공 제법]`, `[자동 가공] 선택 제법 상태`, `CLI가 현재 가공 불가로 응답` 로그로 게임 업데이트 후의 실제 CLI 상태를 분리 진단합니다.

게임의 최신 CLI 원본 응답은 아직 입수되지 않았습니다. 이 릴리스는 게임 측 데이터 구조 변경을 단정하거나 미확인 가공을 강제로 실행하지 않습니다.

이전 공개 릴리스는 변경하지 않으며 Windows Lite ZIP/Source ZIP/SHA256를 새 버전으로 생성해 빌드·스모크 테스트·회귀 테스트 및 최신 main 검증을 통과해야만 공개합니다.
