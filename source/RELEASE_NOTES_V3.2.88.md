# Mabi Auto V3.2.88 — 제작·가공·어비스 한 번에 안정화

이 버전은 V3.2.87 이후 통합 안정화 PR #376을 포함합니다.
PR #375의 제작 재시작 보호 코드와 기존 Draft #368의
입력 없는 상태 진단 부분을 통합한 **단일 정식 배포**입니다.

## 주요 변경 사항

- **제작**: F10/비정상 종료 후 미확정 제작 클릭과 확인된 재고 증가량,
  품목별 완료 및 건너뛴 상태를 로컬 장부에 보존합니다.
  다음 시작에서 미완료 기록이 있으면 기본 '아니요' 확인창을 표시합니다.
  자동 이어하기·남은 수량 추측·중복 제작 클릭은 하지 않습니다.
  '예'는 이전 장부를 보관하고 사용자가 새 목표로 시작하는 **신규 실행 승인**입니다.
  그대로 같은 수량을 다시 선택하면 중복 생산될 수 있으므로
  실제 재고와 퀘스트를 확인한 뒤 선택해야 합니다.
- **어비스**: 재입장 모집·로딩 화면이 15분 이상 변하지 않으면
  상태별 장기 대기 진단을 한 번 남깁니다. 무기한 대기·F10 취소·
  실전 재입장/퇴장 입력 정책은 기존과 동일합니다.
- **Watchdog/상태 감시**: 제작·다중가공·어비스 모드의
  UI/로그 활동을 별도 진단하며, OCR 재시도·모집 대기 로그를
  실제 진전으로 오판해 정체 경고를 초기화하지 않습니다.
  로컬 진단용 JSONL 및 Windows 읽기 전용 관찰 도구를 포함합니다.
- **기존 보호 유지**: F9 K/I/Space 필드 인증, 허브·시설 진입
  화면/CLI 검증, 어비스 클리어 제목+터치 문구 2프레임 확인,
  제작 OCR 30초 재시도 간격, 자동 재시작 금지.

## 검증 및 제한

Windows 빌드·모의 가공/제작/어비스·상태 감시·
실제 캡처 회귀 테스트, exact-main CI, 실행 파일 스모크 테스트,
Windows ZIP/SHA256/소스 ZIP/롤백 파일 검증을 배포 조건으로 합니다.

**실제 게임 실행은 하지 않았습니다.** 다중가공 시설 재진입
이슈 #316은 새로운 실제 화면 증거 없이 확정 해결로 주장할 수 없습니다.
기존 어비스 전투 중 클리어 오인 방지는 이미 코드와 회귀 테스트에 반영되어 있습니다.

설치 ZIP의 `ROLLBACK_PREVIOUS.cmd`로 이전 버전을 복구할 수 있습니다.
실행 중인 게임에 강제 자동 설치하거나 예전 버전을 덮어쓰지 않습니다.
