# Mabi Auto V3.3.03 — 불필요한 정지와 도착 대기 개선

배포일: 2026-11-08 (KST)

- 정체된 가공 시설은 보류하고 다른 독립 시설은 계속 처리합니다. 모든 남은 시설이 정체되면 종료하며, 완료로 처리하지 않습니다.
- 정체 시설은 실제 CLI 작업 변화가 확인되어야 다시 처리합니다. 장부와 시설 현장 검증을 유지합니다.
- 설비 도착 초기 안정화를 7프레임/3초에서 3프레임/0.6초로 축소합니다. 별도 1.2초 후행 검증, CLI 이동 종료, 팝업 및 시설 확인은 유지합니다.
- 이동 직후 일시적 대화/선택 상태는 8회 조회 대신 최대 10초 동안 입력 없이 재확인합니다.
- 스케줄러 일시적 읽기 오류는 최대 4회 조회하며 0.3초/1초/3초 간격을 둡니다. 상태 불일치와 인증 실패는 재시도하지 않습니다.
- 생산 입력 직전 인식이 오래 걸리면 새 화면으로 한 번 재검증합니다. 클릭 자체는 반복하지 않으며 기존 5초 입력 보호를 유지합니다.
- 유료 원격 가공 차단, 중복 등록·수령 방지, F10 취소 및 입력 창 검증을 유지합니다.
- Windows CI 및 회귀검사를 통과한 소스로 배포합니다. 실제 게임 동작 검증은 배포 후 필요합니다.

이전 버전 복구: `ROLLBACK_PREVIOUS.cmd`를 실행하십시오.
