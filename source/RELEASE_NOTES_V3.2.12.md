# MabiAuto V3.2.12 — 다중가공 ‘+ 추가’ 클릭 응답 개선

V3.2.11에서 다중가공 품목 추가 버튼이 눌리지 않는 것처럼 보인다는 실사용 제보를 바탕으로 가공 설정 화면을 개선했습니다.

- **‘+ 추가’ 버튼 응답:** 가공 제법이 즉시 사용 가능한 상태가 아니어도, 매크로가 대기 중이면 버튼 클릭에 반응해 추가할 수 없는 이유를 알려줍니다.
- **화면 내 상태 메시지:** 품목 미선택, 제법 목록 조회 중, 가공 조건 미확인에 따른 추가 거절, 작업 추가·목표 수량 갱신을 가공 화면에 표시합니다.
- **F9 안전장치 유지:** 제법의 작업 가능 조건은 기존 `SelectedAlteringPlan` 로직으로 검증합니다. 불확실한 제법을 실제 작업 목록에 등록하거나 게임 입력을 실행하지 않습니다.
- **레이아웃 및 회귀 테스트:** 다중가공 ‘+ 추가’ 버튼과 안내 라벨이 다양한 창 크기에서 보이는지, 정상 추가가 되는지, 잘못된 제법에서는 안전하게 추가가 차단되는지 Windows 자동 UI 테스트를 통과해야 합니다.

이 릴리스에는 V3.2.11의 Codex 사용량 소진 감지, 오류 대기열 및 ChatGPT 수동 인계 기능도 모두 포함됩니다.

**테스트 관련:** 기존 로그 저장소의 최신 오류 기록은 V3.2.4 시절의 수령 검증 오류이며, 이번 ‘+ 추가’ 버튼 문제와 직접 관련된 실게임 로그는 아직 확보되지 않았습니다. Windows CI 및 UI 회귀 테스트를 통과하더라도 사용자 PC에서 버튼 반응을 다시 확인해야 합니다.

자동 업데이트 방식은 V3.2.11과 동일합니다. 이전 릴리스는 덮어쓰지 않으며, 변경된 최신 코드를 포함하는 새로운 V3.2.12 Windows Lite ZIP과 SHA256 파일을 게시합니다.
