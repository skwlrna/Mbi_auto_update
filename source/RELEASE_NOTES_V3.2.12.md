# MabiAuto V3.2.12 — 다중가공 '+ 추가' 버튼 반응 개선

V3.2.11을 기반으로 다중가공 작업 목록의 **+ 추가** 버튼에 관한 실사용 보고를 반영한 안정화 패치입니다.

- **가공 제법 상태가 불확실할 때 버튼 반응:** 작업이 실행되지 않는 설정 화면에서는 버튼을 누를 수 있게 하되, 재료/제법 확인 결과에 따라 작업 등록을 계속 안전하게 거절할 수 있습니다.
- **화면에 직접 안내:** 품목 미선택, 목록을 불러오는 중, 가공 제법 검증 실패, 다른 작업 실행 중 등의 사유를 작업 목록 아래에 표시합니다. 정상적으로 등록하면 품목명과 목표 수량을 확인할 수 있습니다.
- **작업 중 보호 유지:** 실행 중에는 큐 수정이 비활성화되며, F10 중단과 기존 가공 안전 검사, 사용자 확인 및 서버 등록 동작은 변경하지 않습니다.
- **기존 테스트 보강:** 품목 미선택 상태 클릭, 정상 작업 추가, 미검증 제법 거부 및 잘못된 클릭으로 실제 게임 명령이 발생하지 않는지를 Windows UI 회귀 검사에 추가했습니다.

## 검증 및 적용
- 버튼 수정 소스: PR #199. Windows PR CI 2개 통과, 현재 main에 병합.
- 이 릴리스는 V3.2.12 태그/새 ZIP과 SHA256 체크섬으로만 게시하며 V3.2.11 파일은 덮어쓰지 않습니다.
- 실제 PC에서 버전 확인 후 **생산 관리 → 자동 가공 → 품목 선택 → + 추가**를 소량 테스트하세요.
- 실게임 정상 동작은 Windows 자동화 테스트만으로 입증할 수 없으며, 오류가 지속되면 V3.2.12 화면과 최근 로그를 공유해야 추가 진단이 가능합니다.
