# Mabi Auto V3.2.79 — 제작·가공 화면 복구 수정

- 장소·감정표현 메뉴가 열려 있으면 닫은 뒤 가공 화면 진입을 다시 확인합니다.
- 약품 제작대 목록을 제작 복구와 퀘스트 열기 전 화면 정리 대상으로 인식합니다.
- 알려진 팝업이 없다는 이유로 복구 완료 처리하지 않고, 일반 필드 HUD를 연속 두 화면에서 확인해야 K 입력을 허용합니다.
- 제작 퀘스트 클릭 후 화면 변화만으로 진행하지 않고 목표 품목 제목과 재료 팝업을 확인합니다. 기존 팝업 재사용에도 품목 확인을 적용합니다.

## 검증과 제한

Windows 빌드·화면·제작 회귀 검사를 적용합니다. 정확한 최종 main 커밋의 전체 CI, 배포 직전 화면·제작 회귀, 실행 확인, ZIP SHA256, BUILD_COMMIT 및 롤백 파일 검증을 통과해야 배포됩니다.

실게임 검증은 아직 완료하지 않았습니다. 최초 재료 수량 OCR 실패 순간의 화면이 없어 이번 수정은 확인된 화면 복구 결함과 퀘스트 열림 검증을 다룹니다. 문제가 있으면 ROLLBACK_PREVIOUS.cmd로 이전 버전으로 복구할 수 있습니다.
