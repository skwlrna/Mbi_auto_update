# Mabi Auto V3.2.94 — 산뜻 버섯 하단 행 OCR 재검증 수정

**원인:** 2026-11-05 21:18:37 KST V3.2.93 다중가공 오토로그. 산뜻 버섯은 기존 OCR 검색 영역(X=150~780, Y=145~980)에 보였지만, 전체 목록의 dim-text OCR이 정확한 글자를 반환하지 않아 9페이지 탐색 후 안전 정지했습니다.

## 포함된 수정 (PR #387)

- 약초 채집 검색이 실패할 때 실제 화면에서 관측한 행에 대해 네이티브 색상 OCR(2×/3×)으로 후보를 식별하고 **관측된 행만** 좁게 정확 재검증합니다.
- 유사문자는 OCR 재검증의 후보만 찾으며 그 자체로 클릭 권한이 아닙니다. 정확한 이름 한 건, 같은 행 아이콘, 서로 다른 두 프레임의 위치 안정성이 충족될 때만 항목 클릭을 허용합니다.
- 하단 행의 아이콘 셀을 좁혀 인접 행/패널 장식이 아이콘으로 오인되지 않게 합니다.
- OCR 원문·영역·매칭 수, 아이콘 대비, 행 위치 안정성, 최종 안전 정지 이유를 로그로 구분합니다.
- 가방/재료 상세 우회·고정 좌표 추측 클릭·중복 채집/가공 재시도는 추가하지 않았습니다.

## 검증 및 배포 조건

- 새 약초 행 회귀 테스트(실제 원본 스크린샷은 테스트 환경에 있을 때만, 기본 CI는 합성 화면 사용)와 기존 가공/채집·중간관리자·안전 정지 검사를 유지합니다.
- 정확한 릴리스 소스 SHA의 Windows 메인 CI 및 모의 테스트, 바이너리 빌드와 스모크 검사, ZIP SHA256·롤백 스크립트를 확인한 뒤만 정식 공개합니다.
- **V3.2.94의 실게임 정상 채집은 아직 검증되지 않았습니다.** 실제 성공 여부는 배포 후 다음 GitHub 오토로그로 확인해야 합니다.
- 설치 중인 프로그램을 강제 종료하지 않으며 `ROLLBACK_PREVIOUS.cmd`로 이전 버전으로 복구할 수 있습니다.
