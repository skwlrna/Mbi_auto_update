MabiAuto 16단계 / 독립 실행형 읽기 전용 진단 (개발 테스트)
============================================================

1. ZIP 파일을 운영 모비매크로가 설치된 폴더가 아닌, 새 빈 폴더에 압축 해제합니다.
2. 운영 모비매크로를 완전히 종료하세요. 게임은 필요한 경우 켜 두어도 됩니다.
3. Run_Stage16_ReadOnly.cmd를 더블클릭합니다.
4. 시작 여부 Y를 선택한 후, 열리는 [16단계 · 읽기 전용 테스트] 창에서
   [CLI 1회 확인]을 클릭하세요.
5. 연결, 활동, 가공 작업, 인벤토리 형식, 가공 레시피 형식 분류가 표시됩니다.
6. 테스트가 끝나면 창을 닫으세요.

주의 사항
- 이 테스트 EXE는 모비매크로 메인 화면을 열지 않습니다. 낚시·채집·가공
  자동화, 던전 이동, 버튼 입력, 관리자 업데이트, 텔레그램 제어는 실행하지 않습니다.
- 시작 시 CLI 질의 없음. 누른 뒤 읽기 전용 조회 5가지만 1회 실시합니다.
- 실제 MabinogiMobile_CLI.exe 경로는 기존 프로그램에서 사용하는 경로입니다.
- 관측하는 CLI 결과는 실시간 모비레이 패킷 디코딩이나 게임 공식 상태의 확증이 아닙니다.
- 'AI 증거 모의 확인'은 메모리 형식 검사일 뿐 실제 오류·Codex 분석이 아닙니다.
- 테스트 결과를 파일로 저장하거나 GitHub 등에 전송하지 않습니다.
- 이름·아이템·계정정보·CLI JSON 원문은 화면에 출력하지 않습니다.
- 자동화가 기존 이름과 다른 프로세스로 실행 중인지는 감지하지 못할 수
  있으니 운영 모비매크로를 직접 종료했는지 먼저 확인하세요.
- 새 폴더에 풀지 않고 운영 설치 폴더에 덮어쓰면 안전한 분리가 불가능합니다.

오류가 있다면 화면에 표시되는 진단 범주와 테스트한 시각만 채팅으로
알려주세요. 계정정보·캐릭터명·CLI 원문/스크린샷은 필요하지 않습니다.
