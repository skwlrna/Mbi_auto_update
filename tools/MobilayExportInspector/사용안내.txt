모비레이 내보내기 파일의 구조 확인 도구 (오프라인 전용)

이 도구는 게임 패킷을 캡처하지 않고, 모비레이에서 사용자가 직접
내보낸 JSON 또는 CSV 파일의 형식만 확인합니다.

실행 방법:
1. ZIP 전체를 새 폴더에 압축 해제합니다.
2. 모비레이에서 제공되는 내보내기 기능을 사용해 JSON 또는 CSV를
   먼저 저장합니다. 해당 기능이 없으면 억지로 파일을 만들 필요 없습니다.
3. 해당 JSON/CSV 파일을 RunExportCheck.cmd 파일 위로 드래그해서 놓습니다.
4. 확인 문구가 나타나면 대문자 YES를 입력하고 Enter를 누릅니다.
5. 'result status=' 및 'shape' 줄만 전달하면 됩니다.
   파일 원본은 제출하지 않아도 됩니다.

개인정보 및 제한:
- 원본 데이터 내용, JSON 키 이름, IP, PID, 토큰, 캐릭터 이름은 표시하지 않습니다.
- 처리량은 파일 1개 최대 2MB입니다. JSON 중첩 깊이는 24단계 이내입니다.
- 검사 결과를 파일·네트워크에 자동 저장하지 않습니다.
- 파일은 읽기 전용입니다. 게임, 모비레이, 모비매크로에 명령을 보내지 않습니다.
- 검사에 성공해도 실시간 API 연결이 확인됐다는 의미는 아닙니다.
- 기존 캐릭터 정보 원시 패킷 TXT는 이 검사 대상이 아닙니다.
- 공식 사용 허용 범위 안에서 생성한 자료만 검사해 주세요.
