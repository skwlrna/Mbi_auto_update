# 19단계 — 기존 화면 판정 결과의 읽기 전용 오류 진단 연결

## 연결 대상과 의미

18단계의 공통 오류 분류/사전 CLI 관측을 유지하며, 새 화면 캡처나 OCR을 실행하지 않는다.
**기존 게임 매크로가 이미 통과한 화면 안전 검사 결과**만 메모리의 AI 감시기 진단 캐시에 기록한다.

- **채집:** 기존 `GatheringScreen.StopAsync`의 CLI 활동+화면 정지 버튼 검사 2회가 모두 통과했고, 해당 활동이 채집으로 보고됐을 때만 `gathering_stop_control_double_checked`를 기록한다. 이것은 채집 완료나 안전 재시도 근거가 아니다.
- **어비스:** 기존 `AbyssTransitionTo`의 검증된 클리어 화면 단계와 실제 결과 화면 단계가 성공적으로 전이된 **후에만** `abyss_clear_pair_guard_passed` 또는 `abyss_result_guard_passed`를 기록한다. 별도의 흩어진 물길 기믹/보스 문양/패킷 이벤트를 추정하지 않는다.
- **제작·가공·낚시·일반 던전:** 기존에 위 조건에 해당하는 독립적 화면 판정이 연결되지 않았다. 화면 신호를 지어내거나 다른 모드 신호를 해당 기능의 증거로 재사용하지 않는다.

## 동작 구조

1. 기존 화면 판정 완료 → `AiPassiveCliEvidence.ObserveVerifiedScreen` (원본 이미지·OCR 텍스트·좌표를 기록하지 않음)
2. **사용자가 이미 켠 AI 오류 감시기** 안에서만 최근 두 개의 동일 신호 시각을 보관한다.
3. 오류 발생 시점 이전이고 **5초 이내**인 기록만 `SnapshotForScreenIncident`에서 가져온다. 오류 이후 또는 다른 기능/세션의 신호는 차단한다.
4. 채집에서 같은 구간의 기존 read-only CLI `get_activity`가 채집 중이라고 확인된 경우에만 `compatible_gathering_hints_only`를 붙인다. CLI의 의미가 비교 불가한 어비스 화면은 `no_comparable_cli_state`를 명시한다. 둘 다 오류 원인이나 성공 확정이 아니다.
5. 기존 `error.txt`에 고정된 `BEGIN VERIFIED SCREEN INCIDENT V1` 블록만 추가한다. 원본 화면·원문/OCR·캐릭터명·재료명·패킷 식별자는 넣지 않는다.

## 차단 경계

- 실게임 입력 흐름, H/WASD, F9, 클릭, 패킷 송수신, CLI 조회, 자동 시작/재시도, AI 코드 생성·적용, 릴리스 정책 **변경 없음**.
- 별도 화면 인식 작업, 이벤트 구독 폴링, 화면 데이터 업로드 **없음**.
- 상태가 불확실하거나 5초 만료이면 블록을 만들지 않는다.
- `verified_cause=false;gameplay_authorized=false;repair_authorized=false` 고정.
- AI 감시기가 꺼지거나 다시 시작되면 이전 화면 캐시를 지운다.
- 15단계 A/B의 Before는 18·19단계 블록을 **정확한 고정 스키마일 때만 제거**해서 동일 오류와 비교한다. 위조·중복·잘못된 필드는 유효한 진단 자료로 인정하지 않는다.

## 검증과 배포

`tests/common-observation/Stage19Tests.cs`: AI 옵트인, 영역 일치, 5초 만료, 오류 뒤의 관측 배제, 시간 역전, 오래된 캐시 제거, 고정 분류, 권한 없는 결과, 비식별 정보를 합성 시험한다.

`test_evidence_ab_stage15.py`: 올바른 19단계 블록 제거와 승인 값 위조/중복/영역 불일치 차단을 시험한다. Windows 생산 엔진/어비스·가공 회귀 워크플로도 계속 적용한다.

현재 범위는 **개발 PR #231 검토용**이다. main 병합·릴리스·실게임 효과 검증은 진행하지 않는다. 특히 오류율이 실제로 낮아졌거나 화면/CLI 신호가 완전히 일치한다는 통계는 아직 없다.

다음 작업은 사용자 개입을 늘리지 않는 범위에서 다른 자동화 기능의 **이미 검증된 화면 결과**가 어떤 지점에서 독립 관측값이 되는지 점검하고, 오탐/누락 지표를 실측 전까지 추정하지 않는 것이다.
