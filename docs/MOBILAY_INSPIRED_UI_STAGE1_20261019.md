# MabiAuto: Mobilay 화면 참고형 UI 1차 구현

## 기준 자료
사용자가 2026-10-18 첨부한 `mobilay.zip`과 메인·설정 화면 캡처
(`1(20261018-031910).PNG` 포함)를 시각 참조로 사용함.
원본 실행 파일, 제3자 로고, 메뉴 이미지, 계정 기능, 네트워크 프로토콜은
코드·패키지에 복사하지 않음.

## 적용 범위

- 기본 창을 화면 내 가로형으로 표시하는 다크 테마 (차콜 배경, 밝은 글자, 보라색 강조)
- 상단 제목·버전 표시·테스트/설정 바로가기, 기존 창 최소화/최대화/종료 기능 보존
- 왼쪽 세로 메뉴: 홈, 자동화, 던전/어비스, 생활 생산, 스케줄러, 기타/설정, 로그
- 아래쪽 빠른 버튼: 미니 모드, 최소화, 항상 위에 표시, 설정
- 대시보드 3열 × 2행 카드: 자동화 상태, 모드/진행 단계, 생활 생산,
  실행 통계, 시스템 상태, 최근 활동
- 각 카드 오른쪽 위 버튼은 기존 F8/F9/F10 및 모드 전환 경계를 그대로 사용
- 생산/제작/스케줄러 화면의 배경·입력 목록·선택·버튼 대비 보정

## 동작·안전 계약

UI 이외의 게임 입력기, 패킷 관측, 가공 재료 해결, 스케줄러 실행,
AI 오류 수정 프로세스는 변경하지 않음. UI 카드 값은
기존 MainForm의 실제 상태 라벨과 카운터에서만 가져옴.
실제 DPS/채팅/숙제/유저 정보를 읽어 오는 새 기능은 구현하지 않았으며
이런 수치를 화면에서 생성하거나 지어내지 않음.

`ReferenceDashboard.SelectMode`의 **실행 중 모드 변경 차단**은 유지하고,
F9 시작·F10 정지·F8 테스트와 기존 설정 창/로그/스케줄러 동작을 호출함.

이 작업은 **모비레이 시각 참조 기반 1차 개편**이며,
상대 프로그램의 픽셀 단위 복제나 동일 기능 제공을 의미하지 않음.

## 자동 검증 및 배포 제한

`tests/mobilay-ui/test_mobilay_ui_contract.py`는 UI 코드와
기존 모드 연결을 합성 정적 검증하며 네트워크·게임/입력/AI 호출은 실행하지 않음.
`Check V3 Production Engine` Windows workflow에서
프로덕션 앱 빌드와 위 UI 계약 테스트를 실행함.

UI 실사용 조작성, 한국어 글자 잘림, 125%·150% Windows DPI,
고해상도/저해상도 화면, 기존 미니 모드/설정 창에서의 색 대비는
실제 Windows 화면 확인이 추가로 필요함.

최종 CI 성공 후에도 운영 `main` 반영/정식 릴리스/자동 업데이트는
사용자의 명시적 배포 결정과 실사용 확인을 별도로 요함.
현재 작업 브랜치: `feat/mobilay-inspired-ui-20261019`.
