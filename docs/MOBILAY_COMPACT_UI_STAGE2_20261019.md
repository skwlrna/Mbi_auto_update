# 모비레이형 UI — 콤팩트 시안 2차 조정 (2026-10-19)

기준: 2026-10-18 사용자가 제공한 모비레이 메인 화면 및 1차 UI PR #235.
기존 자동화 엔진 및 업데이트 실행 정책은 변경하지 않는다.

## 변경점

- 기본 창을 1180×780에서 **1120×720**으로 축소한다. 화면 작업영역이
  더 작은 PC에서는 사용 가능한 영역을 넘기지 않도록 제한한다.
- 3열×2행 대시보드를 유지하지만 가상 좌표의 카드 높이를
  **349→302**, 행 간 간격을 **364→315**로 줄인다.
- 왼쪽 탐색 버튼 크기 **200×54→200×49**, 첫 항목 위치
  135→123, 각 항목 간격 58로 변경했다.
- 카드 세부 정보의 행·간격·폰트 크기를 보정했다.
- 화면 아래에 **읽기 전용 최근 실행 기록** 115px 영역을 추가했다.
  실제 로그 텍스트가 없는 경우에는 비어 있음을 명시한다.
- 사용자 요청으로 유지해야 하는 수동 **업데이트 확인** 버튼은
  기존 2열 카드와 겹치지 않게 하단 오른쪽으로 이동했다.
- F8/F9/F10, 기존 채집·가공·제작·낚시·던전·어비스·스케줄러,
  시작/중지 제어와 AI 가드는 기존 핸들러 그대로 쓴다.

## 검증 계획 및 제한

GitHub Windows 빌드 및 실제 WinForms 가짜 CLI 회귀 테스트,
읽기 전용 UI 정적 계약, 기존 엔진 CI를 **마지막 커밋에서** 확인한다.
실제 사용자의 게임 실행 화면에서 DPI/폰트 크기·마우스 클릭·메뉴 겹침은
이 자동 테스트만으로 최종 판정할 수 없다.

이미지 생성 도구의 촘촘한 시안은 **시각적 디자인 제안**이고
실제 앱 스크린샷이 아니다. 화면 속 임의 PID, DPS, 게임 연결, 채집 횟수,
모드 ON/OFF 등은 앱의 확인된 실측 값이 아니므로 그대로 표시하지 않는다.
현재 구현은 실제 메인 앱의 수치와 동작 가능한 기능만 연결한다.

개발 PR #235는 계속 **draft**이며 `main`/정식 설치본/업데이터는 변경하지 않는다.
테스트용 GitHub Actions 아티팩트는 설치본 대체가 아닌 독립 폴더의 UI 비교용이다.
