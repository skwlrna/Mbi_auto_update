# Mobilay 참고 UI 적용 — 2026-10-19

## 출처 및 작업 범위

사용자가 2026-10-18에 직접 첨부한 `mobilay.zip` 및 화면 캡처
`1(20261018-031910).PNG`, `1(20261018-032028).PNG`,
`1(20261018-032100).PNG`, `1(20261018-032456).PNG`의
화면 구조를 참고하였다. 압축파일 안의 제삼자 애플리케이션 실행 파일,
DLL, 브랜드 그림, 폰트는 저장소에 복사하지 않았다.

Windows 매크로 MabiAuto에는 원래부터 WinForms 기반의 별도
ReferenceDashboard 렌더링과 기존 F8/F9/F10 매크로 처리기가 있었다.
원래 제어 기능을 재작성하지 않고 시각 레이어만 변경했다.

## 구현된 모비레이 스타일

- 차콜 배경: RGB(23,23,24), 다크 카드: RGB(29,29,31),
  보라색 강조: RGB(171,143,249), 밝은 정보 텍스트.
- 화면 초기 크기 1180×780(모니터 작업 영역이 작을 땐 축소).
- 상단: Mabi Auto 타이틀/현 버전, 명시적 F8 테스트, 설정,
  기존 최소화·최대화·종료 버튼.
- 좌측 메뉴: 홈, 자동화 실행(낚시), 던전/어비스(페카 심층 포함),
  생활 생산(가공·채집·제작), 스케줄러, 기타/설정, 로그/진단.
- 좌측 하단: 탭 접기, 창 최소화, 최상단 표시 토글, 설정.
- 중앙: 3열 × 2행 둥근 카드와 각 카드 바로가기 화살표.
  카드 1 자동화 상태/실행 시간/진행률, 카드 2 모드/현재 단계,
  카드 3 생활 생산 메뉴, 카드 4 실제 성공·시도 통계,
  카드 5 게임·OCR·입력·감시기·업데이트,
  카드 6 최근 인식 및 기록.

**대시보드 수치는 기존 런타임 Label/ProgressBar에서만 읽는다.**
모비레이의 DPS 수치·채팅·유저 데이터 등 MabiAuto가 지원하지 않는
기능은 가짜 수치로 채우지 않는다. 생활 생산 항목도 모비레이처럼
시설 상태가 실제로 비어 있다고 표시하지 않고
`설정에서 선택`으로 명시한다.

## 시각 비교 및 남은 검증

CI의 성공은 **컴파일과 정적 UI 안전 계약**을 검증할 뿐
Windows 화면과 원본 모비레이의 픽셀 단위 완전 일치까지 보증하지 않는다.
현재 사용자의 게임 환경과 DPI에서 UI를 실제로 촬영하지 않았다.

PR에 포함되는 `MabiAuto-Mobilay-UI-Preview-Win64`은 **14일 보관
미리보기 아티팩트**다. 반드시 원래 매크로를 종료하고 별도 폴더에 풀어
외형을 검사한다. 운영 설치본에 덮어쓰거나 자동 업데이트로 제공하지 않는다.
버튼 실행 검증은 복구 가능한 테스트 환경에서만 한다.

사용자에게 받은 어제 자료를 기준으로 만든 1차 UI 구현이므로,
실제 Windows 캡처 비교 후 간격·아이콘·하단 버튼·설정 팝업 등의
차이를 단계적으로 보완할 수 있다.
