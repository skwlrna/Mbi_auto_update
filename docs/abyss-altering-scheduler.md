# 다중가공 + 어비스 병행 스케줄러 (F7 실험 브랜치)

운영 상태: Draft. 새 7메뉴 통합 UI는 PR #164를 사용하세요.

## 실행
1. 가공 작업 목록을 설정하고 어비스 던전을 선택합니다.
2. 가공 화면에서 F7 병행 켜기, F9 시작, F10 중단.
3. 출발 조건은 활성 가공 작업의 남은 시간이 모두 90초 이상인 순수 대기 상태입니다(기존 실험 브랜치 기본값).

## 시간 정책
- 가공 대기 중 어비스 1판으로 입력권을 넘기며 **가공 관리자 2분 정체 감시만 일시정지**합니다.
- 실제 서버 가공 작업과 완료 시간은 멈추지 않습니다.
- 어비스 소요시간이 매번 달라도 스케줄러 자체의 임의 종료시간을 적용하지 않습니다. 기존 어비스 엔진의 전투 시간초과/안전복구는 유지합니다.
- 결과 화면 확인 → 왼쪽 나가기 고정 클릭(800×1000 기준 165,930) → 던전 밖 HUD 3회 검증 후 가공 관리자 감시 재개.
- 밖으로 나온 직후 CLI 서버 가공 대기열을 재조회하고, 완료 상태라면 기존 등록·수령 관리자 로직에 따라 처리합니다.
- 나가기 검증/퇴장 확인 실패 및 F10 취소 시 후속 가공 입력을 중지하고 영구 작업 장부를 보존합니다.
- 단독 어비스에서는 가운데 다시 하기 고정 클릭(800×1000 기준 400,930) 후 전투 복귀 검증을 유지합니다.

## 검증
- 임의 어비스 길이 동안 타이머 동결 후 재개, 기존 90초 출발 기준, 실패 시 가공 차단, 고정좌표 테스트.
- 운영 전 실제 Windows 화면 클릭 및 필드 복귀와 가공 재시작 테스트가 필요합니다.
