# 어비스 + 다중가공 병행 스케줄러 (실험용)

> **운영 상태: Draft / 실게임 결과 화면 검증 전.** 단독 어비스 및 단독 다중가공은 기존 코드가 기본으로 사용됩니다. 기본적으로 병행 기능은 꺼져 있습니다.

## 실행

1. 기존 방식으로 자동가공 품목과 수량을 설정합니다.
2. 필요하면 **어비스** 모드에서 대상 던전을 먼저 선택하고 다시 **가공** 모드로 돌아옵니다. 현재 병행 기능은 마지막 어비스 던전 선택값을 사용하며 기본값은 **허상의 정박지**입니다.
3. **가공** 모드에서 **F7**: 병행 사용/해제. 상태 표시를 확인합니다.
4. **F9**: 기존 다중가공 배치를 시작합니다. **F10**: 전체 중지 (기존 저장 장부 보존).

## 입력 소유권

- 가공 관리자만 작업 등록/재료 확인/완료 수령/시설 이동 및 저장 장부를 변경할 수 있습니다.
- 가공 코디네이터의 **순수 대기 상태**에서 진행 중 가공이 있고 모든 진행 중 작업의 남은 시간이 **90초 이상**일 때만 선택적 어비스 1판으로 넘깁니다.
- 가공 화면에 있었다면 기존 **ZeroWingAlteringScreen.ExitToFieldAsync**를 실행하여 인식된 UI를 닫고 필드로 복귀합니다. 기존의 캐릭터 및 정령의 날개 검증을 그대로 이용합니다.
- 이때 시설 현장확정 증거를 무효화합니다. 다음 가공 입력 시 기존 코드가 시설 이동/현장 검증을 새로 수행합니다.
- 어비스 1판은 **반복 시나리오 파일을 수정하지 않고**, 메모리상의 시나리오에만 `Repeat=false`를 설정하여 실행합니다. 1판 중에는 가공 화면 입력이 없습니다.
- 결과 화면에서 기존 **가운데 다시 하기 검증**으로 3버튼/프레임을 검증한 다음, **왼쪽 나가기** 정확한 OCR을 2회 확인해야 한 번만 클릭합니다. 던전 밖 HUD를 3회 연속 확인하기 전에는 가공에 입력권을 돌려주지 않습니다.
- 성공적으로 밖으로 돌아오면 CLI 대기열을 **새로 조회**하고, 모든 기존 수령·중복등록·장부 검증 로직을 그대로 진행합니다.

## 오류 정책

- 결과/나가기 OCR, HUD 복귀, 화면 정리/동일 캐릭터/정령의 날개 검증이 불확실하면 **추가 가공 입력 없이 정지**합니다.
- 중간 정지나 오류 때는 **다중가공 세션 기록을 보존**합니다. 해당 가공 작업은 게임에서 계속 진행될 수 있으므로 다음 실행 전에 별도 **이어하기 검증**이 필요합니다.
- F10은 공유 취소 토큰을 사용하며, 병행 중단 시 게임 캐릭터가 어비스 내부에 있을 수 있습니다. 현재 화면을 확인 후 작업을 재개해야 합니다.
- 정령의 날개 자동사용, 재료 임의 보충, 보상 버튼 추정 좌표 클릭을 추가하지 않았습니다. 기존 가죽 원재료 소진 정책도 유지합니다.
