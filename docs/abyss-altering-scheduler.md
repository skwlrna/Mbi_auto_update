# 통합 스케줄러: 제작 + 가공 + 어비스 (실험용)

운영 상태: Draft. 실제 Windows 클라이언트 고정좌표 클릭과 던전 밖 복귀 검증 전에는 main에 병합하지 않습니다.

## 실행
1. 가공 탭에서 시설별 제법 검색 및 다중가공 작업 목록을 설정합니다.
2. 필요하면 제작 탭에서 음식 또는 아이템과 수량을 설정합니다.
3. 스케줄러의 작업 계획에서 제작/가공/어비스를 고르고, 어비스 설정에서 던전을 선택합니다.
4. 어비스 출발 최소 가공 남은 시간은 90/120/180/240/300초 중 선택합니다(기본 120초).
5. F9 시작, F10 전체 정지. 단독 자동화의 기존 실행도 유지합니다.

## 시간과 입력권
- 출발 최소 대기시간은 짧은 가공 대기 중 불필요한 입장을 방지하기 위한 기준이며, 어비스 클리어 예상시간이나 상한이 아닙니다.
- 어비스 입장 전 가공 관리자 정체 감시(2분) 시간은 일시정지합니다. **게임 서버 가공 작업과 실제 완료 시간은 멈추지 않습니다.**
- 어비스가 얼마나 걸리든 스케줄러는 던전 시간을 추정해 임의로 가공에 입력권을 넘기지 않습니다. 단, 기존 어비스 엔진 자체의 전투 시간초과/자동복구 안전정책은 그대로 유지됩니다.
- 결과 화면 확인 → 왼쪽 고정 나가기(800×1000 기준 165,930) → 던전 밖 HUD 3회 연속 검증 뒤에만 정체 감시를 재개합니다.
- 복귀 직후 서버 가공 작업 목록을 새로 조회하고 정상 배치 수령·등록 조건을 판단합니다. 가공 진행상태가 달라졌다면 최신 상태를 따릅니다.
- 나가기/필드 확인 실패, F10 취소 시 후속 가공 입력 금지, 기존 장부 보존.
- 단독 어비스 재시도 버튼은 가운데 고정(800×1000 기준 400,930), 클릭 후 전투 복귀 검증. 두 버튼 모두 실제 화면 검증 뒤 한 번만 클릭합니다.

## 검증
- 테스트: 가공 대기 임계값 조절, 임의 어비스 길이에서 감시 정지/재개, 실패·취소 후 가공 입력 방지, 고정좌표 안전 검증.
- Windows Actions: 프로그램 빌드 및 가공/제작/이어하기/재시도 회귀 검사.
- 미완료: 실제 Windows 800×1000 게임화면에서 고정 클릭과 던전 밖 확인 후 가공 재개.
