## 판정 운영 원칙

- CI 단계가 **성공**이면 위 L2/L3 기계 검증에 한해서 `통과`로 기록한다. 해당 사건의 실게임 원인 해결 여부는 `검증 불가/미검증`으로 유지한다.
- 실게임/비공개 이미지가 없는 항목은 **통과로 승격하지 않는다**.
- CI 실패의 최초 실패 체크 ID를 기록하고, PR #341 브랜치에서만 수정한다. 각 변경 후 **최신 HEAD의 네 필수 CI를 재검증**한다.
- 같은 현상이라도 실제 최초 실패 지점(화면 분류 / 현장·소유권 / CLI·팝업 / 장부 / 안전정지)을 분리한다.
- 단일 오류 스냅샷의 게임 창 좌표·텍스트만으로 CLI 상태·작업완료·현장 도착을 추정하지 않는다.
- 전체 로그 목록은 별도 238건 검증 대장에 취합했다. 표본 외 77개 다중가공 사건과 타 기능 120건은 아직 각 사건을 재현하지 않았다. '**과거 전체 오류 완전 통과**' 선언 금지.
- `main` 병합, 릴리스, 자동업데이트, 실제 게임 조작은 모두 금지한다.
